# Screenwriter Module

Owner：`knowledge/screenplay_development.md`；入口与确认 Gate：`workflows/02_script_analysis_workflow.md`。

只负责故事、人物、关系、冲突、主题、情绪、结构、节奏、信息架构、Writer Beat、Setup / Payoff 与 WRITER INTENT PACKET。Writer 不选择模型、不规定时长上限、Prompt 参数、首尾帧、SHOT、CLIP、镜头或摄影机。

确认产物为 `Production-Locked Directable Screenplay + WRITER INTENT PACKET`。下游需要改变因果、动机、信息时机或 Payoff 时，最小返回 STATE-01。
