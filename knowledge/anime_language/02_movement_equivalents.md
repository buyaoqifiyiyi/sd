# Atom 2 — Movement Equivalents｜运动的版面等效

## Purpose And Owner

本原子拥有 `2d_anime` 档的**运动表达**：把实拍的运镜翻译成版面上可执行的对等物。

它与`knowledge/camera_language/camera_movement/`（65个原子中的运镜族）与`knowledge/camera_language/movement_combinations/`互为**对等物**。

边界：不拥有版面结构本身（归`knowledge/anime_language/01_layout_and_space.md`）；不拥有帧感与冲击（归`knowledge/anime_language/03_timing_and_impact.md`）；不拥有跨镜头的运动组合决策（仍按`knowledge/camera_language/movement_combinations/decision_engine.md`的选择逻辑判断"要不要动"）。

**核心前提**：绘制媒介里**摄影机不存在**。所有运动都发生在版面上，不是发生在空间里。

## Executable Vocabulary｜可执行词汇

| 实拍运镜（本档禁止写入） | 绘制媒介等效物 | 写进哪个既有字段 |
|---|---|---|
| Push In 推 | **版面放大**：角色层与背景层同比例放大，可见取景范围收窄 | `运镜` |
| Pull Out 拉 | **版面缩小**：露出更多环境层与留白 | `运镜` |
| Zoom 变焦 | 版面放大但**层间关系与层信息不变**（与Push的区别：Push可带出新的层，Zoom不能） | `运镜` |
| Pan 水平摇 | **版面水平平移**：只移动可见窗口，**地平线与消失点保持不变** | `运镜` |
| Tilt 俯仰摇 | **版面垂直平移**，同样不改变透视 | `运镜` |
| Tracking / 跟移 | **背景层循环滚动 + 角色层原地动作循环**，角色保持在版面固定位置 | `运镜` |
| Dolly / 侧向移 | 背景层整体水平位移，角色层同向位移或原地，产生**层间视差** | `运镜` |
| Crane / 升降 | 版面垂直位移 + 前景层位移量大于远层 | `运镜` |
| Orbit / 环绕 | **多张已确认背板轮换**，或角色层与背景层反向位移；不做三维环绕 | `运镜` |
| Handheld 手持 | **无对等物**。不安定感改由构图倾斜、线条抖动与帧感承担 | `构图`、`运镜` |

## Conditions And Anti-Use｜成立条件与反用

- **一次一个运动**：同一镜头只允许一个方向、一个触发。叠加两种版面位移（例如同时放大并横移）会让层关系失真。
- **可延展的背景层**：横移、跟移要求背景层可循环或可延展；否则会露出未绘制区域。写Prompt时必须说明背景是可循环的，或给出明确的位移上限。
- **透视不得随平移旋转**：横移与俯仰摇的过程中，地平线、消失点与建筑结构线保持不变。这是绘制媒介与实拍摇镜最大的差别，也是模型最容易做错的地方。
- **环绕降级优先**：没有已确认的多角度背板时，环绕一律降级为分层反向位移；不得要求模型生成真实环绕。
- **运动的触发**：仍按`knowledge/camera_language/index.md`的`Camera Movement Trigger`，由可定位的戏剧Beat触发，写明`Trigger → Path → Stop → End Composition`；本档不因为"是2D"就放宽这条纪律。
- **禁止**：轨道车、摇臂、稳定器、云台、无人机、真实焦段变化、真实运动模糊。

## Prompt Translation｜Prompt 转译

只使用既有`运镜`字段。示例写法：

- `运镜：版面水平右移——背景层循环滚动，角色层保持在版面左侧三分之一并原地跑动循环；地平线与消失点不变化`
- `运镜：版面放大——角色层与背景层同比例放大至胸上占比；不引入新的层信息`
- `运镜：固定版面——不安定感由构图倾斜与线条抖动承担，不写手持`

每条运动必须写出**层级关系**（哪一层动、哪一层不动、角色在版面上的落点），不得只写"镜头移动"。

## Failure Signals｜失败信号

- 横移时消失点跟着转——模型把版面平移理解成了三维摇镜。
- 背景露出未绘制空白区，或循环接缝可见。
- 跟随镜头里角色相对版面漂移，位置无法维持。
- 出现实拍透视畸变、运动模糊或稳定器式的平滑浮动。
- 同一镜头里出现两种以上的版面位移，层关系读不出来。
