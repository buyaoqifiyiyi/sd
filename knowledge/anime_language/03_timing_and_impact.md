# Atom 3 — Timing And Impact｜帧感与冲击

## Purpose And Owner

本原子拥有 `2d_anime` 档的**时间与冲击表达**：动作的节奏、停格、以及"打击感"如何在没有快门与运动模糊的条件下成立。

它与实拍的时间相关原子（快门、帧率、运动模糊、升降格）互为**对等物**。

边界：不拥有运镜与版面位移（归`knowledge/anime_language/02_movement_equivalents.md`）；不拥有剪辑点与信息顺序（仍归`knowledge/camera_language/editing_language/`与`knowledge/transitions/`，两者在本档继续适用）；不拥有 Clip 划分与时长（归`knowledge/clip_planning/`与当前 Adapter）。

## Executable Vocabulary｜可执行词汇

| 实拍量（本档禁止写入） | 绘制媒介等效物 | 写进哪个既有字段 |
|---|---|---|
| 快门角度 / 运动模糊 | **残影**（同一动作的多重轮廓）或**速度线**；二选一，不同时使用 | `运镜`、动作描述 |
| 帧率 / 升降格 | **关键帧密度**：动作段用更疏的关键帧换冲击，平缓段用更密的关键帧换顺滑 | `运镜`、动作描述 |
| 冲击瞬间 | **impact frame**：一张高对比、形变夸张的单帧 + **集中线** | `构图`、动作描述 |
| 极速拉伸 | **smear frame**：单帧的轮廓被拉伸变形，用于速度与力度 | 动作描述 |
| 运动模糊的方向感 | 速度线的方向与密度 | `运镜` |
| 停顿 | **停格**：完全静止的一拍。它是合法且有力的手段，不是失败 | `运镜` |
| 慢动作 | 增密关键帧并保持形变连续，或重复帧强调 | `运镜` |

## Conditions And Anti-Use｜成立条件与反用

- **一次一个手段**：同一次冲击只使用 smear frame、impact frame 或集中线中的一种。三种叠加会让画面糊掉，冲击反而消失。
- **停格要有触发**：停格用于信息落点、反应与决断，不得作为省事手段连续使用；连续停格会让节奏塌陷。
- **速度线避让身份读点**：速度线不得覆盖面部、发型轮廓与关键道具。
- **生成式模型的现实约束**：当前视频模型对"精确输出某一帧"不可靠。smear frame 与 impact frame 只能作为**意图描述**写入，且**同一Clip不超过一次**；不得要求模型输出指定帧号或精确形变。能力与时长窗口以当前`adapters/`对应Adapter为唯一真源。
- **与时长一致**：关键帧密度的描述必须与该Clip的实际时长相容；写不进去时按当前 Adapter 的时长窗口调整动作切分，不写数值。
- **禁止**：快门角度、帧率数值、运动模糊半径、升降格百分比等实拍参数。

## Prompt Translation｜Prompt 转译

只使用既有字段（`运镜`、动作描述、`构图`）。示例写法：

- `运镜：固定版面；动作中段以速度线承担方向感，停格一拍后落回静帧`
- `动作：出拳至命中处以单帧拉伸（smear）表达力度；命中后停格，仅集中线指向前方`
- `运镜：关键帧密度由密转疏——起手顺滑，冲击前只保留三个关键姿态`

## Failure Signals｜失败信号

- 同一次冲击里堆了两种以上手段，画面糊成一片，力度反而不成立。
- 速度线覆盖面部或关键道具，身份读点丢失。
- 连续多个Clip都使用冲击帧，冲击贬值成常规节奏。
- 本该停格的一拍被模型补成缓慢漂移（出现"呼吸感"），停格失效。
- Prompt 里出现帧率、快门或运动模糊数值。
