# Poster Typography And Layered Production

## 1. Copy Hierarchy

按项目实际需要排列，不机械填满：

1. 主片名
2. 核心宣传语
3. 英文副题或译名
4. 上映日期、平台或行动信息
5. 已授权的主创与制作信息
6. 法务、版权或片商标识

中文影片通常以中文片名为主、英文为辅；其他语言项目按发行语境确定。任何文字都必须来自Exact Copy Ledger，未确认信息标记为待确认，不得用貌似真实的姓名或小字填充。

## 2. Typography Direction

字体选择由影片类型、时代、媒介与母题共同决定：

- 粗窄无衬线：运动、战争、犯罪、工业或高压类型
- 高对比衬线、宋/明体：历史、法政、文学、关系剧情
- 克制手写：青春、私人记忆、独立电影；只承担一个主层级
- 书法动作：东方叙事；书法必须成为结构，不是装饰
- 编号或工业系统：制度、实验、隔离、档案或竞技

字图关系可使用：压、穿、嵌、隔、退、反射、遮断。片名可与人物、空间或物件发生局部遮挡，但不得牺牲准确识读。

## 3. Exact Text Rule

精确片名、日期、版权、主创和发行信息默认使用可控排版工具与已授权字体完成，不依赖图像模型直接生成。

图像模型可用于：

- 探索字形气质、笔触、材质和标题构图
- 生成不含最终文字的标题承载表面
- 在明确需要时生成原创装饰性字形草案

若使用生成式字形草案，最终必须人工核对每个字、重新矢量化或用可控文字层重建。禁止把乱码、错字或未经授权字体当作最终交付。

## 4. Layered Production Model

默认交付分为：

1. `base`：无最终文字的主视觉底图，保留标题安全区
2. `type`：可编辑的准确文字、标题锁定与信息层级
3. `composite`：底图、文字和已授权标识的合成主稿
4. `delivery`：不同渠道比例、印刷或数字导出版本
5. `layout-spec`：画布、裁切、安全区、层级、位置、颜色、混合与字体授权记录

本地合成可以进行裁切、缩放、遮罩、透明度、混合、色彩统一、可控排字和导出。它不得用后期合成悄悄改变角色身份、环境结构或剧情动作。

## 5. Prompt Separation

海报设计包不只输出一段混合Prompt，而是分别输出：

- Base-image Prompt：只描述主视觉、构图、资产、光影、色彩、质感和标题安全区；禁止最终文字、logo、桂冠和随机小字
- Typography / Layout Specification：准确文字、字体方向、字重、字距、排向、比例、位置、遮挡与可编辑层要求
- Composite / Delivery Specification：层顺序、遮罩、综合色彩、裁切、安全区、输出比例和版本
- Negative Constraints：防止错误类型、复制参考、乱码、假信息和资产漂移

这样可以降低“底图正确但文字错误”或“文字可读但画面被重绘”的耦合风险。
