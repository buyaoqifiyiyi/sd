# Poster Genre Tendencies

## Usage Rule

题材倾向只提供候选方向，不是固定公式。最终设计以影片冲突、宣传阶段、资产和Visual Direction为准。

| 题材倾向 | 候选母题与构图 | 字体与综合色彩倾向 | 常见误区 |
|---|---|---|---|
| 爱情 / 青春 / 关系 | 距离、倒影、季节、双人负空间 | 细衬线、宋/明体、少量手写；克制综合色彩 | 偶像剧糖水、婚纱广告、正面对望 |
| 运动 / 成长竞技 | 眼神、汗水、装备、倒计时；极端裁切或低机位 | 粗窄无衬线、号码；受控高反差 | 运动品牌广告、励志模板、明星拼贴 |
| 历史 / 法政 / 制度 | 长桌、证物、空椅、门洞、中轴空间 | 克制衬线、低饱和、材质色 | 普通律政剧站队、假权威信息 |
| 公路 / 家庭 / 独立电影 | 旧车、地图、旷野、等待；负空间人物 | 疏朗衬线、褪色色态 | 旅游或汽车广告、明信片风景 |
| 犯罪 / 悬疑 | 车门、档案、窥视框景、隐藏观察者 | 冷硬无衬线、切割关系；低照度 | 警匪模板、爆炸、排排站 |
| 东方历史 / 权谋 | 礼制、长阶、帷幕、棋局、中轴秩序 | 一组主书法或宋体系统，朱砂点 | 祥云龙凤堆砌、廉价国潮 |
| 东方水墨 / 哲思 | 孤舟、山路、棋子、雨幕；大留白小人物 | 单一书法动作、极简信息 | 完整山水复制、印章堆积、伪古诗墙 |
| 战争 / 严肃历史 | 泥水、站台、证件、目击、队列 | 破损粗体或窄体，综合色彩克制 | 英雄摆拍、热血口号、胜利合影 |
| 科幻 / 隔离 / 实验 | 舱门、密封箱、监控、凝结水、编号 | 工业无衬线、参数层级；冷青与警示点 | 游戏UI堆叠、廉价霓虹、怪物直给 |
| 趣味概念 / 穿越 | 时代错位、媒介侵入、标题互动 | 大胆几何或手写，两种标志色 | 综艺封面、无意义彩虹、设定不清 |
| 日常纪实 / 温柔悬疑 | 重复动作、编号、缺席者、异常物件 | 清冷衬线、自然低饱和 | 家政广告、清洁品牌感、过度温馨 |
| 群像 / 社会关系 | 站位、遮挡、尺度与视线组织阵营 | 标题退让或与关系轴锁定 | 头像等大拼贴、所有人直视镜头 |

## Stable Downgrade

如果题材信息不足：

1. 使用Cinematic Still或Singular Object作为低风险主模型。
2. 保留一个可确认的剧情母题。
3. 使用项目Visual Direction中的既有光影与综合色彩。
4. 文字层保持克制，不虚构主创、日期和奖项。
