# Poster Design Foundations

## 1. Film Judgment

海报设计前必须形成最小影片判断：

- 类型与亚类型
- 一句话核心冲突
- 目标观众与投放语境
- 情绪温度：冷/热、克制/爆裂、亲密/疏离、诗意/粗粝
- 关系模型：单人、双人、群像、人与空间、人与物件
- 宣传承诺：观众看完海报后应期待怎样的电影
- 核心意象候选：最多三个

这些判断来自已确认剧本和项目文件，不得为匹配某种海报样式新增剧情。

## 2. Poster Lane

根据宣传阶段和用途选择海报类型：

- Teaser Poster：隐藏信息，以一个母题或疑问建立记忆
- Theatrical One-sheet：同时交代片名、类型承诺、核心人物或冲突
- Character Poster：突出单一角色身份与关系位置，必须继承角色资产
- Ensemble Poster：用站位、尺度、视线和遮挡表达群体结构，禁止平铺头像
- Object / Symbol Poster：由一个关键物件承载影片含义
- Festival / Prestige Poster：克制、概念优先；只有项目确有授权事实时才可出现电影节信息
- Digital Vertical Poster：服务移动端和竖屏渠道，不等于默认9:16
- Horizontal / Platform Key Art：服务平台横版展示，必须重排而非简单裁切竖版
- Platform Cover：平台封面，服务剧集/短剧/频道在平台页面的封面位；信息密度高于电影海报，大字标题必须在缩略图尺寸可读
- Series / Episode Cover：系列/分集封面，同系列共享模板与一级母题，分集只换最小变量（集数、焦点人物或事件）
- Social Announcement Cover：定档、上线、首发等事件的社媒宣传封面，方图或竖版
- Video Thumbnail：影片相关视频的封面/缩略图，人脸或冲突可读与大字优先

封面系Lane与电影海报系共享同一管线与质检门，信息层级相反：海报以母题压缩优先，封面以秒级识别优先；封面仍从影片事实与已确认资产出发，不做与影片内容无关的通用营销风。

## 3. Delivery Format

画幅由投放渠道和交付要求决定，不固定为9:16。

常见选择：

- 2:3或接近传统One-sheet比例：正式竖版海报
- 4:5：社交平台竖版宣传
- 9:16：移动端全屏或数字竖版
- 16:9 / 1.91:1：横版平台Key Art
- 1:1：方图社媒封面
- 项目明确的印刷尺寸：按成品尺寸、出血和安全区执行

平台封面的尺寸、安全区、文字区与导出格式以渠道官方规范或用户提供的规格为准；缺失时记录待确认，不得凭记忆硬编码平台数值。若需要多渠道派生，先确定Master构图和不可裁切区，再为每个比例重新安排标题、人物与信息层级。禁止只做中心裁切。

## 4. Visual Hierarchy

海报必须在三种观看距离成立：

- 缩略图：片名或母题可识别，整体轮廓清楚
- 中距离：人物关系、类型与情绪可读
- 近距离：宣传语、日期、版权与制作信息准确

建立明确眼路：第一注意点 → 第二信息点 → 片名 → 辅助信息。每张海报只允许一个第一注意点。

## 5. Asset Priority

使用顺序：

已授权且已确认的项目资产

＞ Asset Registry

＞ Project Bible与Visual Direction

＞ 已确认剧照或概念图

＞ 为海报专门生成的新视觉

新视觉只能补足海报表达，不得静默重设计资产。
