# Poster Composition And Visual Motif

## Visual Motif Rule

一级视觉母题是海报对整部影片的视觉压缩。

每张海报：

- 只选择一个一级视觉母题
- 最多保留两个辅助线索
- 母题必须能追溯到已确认剧情、人物关系、环境或关键道具
- 母题必须同时解释“为什么是这部电影”和“为什么要这样构图”

母题不是抽象形容词。错误示例：高级、震撼、电影感。可执行母题应是可见关系，例如：空椅压住长桌中轴、两个人被玻璃反射分割、一个人物被舱门圆环吞没。

## Primary Composition Models

只选择一个主模型，最多选择一个支持模型。

1. Cinematic Still：像事情刚发生或即将发生，人物通常不直视镜头。
2. Title-led Composition：标题是主要空间结构，压、穿、嵌、隔或退入画面。
3. Singular Object：一个道具或痕迹代表主要冲突。
4. Negative-space Figure：人物占比很小，环境或空白承担命运、距离或制度压力。
5. Extreme Character Crop：眼部、侧脸、手部或局部身体成为心理入口。
6. Relational Two-shot：距离、朝向、视线、遮挡和负空间表达双人关系。
7. Ensemble Hierarchy：人物尺度、前后层级和阵营关系表达权力与秘密。
8. Spatial Order：透视、中轴、门洞、走廊、长桌、队列或重复结构组织权力。
9. Subjective / Surveillance：前景遮挡、监控边缘、车门、镜面或第一人称建立临场观看。
10. Collage / Print / Painted：拼贴、网点、丝印、绘画或错位必须直接服务剧情和时代媒介。

## Selection Logic

- 单人心理：Extreme Character Crop或Negative-space Figure
- 双人距离：Relational Two-shot或Cinematic Still
- 群体牵制：Ensemble Hierarchy
- 空间控制人：Spatial Order
- 物件代表影片：Singular Object
- 临场行动或目击：Subjective / Surveillance
- 片名本身是最强识别：Title-led Composition

支持模型只能帮助主模型，不能与主模型竞争。例如“Ensemble Hierarchy + Singular Object”可以成立；同时叠加群像、空间秩序、巨型标题、第一人称和拼贴则必须拆成不同方案。

## Spatial Construction

必须明确：

- 主体尺度、位置、朝向和边缘安全
- 前景、中景、背景的叙事职责
- 视线动线和视觉重心
- 标题可以物理落在哪个表面或负空间
- 人物脸、关键动作、道具和片名的不可遮挡区
- 上下左右安全区及渠道裁切风险

标题表面可以是天空、玻璃、墙面、地面反射、门洞、阴影、布帘、纸面或受控色块。它必须像画面结构的一部分，而不是后贴标签。
