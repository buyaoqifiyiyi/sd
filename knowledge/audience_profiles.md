## Purpose And Boundary

本文件拥有**受众剖面**：同一套叙事内核在不同受众定位下必须如何分化。

它回答一个问题：**哪些内容可以出现、以什么方式出现，以及理解难度、表演与声音尺度要调到什么程度。**

它**不拥有**：剧情事实、故事结构、媒介分化（`knowledge/medium_profiles.md`）、类型承诺（`knowledge/genre/index.md`）、时代与地域（`knowledge/period_and_place/index.md`）、美学方向、资产身份、STATE推进、任何Template字段或STATE-08最终Schema。

**它也不是分级制度本身**：各国、各平台的分级条文属于**外部事实**，必须由用户提供或引用可核对来源；本文件不虚构分级标准，也不声称"符合"任何未确认的分级体系。

它属于**条件性Knowledge**：只在受众定位已声明时加载。

## Selection And Ownership

受众由用户或已确认项目材料给定（`workflows/02_script_analysis_workflow.md`的Adaptation Target含受众项），本文件拥有该值的**值域**与三档分化规则。

| Profile ID | 受众 | 说明 |
|---|---|---|
| `preschool` | 学龄前 | 理解依赖直接因果与重复；禁忌面最窄 |
| `children_family` | 儿童 / 家庭向 | 儿童可独立理解，同时给成年观众留下层次 |
| `general` | 通用 | 未作年龄限定；按既有规则执行，不额外分化 |

判定纪律：

- **不得推定受众**：媒介是动画、类型是冒险、平台是少儿频道、画风可爱、时长很短——都不构成"这是儿童向"的依据。"动画片是给孩子看的"是最常见的一条错误推定。
- 未声明时记`Audience Profile: PENDING`，**不加载分化表**，按既有通用行为继续，也不得登记为已确认的儿童向或家庭向。
- 受众与媒介、类型、时代地域**正交**：任一轴不得覆盖另一轴。

## Suitability Layer

内容适宜性按档分化。**"不出现"与"不表现后果地出现"是两件不同的事**：

| 维度 | `preschool` | `children_family` | `general` |
|---|---|---|---|
| 暴力 | 不出现人身暴力；冲突以语言、规则或非伤害性对抗呈现 | 可暗示、可在画外发生；不得呈现伤害细节与痛苦特写 | 按类型与导演意图 |
| 恐惧 | 不使用威胁形象、突袭惊吓与不可解释的黑暗 | 恐惧必须有可理解的来源与解除路径 | 按类型 |
| 危险行为 | 不呈现可模仿的危险动作；必要的危险必须有即时、明确的负面后果 | 同上，且不得把危险行为表现为"勇敢"或"酷" | 不受此限 |
| 成瘾物 | 不出现；不得作为道具或氛围 | 不出现或只作为负面后果 | 按项目事实 |
| 亲密关系 | 限于拥抱、牵手等安全表达 | 可暗示情感关系，不呈现亲密场面 | 按项目事实 |
| 死亡 | 以缺席、告别或象征处理；不呈现尸体与临终细节 | 可呈现失去与哀悼，不呈现细节 | 按项目事实 |

**可模仿性是本层的核心判据**：受众越小，画面中"做完就有结果"的动作越容易被复制。凡出现危险动作，必须在同一段落内给出可理解的负面后果，或改为不可模仿的表达。

## Comprehension Layer

理解难度按档分化。**可理解不等于降智**：

| 维度 | `preschool` | `children_family` |
|---|---|---|
| 因果 | 单一因果链，原因与结果在短间隔内可见 | 可并行两条因果链，但每条都必须闭合 |
| 角色数量 | 主要角色少，且外观与声音差异明显 | 可多，但每个角色必须有稳定的识别点 |
| 信息速度 | 新信息之间留出反应时间；允许重复 | 允许较快，但关键信息至少出现两次 |
| 内心表达 | 必须外化为可见动作、表情或台词 | 可部分依赖台词，仍不得依赖读不到的微表情 |
| 冲突 | **必须有冲突**，只是形式与代价受限 | 同左 |

- **禁止把"儿童向"当成"没有冲突"**：冲突来自需求受阻、规则、关系与选择，不来自伤害。
- 重复在本层是**合法手段**（帮助理解与预期），但不得机械堆叠；重复必须带来变化或强化。
- 家庭向的"双层文本"通过可被成年观众读到的处境、幽默或情感层次实现，**不得靠加入儿童不宜内容来实现**。

## Performance And Sound Layer

| 维度 | `preschool` | `children_family` |
|---|---|---|
| 情绪强度 | 变化明确、信号清晰，不长期停留在高压 | 可出现较强情绪，但必须有出口 |
| 表演载体 | 大幅、可读的身体动作与表情，不依赖停顿与潜台词 | 可有停顿与潜台词，关键处仍需可见载体 |
| 声音强度 | 不使用突袭式巨响与高频尖啸 | 允许范围更大，仍不得以惊吓本身为目的 |
| 配乐 | **视频Prompt永久禁止非剧情内配乐**，儿童向不构成例外；不得用儿歌、罐头音效或氛围音乐替代声音设计 | 同左 |
| 静默 | 使用要短、要可解释；长静默会让低龄观众失去线索 | 可正常使用 |

## Shared Invariants

受众剖面**不改变**以下任何一项：

- Story First、Asset First、镜头必须服务剧情
- STATE-00至STATE-09主Pipeline、Completion Gate与推进规则
- 资产双确认、Canonical Lock与连续性纪律
- 媒介、类型、时代地域三条轴
- STATE-08最终Prompt字段与Template：不因受众新增任何字段
- 视频Prompt永久禁止非剧情内配乐
- 真实人物、真实机构、真实事件与真实品牌的Hard Stop

## Return Routing

- 受众未声明、冲突或需要确认 → 用户与已确认项目材料；不得由本文件代替用户确认
- 分级是否合规 → 外部分级事实，必须由用户提供来源
- 内容适宜性与剧情事实冲突 → Writer Owner；不得为适宜性静默改写已锁定剧本
- 理解难度与媒介表达冲突 → `knowledge/medium_profiles.md`
- 项目级美学方向 → STATE-04
- 逐镜尺度 → STATE-06

## Non-Applicable Rule

- 受众为`PENDING`：不加载分化表，按既有通用行为继续；不得登记为已确认的儿童向或家庭向。
- 本文件不适用于Poster、MUSIC、AUDIO等辅助模块的既有边界；海报的渠道与受众差异由`knowledge/poster_design/index.md`拥有。
- 本文件不创建STATE、不新增Template字段、不改变任何Model Adapter能力与能力数值。

## Validator-Checkable Invariants

- 三档ID固定为`preschool`、`children_family`、`general`，不得改名或新增同义档。
- 三张分层表（Suitability / Comprehension / Performance And Sound Layer）必须同时存在。
- "不得推定受众"与"动画片不等于儿童向"的声明必须存在。
- 可模仿性判据必须存在。
- 分级条文属外部事实、不得虚构的声明必须存在。
- 不改变STATE-08 Schema、不新增Template字段的声明必须存在。
