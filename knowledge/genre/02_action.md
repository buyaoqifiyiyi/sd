# Genre Profile — Action｜动作 / 冒险 / 追逐

Profile ID：`action`
承诺轴：身体能力与代价的可见兑现
Owner：`knowledge/genre/index.md`拥有共享Schema、加载规则、正交声明、反公式边界与共享不变量；本文件只写本类型的专属内容。

## Genre Promise｜类型承诺

观众被承诺看到**身体在真实限制下完成可见的事**，并承担由此产生的代价。承诺的对象是**过程的可读性**，不是破坏规模。

承诺成立的判据：观众能说出"谁在什么限制下做了什么，代价是什么"。说不清限制的动作只是运动。

最常见的落空：把动作等同于快。切得越碎、动得越快，观众越读不出因果；**读不出因果的段落，观众只会记得吵**。

## Information Discipline｜信息与悬念纪律

- 动作段的信息是**空间与能力**，不是秘密：谁在哪、距离多近、手上有什么、身体还能做什么。这些必须在动作开始前建立。
- 规则一旦建立必须守恒：角色在前面展示过的能力、伤情、装备与限制，在同一段动作内不得凭空扩大或消失。
- 代价必须**可见**：喘息、失衡、抓握不住、动作变小、反应变慢。没有代价的动作不构成承诺兑现。
- 观众必须在每个动作节拍开始时知道**目标是什么**；目标不清楚时，再好的动作设计也只被读成混乱。
- 不得靠"对手忽然变弱"或"角色忽然会做没展示过的事"解决局面。

## Camera Tendencies｜镜头倾向

| 倾向 | 成立条件 | 反用场景 |
|---|---|---|
| 保持空间连续：让观众始终知道双方相对位置 | 动作发生在同一可辨认空间内 | 空间本身混乱且无法在一次剪辑内讲清 |
| 用较长镜头记录完整动作单元 | 动作单元本身可执行、可读 | 动作细节无法在一次生成内稳定完成 |
| 在冲击点切入特写或近景 | 冲击的因果已被前一个镜头建立 | 因果未建立，切入只会变成视觉噪音 |
| 跟随（Tracking / 侧向跟拍）保留身体位移 | 位移是承诺的一部分 | 位移无意义，或空间关系会被跟丢 |
| 固定机位承接大范围运动 | 运动足够明显、构图能容纳它 | 运动幅度小，固定机位会吞掉动作 |

**禁止**：用无因果的抖动、快切与升格掩盖动作设计缺失。**速度不是动作，因果才是。**

## Performance And Reaction｜表演与反应

- 动作段中表演的核心是**决策**：出手前的判断、命中后的反应、代价出现时的调整。三者必须留在画面上。
- 反应顺序：**接触 → 身体反馈 → 表情**。表情先到会让冲击失去重量。
- 强度尺度服从代价：轻伤不演出重伤，力竭不演出崩溃。受伤后的动作幅度必须小于受伤前。
- 最小充分载体：一次换手、一次重心调整、一次呼吸变粗，比大幅表演更能证明"他还能打，但不容易"。
- 群体动作中**只让一到两个人承担可读的反应**，其余人保持功能性运动。

## Sound And Silence｜声音与留白

- 动作的注意力靠**声音指向**：接触声、材质声、呼吸、脚步、衣料摩擦。声音告诉观众"该看哪里"。
- 声音必须与材质一致（金属、木、玻璃、骨、布）——材质错配会让冲击失去可信度。
- 静默用于**动作前的一拍**：底噪撤掉、只留呼吸，观众会自动预期下一个动作。
- **永久禁止非剧情内配乐、氛围音乐与主题音乐进入视频Prompt**。不要用"激烈音乐"代替声音设计；动作段尤其容易被写成靠音乐推。
- 呼吸是动作段最被低估的节奏器：呼吸变粗、变慢或停住，比任何音效都更能标出代价。

## Rhythm And Cutting｜节奏与剪辑

- 节奏的单位是**动作单元**（一次完整的攻防、一次位移、一次抓取），不是秒数。
- 顺序固定为**建立空间 → 执行 → 后果**。三段缺一，动作就变成片段集合。
- 镜头长度服从可读性：**先长后短**（建立用长，冲击用短），不要在空间未建立时使用短切。
- 切点依据是因果：切在动作单元的结束或反转处，不切在运动中间（除非刻意制造断裂，且断裂必须在下一镜被回收）。
- **不预设节拍模型**：不得出现"每N秒一个爆点"之类要求。

## Model Execution Notes｜模型执行提示

- 当前视频模型对**连续复杂肢体接触**的稳定性有限：把一段连续打斗拆成多个**单一动作单元**的Clip，每个Clip只安排一次可命名的动作（推、拽、挡、跌），比要求"完整打出成套动作"更可能存活。
- 空间关系必须写进Prompt（谁在左、谁在右、距离、朝向）；模型不会从上下文补出站位。
- 避免在同一Clip内同时要求快速位移 + 精细手部 + 表情变化：三者相争时通常全部劣化。按该Clip的承诺取舍。
- 破坏与群体场面最容易崩：优先保留**人的动作与代价**，把规模降级为可见的少量元素（碎片、尘土、被撞开的物件）。
- 模型能力、时长窗口与参考容量**以当前`adapters/`对应Adapter为唯一真源**，本文件不写数值。

## Pairs And Tensions｜组合与张力

- 与`crime`：程序与证据提供**为什么打**，本类型提供**怎么打**。先保因果，再保动作。
- 与`comedy`：喜剧要求观众看清落差，动作要求速度；两者同时要快会互相削弱。取舍：把喜剧节拍放在动作**之间**，不放在动作**之中**。
- 与`mystery_thriller`：动作是本类型承诺的兑现，却是悬疑承诺的终止；组合时把动作放在揭示之前或之后，不夹在中间。

## When Not To Apply｜反公式边界与失败信号

**不适用**：

- 剧本中没有身体性冲突，只有对话与关系——加载本类型会凭空制造打斗。
- 用户明确要求克制、纪实或写实后果（例如事故、劳动、体能题材）——此时动作应服从"代价可读"，不得套用娱乐化的动作节拍。
- 类型未登记，或只有"打斗""爽"这类标签而无剧本支撑时，不得据此加载。

**必须让位**：Writer的因果与人物逻辑、Director的观众体验取舍、已确认Blocking与资产事实、动作可行性（`knowledge/action_previs.md`拥有的A1/A2/A3与Kinetic Chain）。

**失败信号（可观察）**：

- 观众只能描述"很乱、很快"，说不出谁在什么限制下做了什么。
- 动作段的规则前后不一致（能力、伤情、装备忽然变化）。
- 代价不可见：动作做完后角色状态与之前没有区别。
- 靠切碎与抖动维持强度，没有可读的动作单元。
- 群体场面压过主角动作，承诺的对象（身体与代价）被规模淹没。
