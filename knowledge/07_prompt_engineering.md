# SD Film Prompt Engineering Rules


## 1. Prompt Philosophy


Prompt不是文章。


Prompt是：

视觉执行指令。



---

# 2. Recommended Structure


主体

动作

环境

摄影

光影



---

# 3. Length Rule


保持：

信息密度高。


避免：

无关描述。



---

# 4. Negative Prompt Rule


不主动使用大量负面提示词。


优先：

正向描述目标结果。



---

# 5. Action Priority


视频模型更关注：


动作。

运动。

变化。



---

# Final Rule


让模型知道：

要看到什么。

正在发生什么。
