# Dialogue Performance

## Principle

对白不是只有口型。它包含说话前的意图、说话过程、倾听、被影响后的反应和沉默。

---

## Dialogue Beat Map

为需要对白的镜头确认：

- Speaker
- Listener
- Line Intent
- Vocal Energy
- Eye Target
- Pre-line Action
- Speaking Action
- Listener Reaction
- Post-line Hold
- Interruption / Overlap（如有）

## Executable Beat Formula

每个关键对白节拍按以下闭环编译，轻量过渡可合并字段，情绪转折、反转、产品操作和抢话必须逐项落地：

`时间码 / 镜头 → 开始状态与话语权 → 说话目标 → 原句＋主触发词 → 触发延迟 → 可见反应（面部 / 目光 / 身体；Onset → Apex → Offset） → 声音 / 呼吸 / 重音 / 停顿 / 口型 → 话轮关系与听者信息延迟 → 结束状态＋禁止提前反应`

默认八维核对表为：

1. 时间段与镜头；
2. 开始状态与当前话语权；
3. 人物目的；
4. 情绪从何处转向何处；
5. 台词中的主触发词与触发延迟；
6. 面部、目光、身体、手与距离（Onset → Apex → Offset；AU 仅作内部校准）；
7. 声音、呼吸、重音、停顿、口型、启动失败或改口；
8. 话轮关系、听者信息延迟、结束状态与禁止提前反应。

**时间码只约束执行顺序，不替代动作证据。** 反应必须在触发词被听见后出现；若发生重叠，写清入口、相对时长和音量关系，不把两句台词排成机械先后。

轻量节拍可合并字段，但不能删除“开始状态”“触发延迟”“话轮/听者信息延迟”或“结束状态”中的控制语义。

## Lip-sync Capacity

对白长度必须与镜头容量和人物动作相容。

优先：

- 一次只让一个主要说话者承担清晰口型
- 保留说话前后短暂稳定面部窗口
- 避免说话同时快速转头、遮脸、吞咽、大幅奔跑或复杂打斗
- 多句长对白拆分为可理解的表演段，而不是压缩口型速度

如对白无法在已确认镜头内自然完成：

返回STATE-06调整镜头容量，不在STATE-08强行加速。

---

## Listening Performance

非说话者必须有受控反应，但不得每一句都做夸张点头或抢夺视觉重点。

可使用：

- 视线保持或移开
- 呼吸改变
- 轻微重心变化
- 手部动作停止
- 延迟反应
- 说话结束后的短暂停顿

---

## Trigger Word｜触发词

每个节拍除了“已确认刺激”，还要落到**哪个字词让表演转向**。刺激是剧作层的（她意识到自己没被看见），触发词是执行层的（他说出了“每次都说累”）。

- 触发词必须是已确认台词里的真实字词，不得新增对白来制造触发。
- 触发词决定节拍切点：表演变化从该词被听见的那一刻开始，而不是从这一句台词开始。
- 一个节拍通常只有一个主触发词；一句话里多个词都可能触发时，只保留最先起作用的那个。
- 触发词之后的可见变化要有可指认的先后，便于逐点核对。

```text
触发：听到“……”后约……，人物的注意与面部开始转向该信息。
```

秒数只用于内部核对触发位置，最终写法按`facial_action_language.md`的`Prompt Serialization`落成可见动作。

## Speech Disfluency｜言语不流畅

不流畅不是“演得自然一点”的形容词，而是四种可分别执行的现象。先确认人物的心理处境，再选择对应形态；不得四种混用。

| 心理处境 | 可执行形态 | 落地要求 |
|---|---|---|
| 羞耻、内疚、不敢承认 | 启动失败 | 口型已准备但未出声，一次失败吸气后才开口 |
| 急于自证或纠正对方 | 重复与重音 | 同一词组重复，重音落在需要被否认的那个词上 |
| 突然听懂残酷事实 | 沉默 + 一次失败吸气 | 先停止一切口部动作，吸到一半就断开 |
| 隐藏真实意图 | 自我修正 | 说到一半改口，改口前后语义指向不同 |

**口吃落点**：口吃应落在人物最难面对的那个词上——对方的名字、`你` / `我`、`但是`，或触发内疚的关键词。不得平均分布在整句里，否则读起来像喜剧节奏。

**同步要求**：启动失败必须同时出现在声音、呼吸与口型上。只写“说不出来”而口型照常完整，等于没做。

---

## Turn-Taking｜话轮

先决定谁拥有话语权、谁在准备接话、谁抢入、谁最后退让，再写台词。人物不是轮流念稿。

**重叠写法**：需要重叠时写清入口、相对时长与音量关系，而不是绝对秒数：

```text
新说话人在上一句尾词的口型尚未结束时进入；短暂重叠；
新说话人起音低于被抢话者；被抢话者不突然静音，尾音自然收住。
```

- 抢话适合“无法继续容忍这句话”的时刻；听到需要消化的秘密时，通常应沉默而不是抢话。
- 被抢话者不得为了给新说话人让位而立刻闭口；声音要有自然的收束形态。
- 重叠只在剧情明确且模型/后期流程能够支持时使用；它是高风险项，不因写得更细而降低风险。

**听者信息延迟**：听者只在触发词之后才反应。同理，反馈不得早于发声。

```text
听者只在听到“……”后出现……；此前保持原任务与原有视线。
```

每个节拍用`Trigger → 反应 → 是否重叠 → 谁掌握话语权`四件事核对一次，缺任一项即节拍未设计完。
