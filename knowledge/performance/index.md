# Performance Knowledge Index

## Purpose

本目录把抽象情绪转换为演员可观察、视频模型可执行的行为。

适用于：

- STATE-04 项目级表演尺度
- STATE-06 逐镜表演目标与节拍
- STATE-07 表演关键姿态预演
- STATE-08 具体表演执行与连续性

它不定义角色资产，不改写剧情，也不定义最终Prompt字段。

人物表情不是情绪标签的插图。任何适用表演必须以已确认刺激、注意目标、局部面部动作、呼吸/身体反应、行动选择和稳定结束状态成立。

---

## Routing

- micro_expression.md：Performance Progression Engine、PL1/PL2/PL3载体负荷、微表情、身体表演、强度和连续性基础
- facial_action_language.md：FACS启发的眉眼、眼睑、嘴角、下颌、注视和生理结果语言
- emotion_dynamics.md：刺激、评估、冲动、控制/泄漏、混合情绪、身体状态与恢复曲线
- expression_patterns.md：36个去重后的条件性表演模式
- expression_image_source_coverage.md：8张附件候选内容、归并结果与专业校正
- dialogue_performance.md：对白节拍、口型容量、倾听和反应
- group_reaction.md：双人及多人反应顺序、空间与注意力

只加载当前镜头需要的文件。

## Boundary

- Character Asset拥有天生脸型、五官、年龄、妆容和个体不对称。
- Performance拥有随刺激发生的可见动作与时间变化。
- Action / Blocking拥有手势、走位、接触和道具动作。
- Lighting / Color拥有受光、明暗和色调，不用冷暖替代表演。
- Sound拥有台词、哭笑发声与声音空间；Performance只定义发声前后的身体行为。
- STATE-08仍由`templates/10_video_prompt.md`拥有最终字段；PEX和AU不得成为最终栏目。
