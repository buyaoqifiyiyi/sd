# Micro-expression And Physical Performance

## Observable Performance Rule

禁止只写：悲伤、紧张、惊讶、感动、愤怒。

必须将情绪转换为少量可见信号：

- 视线目标与转移速度
- 眨眼频率或短暂停眼
- 呼吸深浅与节奏
- 下颌、嘴角、眉间的轻微变化
- 肩颈张力
- 手指和握力
- 重心、步幅、身体距离
- 动作前停顿与动作后余韵

优先读取`facial_action_language.md`确定面部区域、注视和口部动作；复杂、压抑或混合情绪读取`emotion_dynamics.md`。来源中的情绪名称可在`expression_patterns.md`中归并，但模式名不得代替动作过程。

## Performance Beat

每个表演变化采用：

Baseline

↓

Stimulus

↓

Attention Shift / Appraisal

↓

Internal Processing

↓

Control / Leakage / Visible Response

↓

Action Choice / Settled State

单个短镜头优先一个主要情绪转折和少量辅助信号。

## Intensity Scale

### Restrained

微小视线、呼吸、姿态变化；适合隐忍、观察、尚未确认的情绪。

### Open

表情和身体反应清晰但自然；适合明确交流和情绪表达。

### Heightened

大幅动作或强烈面部反应；只能由剧本、类型或情节强度授权。

禁止默认把所有高潮写成大哭、瞪眼、尖叫或猛烈动作。

强度增加时仍须保持动作先后、口型容量、呼吸和结束后果；不得通过同时堆叠瞪眼、张嘴、握拳、后退、落泪制造“强烈”。

## Expression Is Conditional

- 同一情绪可以有多种表演策略，同一面部动作也可能来自不同情境。
- 瞳孔、脸红、泪水、出汗和颤抖只在条件成立时使用，不作为固定情绪按钮。
- “面无表情”仍要说明视线目标、呼吸、姿态和反应延迟，不能冻结人物。
- 微表情是短暂泄漏，出现后必须被控制、发展或回落，不能整镜保持。
- 表演的最小单位是变化：开始如何、什么触发、哪里先变、人物做何选择、最后停在哪里。

---

## Continuity

下一镜必须继承：

- 情绪强度
- 呼吸状态
- 视线目标
- 身体张力
- 动作完成阶段
- 与他人的距离
- 眼眶湿润/泪痕、红肿、颤抖或其他仍然可见的身体后果
- 公开状态与内部泄漏是否已被重新控制

除非有明确刺激或叙事断点，否则不得情绪重置。
