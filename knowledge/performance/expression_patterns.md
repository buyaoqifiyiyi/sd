# Canonical Expression Performance Patterns

这些模式用于内部选择和去重。PEX编号和模式名称不得直接代替最终Prompt；每次必须结合角色基线、刺激、视线目标、身体动作、强度与结束状态。别名只表示来源词的归并，不表示固定心理诊断。

| ID | 规范表演模式 | 来源别名示例 | 可观察执行语义 | 关键限制 |
|---|---|---|---|---|
| PEX-01 | 真诚轻笑 | 自然微笑、元气微笑、温柔浅笑、天真无邪 | 视线停在明确对象，嘴角双侧轻提，面颊与眼周小幅参与，呼吸和肩颈保持松弛 | “天真”是角色/情境判断；不固定露齿数 |
| PEX-02 | 开放欢笑 | 大笑、灿烂大笑 | 面颊抬起、眼裂自然收窄，下颌随笑声释放，呼气带动头颈或躯干后再回稳 | 必须与声音和呼吸同步，不持续僵在张口状态 |
| PEX-03 | 玩味逗弄 | 俏皮眨眼、调皮眨眼、戏谑玩味、狡黠坏笑、坏笑/邪笑 | 先确认对方注意，单侧嘴角或眉峰轻动，可有一次有动机眨眼，头部轻偏后观察回应 | 眨眼不是普适情绪符号；避免偶像式持续挑眉 |
| PEX-04 | 社交/策略性微笑 | 假笑、礼貌笑、故作友好 | 嘴角维持有限弧度，眼周参与较少，视线与呼吸出现一处不一致泄漏，随后恢复控制 | 必须说明社交目的，不等同恶意 |
| PEX-05 | 羞怯与自我意识 | 害羞笑、羞涩低头、心动羞涩、尴尬抠手 | 视线短暂相遇后移开，头颈微收，嘴角想抬又压住，可出现手指自我触碰或重心后移 | 脸红仅作条件性结果；尴尬、羞怯、吸引需由情境区分 |
| PEX-06 | 亲近与温柔关注 | 甜蜜对视、宠溺笑、温柔注视、温柔安抚、宠溺摸头、痴痴凝望 | 身体和视线稳定朝向对象，眼睑与眉间放松，嘴角轻提，动作速度放缓并留出对方反应空间 | 摸头是动作且需关系授权；“宠溺”不能越权建立关系 |
| PEX-07 | 满意与自得 | 暗爽得意、得意笑、腹黑笑 | 信息确认后嘴角短暂上提，可有轻微抬下巴或视线回看，胸肩保持受控而非夸张扩张 | “腹黑”是人物解释；用可见克制表现，不写性格结论 |
| PEX-08 | 苦笑与无奈 | 苦笑/无奈笑、苦笑 | 嘴角试图上提但很快失去力量，眉眼保留疲惫或失落，吐气后视线移开 | 不把两种完整表情叠加；用不一致和回落表现 |
| PEX-09 | 期待与兴趣 | 期待睁眼、温柔关注、好奇期待 | 注意先转向目标，眼睑略抬，头或上身轻微前倾，呼吸暂缓，等待结果后松弛或转变 | 不把瞳孔明亮当动作；结果必须进入下一状态 |
| PEX-10 | 突发定向惊讶 | 惊讶瞪眼、瞳孔放大、瞳孔地震、意外挑眉 | 眼睑和眉部短促抬起，头眼迅速定向，嘴唇可微分，随后立即进入确认与次级反应 | 惊讶不能整镜冻结；瞳孔词降级为眼睑/定向变化 |
| PEX-11 | 错愕与难以置信 | 错愕失神、难以置信 | 先定向目标，动作短暂停顿，眼睛复核信息，嘴唇轻分后收住，头部出现很小的否认或后撤 | 必须说明人物为何不信，不能只用空洞大眼 |
| PEX-12 | 困惑与迟疑 | 茫然发呆、忘忐不安中的犹疑、轻微困惑 | 视线在两个信息点之间切换，眉部可轻微不对称，头部略偏，原动作减速或停在中途 | 区分困惑与失神；不要无限循环扫视 |
| PEX-13 | 怀疑与警戒 | 怀疑警惕、警惕戒备 | 视线缩窄并锁定潜在威胁，头部微退但身体保留行动准备，呼吸减小，手部靠近支点或保持待发 | 不自动加武器或敌人；光线不随警惕改变 |
| PEX-14 | 急性惊吓与退避 | 惊恐后退、震惊捂嘴 | 刺激后先快速定向，吸气中断，肩颈抬起或重心后撤，手部保护动作随后出现 | 后退和捂嘴需空间/动作容量；避免所有通道同时最大化 |
| PEX-15 | 持续恐惧/冻结 | 战栗恐惧、毛骨悚然、胆怯缩肩 | 视线固定威胁或短促扫描，呼吸浅而受限，肩颈与手指出现局部张力，身体选择冻结或缓慢退让 | 颤抖指定部位；冻结不等于模型完全静止 |
| PEX-16 | 惊吓后的余震 | 惊吓后怕 | 威胁解除后先复核环境，再长吐气或吞咽，肩部缓慢落下，手仍短暂保持防御位置 | 体现恢复过程，不瞬间恢复正常 |
| PEX-17 | 焦虑与失措 | 忐忑不安、慌张无措、忘忐不安 | 视线难以稳定，呼吸加快或被压住，手指寻找重复性小动作，重心频繁但有限调整 | 限制重复动作次数，避免全身乱动和表情漂移 |
| PEX-18 | 心虚/羞愧回避 | 心虚躲闪、故意回避、羞愧 | 被注视后视线回避又短暂复看，嘴唇压住，肩胸略收，可停止或隐藏手部动作 | 心虚必须有剧情依据，不凭视线回避判定撒谎 |
| PEX-19 | 克制悲伤 | 悲伤泛红、隐忍不哭、失落低头、委屈瘪嘴 | 眼周与下巴出现有限张力，视线下移或停在对象上，嘴角失去力量，呼吸被压住后缓慢释放 | 不默认落泪；委屈需人物关系和刺激支持 |
| PEX-20 | 泪意形成 | 泪水滑落、隐忍落泪 | 眼眶先湿润，眨眼受抑或一次缓慢眨眼后泪液聚集，随后一滴沿稳定路径滑落，人物仍试图维持动作 | 泪水与妆容、湿度、镜头连续；禁止泪滴瞬移或双眼同步复制 |
| PEX-21 | 安静哭泣 | 默默流泪、小声抽泣、低声啜泣、啜泣 | 泪液持续但面部动作受控，呼吸间歇被打断，肩部或下颌有小幅节律，声音压低 | 先排出口型、吸气与抽泣先后；避免循环抖动 |
| PEX-22 | 开放性崩溃哭泣 | 放声大哭、崩溃大哭、绝望闭眼 | 控制失败后下颌释放、发声和呼吸断裂，肩胸参与，手部寻找支撑，高潮后进入疲惫或余泣状态 | 必须由剧情授权；不是“张嘴+流水”静态表情 |
| PEX-23 | 麻木与绝望失联 | 空洞麻木、绝望失神 | 视线失去明确目标或固定在无关点，眨眼和反应延迟，嘴部放松，身体动作减少但保留呼吸 | 不把麻木写成无生命冻结；与疲惫/困惑区分 |
| PEX-24 | 记忆触发的怅然 | 触景生情、怀念怅然 | 外部对象触发视线停顿，注意逐渐转向记忆，嘴角或眉眼出现很轻的矛盾变化，吐气后重新看回现实 | 不能凭“怀念”新增闪回；是否剪入回忆由剧情/剪辑决定 |
| PEX-25 | 烦躁与不耐 | 烦躁不耐、生闷气 | 眉眼短促收紧，呼气变重或动作节奏变硬，视线避开交流对象，手部停止后改做一个受控小动作 | 不自动升级为愤怒；鼻翼变化不是必选项 |
| PEX-26 | 受控愠怒 | 眉头紧锁、阴沉脸、愠怒皱眉 | 眉部下压靠拢，下颌或嘴唇收紧，视线稳定对准目标，呼吸受控，姿态不夸张扩大 | 区分决心和愤怒；必须有对象和控制策略 |
| PEX-27 | 压抑怒意 | 憋屈忍怒、故作镇定中的怒意 | 人物维持中性或礼貌表面，下颌、嘴唇、握力或呼吸短暂泄漏，随后压低声音或移开视线 | 不同时完整微笑与完整怒脸；用一处泄漏表达 |
| PEX-28 | 愤怒升级与爆发 | 咬牙切齿、暴怒前兆、爆发怒吼、暴躁怒吼、愤怒瞪眼 | 受控张力逐步增加，呼吸和音量改变，身体明确选择逼近/喊叫/停止之一，爆发后保留喘息与姿态后果 | 剧情授权后使用；咬牙、怒吼、握拳不能无序同时发生 |
| PEX-29 | 轻蔑与不屑 | 轻蔑不屑、冷笑嘲讽、不屑撇嘴、轻蔑斜睨、冷眼相视 | 单侧嘴角或面颊轻微收紧，视线短暂评估后移开，可伴很小的抬下巴 | 不把“冷色调”当表演；轻蔑是关系判断，需情境依据 |
| PEX-30 | 嫉妒与怨怼 | 妒忌扭曲、隐性嫉妒 | 注意在人物与争夺对象之间切换，嘴唇压紧或单侧收紧，身体保持克制但距离选择暴露占有/退避倾向 | 嫉妒不能由固定脸型识别；必须有关系和目标依据 |
| PEX-31 | 决心与专注 | 坚定眼神、决绝皱眉 | 视线稳定在目标，眉眼保持清晰而非凶狠，呼吸收稳，下颌和重心确定，随后执行明确行动 | 不自动使用硬光；与愤怒区别在控制、目标与动作选择 |
| PEX-32 | 倔强与抗拒 | 倔强不服输、轻蔑式抗拒 | 身体保持原位或重心前置，嘴唇压成直线，视线不退让但可能带轻微动摇，动作选择是拒绝或继续 | 不把抬下巴固定为反抗；避免角色无依据挑衅 |
| PEX-33 | 冷淡与疏离 | 高冷面无表情、疏离冷漠、冷眼相视 | 面部动作减少，视线短暂接触后离开，身体不朝对方开放，回应延迟或简短 | “面无表情”仍需视线、呼吸与姿态；不是冻结脸 |
| PEX-34 | 疲惫与困倦 | 慵懒淡漠、困倦打哈欠、疲惫耷拉眼、困倦眯眼、慵懒挑眉、慵懒犯困 | 眼睑沉重、眨眼变慢，头颈与肩部支撑减弱，动作启动延迟；打哈欠时先吸气再张口回落 | 属于身体状态；不依赖暖光或低饱和调色 |
| PEX-35 | 释然与恢复 | 释然释怀、满足喟叹 | 刺激解除或结果确认后吐气延长，肩颈落下，眉眼和手部张力逐步释放，视线重新稳定 | 必须从前一张力状态过渡，不凭空“全身放松” |
| PEX-36 | 伪装与短暂泄漏 | 故作镇定、假笑、隐忍、公开状态与真实反应冲突 | 明确公开状态，选择一个眉眼/嘴角/呼吸/手部泄漏，短暂出现后被压回或导致控制失败 | 不输出两个完整冲突表情；结尾记录控制是否成功 |

## Selection Rule

先选剧情需要的表演功能，再用一个模式作为主结构；需要复杂情绪时最多增加一个支持模式，并说明先后或公开/内部通道分工。任何模式都可以因角色基线、文化习惯、年龄、身体状态和人物关系而改变，不作为心理诊断。
