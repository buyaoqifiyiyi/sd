# Atom 3 — Period Consistency｜时代一致性与错置

## Purpose And Owner

本原子拥有**时代与地域基线在项目内的投影与跨镜一致性**：基线一次锁定、向资产与声音的投影方式，以及**时代错置（anachronism）**的判据。

边界：不拥有时代与地域的**内容**（`knowledge/period_and_place/01_era_visibility.md`与`02_place_and_culture.md`）；不拥有资产身份与形制仲裁（对应资产owner与`references/asset_lock_contract.md`）；不拥有美学方向（STATE-04）；不拥有连续性判据的一般规则（`knowledge/quality/continuity_pair_qa.md`）——本原子只提供其中**时代维度**的判据。

## Visible Constraints｜可见约束

| 投影对象 | 时代基线如何进入 | 写进哪个既有字段 |
|---|---|---|
| CHAR 角色 | 服装形制、发型、材料与工艺进入**不可变项**；同一角色跨镜不得回退到其他时代形制 | 角色资产`Immutable Traits`、`服装结构、材质与配色` |
| ENV 环境 | 建筑形制、街道元素、招牌与标识、**照明条件**进入环境规范 | `环境风格`、`Architecture / Space`、`环境一致性` |
| PROP 道具 | 器物、工具、容器、包装的技术边界与工艺水平 | 资产定义、`PROP`描述、状态变体 |
| 光线 | 该时代可用的光源决定了光源类型、色温倾向与夜间明暗结构 | `光线` |
| 声音 | 该时代可用的技术与环境底噪：无电时代没有电流声、引擎声与城市连续底噪 | `声音`、`环境一致性` |
| 反向提示词 | 只归位当前Clip真实高风险的时代错置项，不扩成通用清单 | 内容相关部分写在所属阶段字段；真正跨阶段的残余收束到末尾唯一`反向提示词` |

**基线一次锁定**：时代与地域基线在 STATE-04 与 Project Bible 的 World Building 区域一次确认，之后 STATE-05 / 06 / 07 / 08 只继承与投影，不逐镜重新解释。改变时代基线属于项目事实变更，按`references/artifact_revision_contract.md`出新Revision。

## Conditions And Anti-Use｜成立条件与反用

- **一致性检查的对象是"错误"，不是"风格"**：相邻镜头之间的时代细节不必逐件相同（可以是不同房间、不同器物），但**不得出现时代不允许的类别**。这与`knowledge/quality/continuity_pair_qa.md`的一般连续性判据互补：那条管"是否延续"，本原子管"是否越界"。
- **资产锁定必须覆盖时代不可变项**：角色资产的`Immutable Traits`若不含时代相关形制，跨镜回退就没有判据；发现缺失时返回STATE-03补齐，不在Prompt阶段临时补救。
- **返修隔离**：发现时代错置时只修受影响资产或Clip，并检查同一时代基线是否在别处被同样写错；不得因为一次错置重做全部资产。
- **不得用"风格化"豁免事实错误**：风格化可以改变**呈现方式**（画法、质感、色彩），不改变**技术类别**。
- **不得把一致性做成冻结**：同一时代内部的差异（新旧、贫富、城乡）是真实存在的，不要求所有场景形态一致。

## Uncertainty Marking｜不确定项标注

- 时代基线中标记为**推断**的条目，跨镜一致性检查按推断处理：允许后续获得确认后修正，但同一项目内**不得一半按推断、一半按已确认**而互不告知。
- 不可确认项（年号、真实机构、型号）不得进入`Immutable Traits`或`环境一致性`这类当作事实的字段；需要时以降级后的等价物形式写入。
- 时代错置的判定只使用已确认或已标注的约束；两条推断冲突时不上报为错误，改为记录待确认项。

## Failure Signals｜失败信号

- 同一角色或环境在不同Clip之间出现时代形制回退或漂移。
- 现代物件、字体、标识或包装混入已确认时代。
- 夜景出现该时代不可用的光源或均匀照明；无电时代出现电流声、引擎声或连续城市底噪。
- `Immutable Traits`缺少时代相关不可变项，导致每次生成都要重新赌一次。
- 反向提示词里堆了与该Clip无关的时代清单，挤掉主体、动作与空间的权重。
- 用"风格化"解释技术类别错误；或反过来把一致性做成冻结，抹掉同一时代内部的真实差异。
