# Canonical Lighting Source Patterns

模式ID只供内部选择与校验，最终视频Prompt不得输出ID或只写模式名。情绪用途是条件性建议，不得转化为剧情事实。

| ID | 规范名称 | 分类 | 可执行光影语义 | 协同与风险 |
|---|---|---|---|---|
| LGT-01 | 黄金时刻斜射日光 | 自然时段光 | 低角度暖色太阳光从已确认方向斜射，形成较长阴影、温暖轮廓与随距离稳定衰减；保护天空和皮肤高光。 | 时间窗、太阳方位与跨镜色温连续；浅景深另交Lens处理。 |
| LGT-02 | 侧后逆光与轮廓分离 | 方向/布光 | 已确认主光位于人物侧后方，在发丝、肩部或物体边缘形成连续轮廓，面部暗侧保留必要细节。 | 摄影机越轴或人物转身会改变受光；不能凭空补出另一侧强光。 |
| LGT-03 | 伦勃朗式单侧主光 | 人像布光 | 单侧约45度、略高于视线的主光在远侧面颊留下小型三角亮区，暗部受控且眼神仍可读。 | 需匹配脸部朝向与机位；低调风格是光比策略，不等同此模式。 |
| LGT-04 | 有动机窗光 | 环境实用光 | 日光由已确认窗户进入，方向、软硬和窗格/百叶遮挡与建筑结构一致，在人物和室内表面形成可追踪受光区。 | 窗的位置、时间、天气与人物移动共同决定变化；禁止光穿过实墙。 |
| LGT-05 | 霓虹实用光与湿面反射 | 环境实用光 | 已确认霓虹招牌产生局部高饱和色光，在面部、衣物和湿地形成方向一致的双色或多色反射，保留主次光关系。 | 颜色必须绑定具体招牌位置；控制肤色污染、曝光闪变和反射漂移。 |
| LGT-06 | 烛光多点暖源 | 动态实用光 | 一支或多支已确认蜡烛形成低照度暖色近距离光，亮度随距离快速衰减，阴影轻微连续跳动。 | 道具状态、火焰FX与火焰声协同；禁止随机全画面明暗脉冲。 |
| LGT-07 | 顶部集中光 | 方向/布光 | 光源从人物正上方或上方偏侧落下，突出头肩上缘并在眼窝、鼻下形成较深阴影，背景保持较暗。 | 需说明人物面部是否仍可读；顶光位置与舞台/建筑光源相符。 |
| LGT-08 | 阴天/柔化散射光 | 光质 | 天空或大面积柔化源提供低反差、软阴影的包围式光照，肤色和材质过渡自然。 | 散射是光质而非独立光源；天气、雾量和方向信息仍需保留。 |
| LGT-09 | 参与介质体积光束 | 光学介质 | 定向光穿过雾、烟或尘形成可见光束和层次，光束源点、方向、遮挡和介质密度相互一致。 | 介质由Environment/FX确认；避免无介质光柱、光束穿墙和过曝白雾。 |
| LGT-10 | 低调选择性照明 | 明暗风格 | 以已确认光源只照亮叙事关键面部或物体，大面积暗部保持干净层次与稳定黑位，形成高光比。 | 必须说明可读区域；避免黑位压死、眼睛全失和随机曝光泵动。 |
| LGT-11 | 反射/跳光柔和补光 | 补光机制 | 主光之外由墙面、地面或已确认反射面提供低强度柔和补光，减轻暗侧而不消除主光方向。 | 最终Prompt优先写可见补光效果，不虚构反光板器材；反射色受材质影响。 |
| LGT-12 | 舞台聚光与烟雾光柱 | 环境实用光 | 单一聚光灯从舞台上方或指定方向集中照亮表演区域，背景暗，若有烟雾则显出受控光柱。 | 聚光范围、人物走位和舞台资产一致；烟雾须有来源，构图居中不是灯光必然。 |
| LGT-13 | 月光/夜空冷侧光 | 自然夜光 | 来自已确认月亮或夜空方向的低强度冷色侧光/轮廓光，深蓝暗部保留夜间层次和有限反射。 | 不把夜景照成白昼；月向、云层、雾和跨镜阴影方向连续。 |
| LGT-14 | 油灯近距暖源 | 动态实用光 | 已确认油灯作为局部暖色近距光源，琥珀高光集中于邻近脸部与物体，并向暗背景快速衰减。 | 与灯具位置、燃烧状态、时代资产和微弱火声协同；避免无源暖光填满房间。 |
| LGT-15 | 车灯直射与湿路反射 | 环境移动光 | 已确认车辆前灯从车辆方向照射，在薄雾、雨丝和湿路形成受视角约束的高光与反射带。 | 车辆位置/速度、地面湿度、眩光和光束移动连续；避免车灯方向与车辆相反。 |
| LGT-16 | 烟雾中的背光剪影 | 光学介质 | 一束或多束背光穿过已确认烟雾，人物形成可读剪影与边缘分离，空间层次随介质密度递减。 | 烟雾由FX/环境控制；人物表情不可读时不得仍要求细微面部表演证据。 |
| LGT-17 | 暮光/蓝调时刻渐变 | 自然时段光 | 日落后天空由地平线残余暖色渐变为上方冷蓝环境光，城市或地景形成低对比剪影。 | 与黄金时刻区分并锁定时序；长段落需考虑自然光渐变是否允许。 |
| LGT-18 | 水下体积光与焦散 | 光学介质 | 日光穿过水面产生随波纹连续变化的柔和焦散和体积光，蓝绿色随深度衰减，悬浮颗粒增强空间层次。 | 水体与相机环境必须确认；FX、人物浮力、气泡和声音空间协同。 |
| LGT-19 | 雨夜混合光与湿地反射 | 天气/环境光 | 路灯、店铺或招牌在雨夜形成有来源的冷暖混合照明，湿地和伞面呈现位置一致的反射与高光晕。 | 雨量、路面湿度、反射、车辆/行人和雨声跨镜连续；不自动等同霓虹赛博风。 |
| LGT-20 | 火光动态暖源 | 动态实用光 | 已确认火堆或火焰为主导暖源，在邻近人物和物体上形成有限、连续的橙红亮度变化，与冷色夜间环境分离。 | 火焰FX、火星、烟、道具燃烧状态与声音同步；禁止火光强度随机跳帧。 |

## Combination Examples

- `LGT-04 + LGT-10`：窗户是唯一主光来源；整体采用低调选择性照明，暗部保留少量面部细节。
- `LGT-15 + LGT-19`：车灯负责移动直射光，雨夜环境负责湿地反射与持续天气状态。
- `LGT-12 + LGT-09`：舞台聚光灯提供方向，已确认舞台烟雾让光柱可见。
- `LGT-06 + LGT-11`：烛光是主导实用光源，室内暖色墙面只提供弱跳光，不能抹掉火焰方向。

## Stable Downgrade

当模型难以稳定执行复杂光影时，依次降级：减少光源数量 → 固定光源与摄影机之一 → 降低介质密度或反射复杂度 → 只保留主光方向、主体可读性和稳定结束光态。降级不得改变剧情事实或环境资产。
