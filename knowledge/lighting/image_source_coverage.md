# Lighting Image Source Coverage

本表只证明附件来源的20项已被覆盖。来源中的情节适配、抽象“电影感”以及混入的镜头/调色词不视为事实指令。

| 来源术语 | 规范模式 | 保留内容 | 校正 / 去重 |
|---|---|---|---|
| 黄金时刻光 | LGT-01 | 低角度暖色斜射、长阴影 | 浅景深转交Lens；情绪标签不自动采用 |
| 侧逆光 | LGT-02 | 侧后光、发丝与肩部轮廓 | 冷暖对比需有第二光源或环境依据 |
| 伦勃朗光 | LGT-03 | 单侧45度主光、面颊三角亮区 | 低调是可组合光比策略 |
| 窗户光 | LGT-04 | 窗口有动机侧光、百叶切割 | 方向绑定真实窗与时间天气 |
| 霓虹光 | LGT-05 | 招牌色光、湿面反射 | 综合色彩由Color协同，不默认赛博风 |
| 烛光 | LGT-06 | 多点暖色近距光、柔和动态阴影 | 火焰状态归Prop/FX，避免曝光抽动 |
| 顶光 | LGT-07 | 上方集中光、深眼窝阴影 | 必须检查面部表演可读性 |
| 散射光 | LGT-08 | 软阴影、低反差自然过渡 | 这是光质，仍需给出天空/窗等来源 |
| 丁达尔光 | LGT-09 | 雾烟尘中的可见体积光束 | 统一专业表述为参与介质体积光 |
| 低调光 | LGT-10 | 选择性高光、大面积暗部 | 这是明暗/光比风格，不是物理光源 |
| 反光板光 | LGT-11 | 柔和反射补光、暗部透气 | 不确认器材时只写跳光效果 |
| 舞台光 | LGT-12 | 单一聚光灯、烟雾可见光柱 | 中心构图归Composition，烟雾归FX |
| 月光 | LGT-13 | 冷色低强度侧光/轮廓 | 绑定月亮/夜空方向，避免夜如白昼 |
| 油灯光 | LGT-14 | 琥珀近距实用光、快速衰减 | 灯具与燃烧状态需资产依据 |
| 车灯光 | LGT-15 | 正向车灯、薄雾与湿路反射 | 绑定车辆位置、运动与地面状态 |
| 烟雾光 | LGT-16 | 烟雾背光、剪影和边缘分离 | 与LGT-09共享介质物理但保留剪影用途 |
| 暮光 | LGT-17 | 日落后冷蓝与地平线余暖渐变 | 与LGT-01按时间阶段区分 |
| 水下光 | LGT-18 | 水面焦散、体积光、悬浮颗粒 | 水体、FX、声音空间和深度衰减协同 |
| 雨天光 | LGT-19 | 雨夜混合光、湿地反射与高光晕 | 雨/湿度归环境FX，不自动等同霓虹 |
| 火光 | LGT-20 | 橙红动态暖源、火星、冷暖分离 | 火焰、烟、道具与声音同步，稳定变化 |
