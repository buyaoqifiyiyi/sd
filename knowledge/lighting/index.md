# Lighting Knowledge Index

## Module Contract

- Module Type：STATE-04、STATE-06至STATE-08辅助 Knowledge。
- Trigger：时间、天气、环境实用光源、人物受光、明暗关系、光线变化或光学介质影响镜头可见结果时。
- Not Applicable：上游未确认任何特定光影要求且默认环境光足以执行时，不为展示专业度强行套用模式。
- Required Inputs：已确认 Visual Direction、Environment / Character / Prop / FX Asset、Shot Purpose、空间关系、时间、天气与连续性边界。
- Output Owner：STATE-04由Project Bible对应字段拥有，STATE-06由Shot Design Template拥有，STATE-08仍只由`templates/10_video_prompt.md`拥有。
- Consumers：Visual Development、Detailed Shot Design、Clip Production、Video Generation、Review。
- Forbidden：新增剧情或光源、把情绪标签当照明事实、创建新主STATE或新的最终Prompt字段。
- Return Route：项目级光线体系冲突返回STATE-04；环境或光源资产冲突返回其资产拥有者；逐镜执行冲突返回STATE-06。

## Final Principle

光影不是独立装饰词。它必须由真实或已确认的光源、空间与介质成立，并被编译为人物、环境、材质和镜头时间中可观察的变化。
