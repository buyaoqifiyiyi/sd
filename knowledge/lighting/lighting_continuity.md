# Lighting Continuity

## Cross-Shot Rules

- 同一连续空间锁定主光源、环境光、可见实用光源和其空间锚点。
- 人物或摄影机移动时，受光变化必须由相对位置、遮挡、距离或朝向变化解释。
- 反打镜头可以改变画面中的亮暗分布，但不能让世界空间中的光源换边。
- 人物转身后面部受光可以变化；肤色、湿润、烟尘与服装材质对光的反应仍要连续。
- 光线通过门、窗、柱、树叶、车辆或人物形成遮挡时，阴影移动必须与遮挡物一致。
- 连续镜头中的动态实用光源保持同类波动频率和范围，避免每镜重新随机闪烁。
- Motivated Discontinuity允许重建新光线体系，但新段首镜必须说明时间、天气、环境和新光源锚点。

## Interaction Matrix

| 相关模块 | Lighting读取 | Lighting提供 | 禁止越权 |
|---|---|---|---|
| Environment | 时间、天气、建筑开口、灯具位置、材质、湿度 | 受光区、阴影、反射与衰减 | 不改地点、天气或建筑 |
| Character / Performance | 人物位置、朝向、动作与必须可读的表演 | 面部可读区、眼神光、轮廓与动作中的受光变化 | 不用光替代情绪与表演 |
| Camera / Lens | 机位、轴线、运动、焦段、曝光风险 | 相对光源位置、高光/暗部保护需求 | 不定义运镜、景深或光晕 |
| Composition | 主体、前中后景、负空间、遮挡、光区 | 可见光区与明暗层级 | 不用亮度关系重写主体布局 |
| Prop | 灯、蜡烛、油灯、车灯等状态 | 点亮范围、反射与光态结果 | 不自动点亮、熄灭或移动道具 |
| FX | 雾、烟、雨、水、火焰、粒子状态 | 散射、体积光、焦散、边缘光和反射 | 不新增FX来源或阶段 |
| Sound | 已确认声源与持续声 | 可见光源/FX需要同步的时点 | 不为无声光学现象虚构声音 |
| Editing / Handoff | 连续或断点类别 | 光态切点、Match Light/Color锚点 | 不制造不存在的过渡动作 |

## Dynamic Light State

动态火光、烛光、油灯、车灯、招牌或遮挡光影必须描述：

`起始强度/位置 → 触发或运动原因 → 受光区域如何变化 → 结束强度/位置 → 下一镜是否继承`

如果变化不是镜头叙事重点，只保留“有限、连续、物理稳定的微小变化”，避免模型把光线变成主动作。

## Clip Production Verification

Clip Production Plan至少必须明确：

- 光源大致来自哪一侧或哪个空间锚点；
- 人物与重要道具是否处在要求的可读受光区；
- 阴影、轮廓、反射和体积光是否与环境成立；
- 起始与结束构图中光态差异是否支持STATE-08描述；
- 剪影或极低调镜头是否与表演可读性目标冲突。

## STATE-08 Projection

- 【主风格】：生成段共同的光质、综合色温关系、光比和曝光倾向。
- 【环境一致性】：光源空间锚点、方向、时间/天气、介质、湿地/反射与连续性。
- 镜头/机位：摄影机与光源的相对位置，以及必要的主体曝光/高光保护。
- 起始状态：继承的光源状态、受光区、介质和反射状态。
- 画面描述：人物、摄影机、遮挡物或光源运动造成的一次可追踪受光变化。
- 人物动作与情绪：在当前光线下仍可见的表演证据，不用光影标签替代表演。
- 空间关系：光源—人物—摄影机—遮挡物—受光面/反射面的几何关系。
- 道具状态：实用光源道具的点亮、位置、朝向与结束状态。
- 音效：仅写已确认光源或关联FX实际产生的声音。
- 镜头结尾状态：稳定结束光态与连续/断点关系；不得另增“与下一镜衔接”字段。
- 【反向提示词】：只按风险写光源换边、曝光泵动、随机闪烁、介质/反射漂移等限制。
