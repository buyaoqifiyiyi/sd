# Lighting Foundations

## Atomic Lighting Model

每次设计至少判断以下维度，只输出当前镜头真正需要的部分：

1. **Motivation / Source**：太阳、天空、窗、霓虹、蜡烛、油灯、车灯、火、舞台灯或其他已确认光源。
2. **Position / Direction**：相对人物、摄影机和空间锚点的前、侧、后、顶、低位与角度。
3. **Size / Quality**：硬或软、直射或漫射、集中或铺开、阴影边缘与高光面积。
4. **Intensity / Exposure**：主体可读度、高光保护、暗部保留和曝光稳定性。
5. **Contrast / Key-to-Fill**：主辅光关系、低调或高调、背景与主体分离。
6. **Color Relation**：色温、综合色偏向、冷暖来源及不同光源之间的关系。
7. **Falloff**：光线随距离、遮挡与表面方向产生的衰减。
8. **Medium / Atmosphere**：雾、烟、尘、雨、水等是否让光束、散射、反射或焦散可见。
9. **Visible Effect**：面部、皮肤、眼神光、轮廓、服装、道具、墙面、地面和背景的具体受光结果。
10. **Temporal State**：起始光态、镜中变化、结束光态以及下一镜继承或已确认断点。

推荐内部句法：

`已确认光源 + 空间位置与方向 + 软硬/范围 + 强度与光比 + 色温关系 + 衰减/介质 + 人物与环境可见结果 + 起止变化与连续性`

## Responsibility Boundary

- 浅景深、焦外、焦段和光晕属于 Lens / Optics，不属于灯光原子。
- 摄影机推进、摇移、跟拍属于 Camera Movement；光线可以随相对位置变化，但不能替代运镜描述。
- 主体位置、负空间、内框和视觉重心属于 Composition；“光区”只有存在真实受光区域时才是构图支持层。
- 调色决定综合色彩整理；Lighting必须先说明光从何处来以及照亮什么。
- 雾、烟、雨、水、火星等实体或粒子由Environment / FX拥有；Lighting只描述它们如何散射、遮挡或反射光。
- 光源发声只在声源确实存在时进入Sound，例如火焰噼啪、雨声、车声；月光、低调光、反射补光本身没有音效。
- 情绪由Performance和叙事建立；光影可以支持可读性与氛围，不能凭“压迫、浪漫、神秘”新增剧情反应。

## Normalization Rules

- **低调光**是曝光与光比策略，不是一盏灯；必须绑定已确认光源及可读区域。
- **散射光**是光质；应说明其来源，例如阴天天空光、柔化窗光或雾中散射。
- **丁达尔光**统一为“参与介质中可见的体积光束”；没有雾、烟或尘等介质时不得虚构清晰光柱。
- **反光板光**统一为“反射/跳光补光效果”；除非上游确认器材入镜，否则最终Prompt描述补光结果而非摄影设备。
- **月光**必须由月亮或夜空方向成立，控制为可信的冷色低强度环境光或轮廓光，不无故照成白昼。
- **烛光、油灯光、火光**是动态实用光源；允许有限、连续、物理合理的亮度变化，禁止随机曝光抽动。
- **霓虹、车灯、雨天反射**必须与招牌、车辆、湿地和空间位置一致，反射方向受表面与视角约束。
- **水下光**必须依赖水体、表面波纹和悬浮介质；焦散与体积光强度随深度衰减。

## Selection And Density

单镜头优先：

- 一个主导光源或主导环境光系统；
- 一个必要的补光/轮廓/实用光支持关系；
- 一次可追踪的受光变化；
- 一个稳定、可继承的结束光态。

多个模式可以组合，但必须说明各自职责。例如“窗光 + 低调光”表示窗是主光来源、低调是整体曝光/光比策略；不能把两个名称并列后停止解释。

## Prompt Quality Gate

以下内容单独出现均不构成合格灯光语句：

- 电影感、大片感、高级感、氛围感；
- 神秘、压迫、浪漫、史诗；
- 伦勃朗光、霓虹光、丁达尔光等裸模式名；
- 不说明来源的“轮廓光”“补光”“光束”；
- 与环境、时间、天气、资产或人物位置矛盾的光线。

合格语句必须至少让模型知道：光从哪里来、朝哪里照、呈现什么可见结果、是否发生变化以及结尾如何稳定。
