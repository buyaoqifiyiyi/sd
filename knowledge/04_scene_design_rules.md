# SD Film Scene Design Rules

# AI影视场景设计规则


## 1. Scene Philosophy


场景不是背景。


场景是：

人物行为发生的空间。



---

# 2. Space Rule


优秀场景必须明确：


人物在哪里。


镜头在哪里。


视觉重点在哪里。



---

# 3. Environment Relationship


环境必须服务：


剧情。


人物。


摄影。



---

# 4. Lighting Rule


光影必须表达：


时间。


情绪。


空间。



---

# 5. Color Rule


色彩遵循：

Project Bible。



避免：

每个场景随机改变风格。



---

# 6. Asset Rule


场景设计：

只能调用已有资产。


禁止：

随意创造新角色。


随意改变环境结构。



---

# Final Principle


场景设计的目标：

创造一个可以被摄影机进入的世界。
