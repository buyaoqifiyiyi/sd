# Tone Patterns

## Pattern Library

这些模式仅用于内部选择。图片中的“典型氛围/适合类型”只作为候选，不是剧情事实；最终Prompt必须拆成可执行色彩语义，不输出CLR编号。

| ID | 规范模式 | 可执行综合色彩设计 | 成立条件 | 主要风险与稳定降级 |
|---|---|---|---|---|
| CLR-01 | 冷色倾向 | 综合色温偏冷，蓝/青/受控紫为主；保留肤色和中性锚点，冷色主要来自天空、环境光或已确认人工光 | 时间、天气或光源支持冷色反射 | 全画面蓝染、肤色灰死；降级为中性基底+冷色阴影/背景 |
| CLR-02 | 暖色倾向 | 暖综合色温，黄/橙/受控红为主；高光与肤色分离，保留中性黑白 | 夕阳、火光、钨丝灯或暖色环境材质成立 | 橙脸、黄白失真；降级为中性肤色+暖色高光/环境 |
| CLR-03 | 冷暖互补分离 | 冷色环境与暖色人物/实用光，或反向分配；明确两侧光源和空间区域，综合色彩主次清楚 | 至少两个真实颜色来源或一主一辅综合色彩区域 | 套路化青橙、脸部双色随机；降级为单一综合色温+小面积互补强调 |
| CLR-04 | 选择性高饱和 | 大部分画面保持可控，已确认主色或强调色提高纯度；肤色、白色和黑位不被综合色彩吞没 | 资产、FX、服装或环境存在高综合色彩依据 | 全局过饱和、通道溢出、颜色闪烁；降级为中等饱和+单一强调色 |
| CLR-05 | 低饱和保留身份色 | 整体降低色度并保留关键身份色、肤色差异和材质层次；黑白灰关系稳定 | 叙事需要克制且资产识别不依赖大量综合色彩 | 灰泥、肤色无生命、道具线索丢失；降级为中低饱和而非近灰度 |
| CLR-06 | 暗调低明度 | 低整体明度与受控黑位，局部高光、轮廓或色块保证人物和动作可读；阴影保留层次 | Lighting提供低调光或夜景依据 | 欠曝、死黑、噪点、换脸；降级为中低明度+局部面部可读区 |
| CLR-07 | 霓虹实用色光 | 蓝/青/紫/品红等高饱和实用光具有固定招牌/灯具位置，在皮肤、服装、玻璃和湿地形成方向一致的反射 | 环境资产或实用光源已确认 | 无源霓虹、换边、闪烁、肤色污染；降级为一种主霓虹色+一种弱辅色 |
| CLR-08 | 糖果/粉彩色 | 高明度、柔对比，浅粉、薄荷绿、鹅黄、浅紫、天蓝、奶油白中选择受控综合色彩；中性色干净 | 美术、服装和环境本身支持浅色体系，Lighting为柔和高调 | 塑料感、综合色彩漂白、全局糖果滤镜；降级为两种粉彩+中性白灰 |
| CLR-09 | 清透自然色 | 中性或轻微冷青倾向，干净高光、自然肤色、中低饱和与清晰综合色彩分离；不过曝 | 日光/柔光、洁净环境和材质支持 | 过曝发白、肤色青绿、广告滤镜；降级为中性白平衡+轻微冷背景 |

## Selection Rule

1. 先确认资产颜色、时间天气、实用光源和材质，再选主模式。
2. 一个连续段优先只有一个主色调模式；第二模式只能作为有依据的辅助结构或已确认叙事转变。
3. 冷暖、明暗与饱和度不自动决定人物情绪；情绪仍由剧情和表演建立。
4. CLR-07霓虹依赖真实光源，CLR-06暗调依赖可读Lighting，CLR-08糖果依赖美术与高明度，不得只靠后期滤镜伪造。
5. 模型不稳定时先减少色数、降低局部饱和、固定光源颜色和保留肤色/中性色锚点。
