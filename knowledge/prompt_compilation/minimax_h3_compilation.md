# MiniMax H3 Compiler

## Scope And Boundary

仅当 `Target Video Model = MiniMax H3` 且 Model Execution Lock 已锁定时使用，并同时读取 `adapters/minimax-h3.md`。本文件只把已确认 Clip 编译为 H3 可执行的自然语言语义；不拥有 API 字段、上传格式、最终 Prompt 字段、顺序或排版。

## Compilation Rules

- 一个 Execution Clip 的生成时长必须为 4—15 秒。超出窗口时返回 STATE-07，不在 STATE-08 偷改时长、补剧情或压缩动作。
- 按官方三段式编译，并只投影到`templates/13_minimax_h3_video_prompt.md`：`参考素材说明：`写每个实际输入的`@图片N / @视频N / @音频N`和唯一用途；`核心创意：`形成“主体 + 地点 + 事件 + 题材/风格 + 必要运镜”；`画面过程说明：`按故事线或Shot分段写景别、画面、运镜、动作、台词和音效；`反向提示词：`收束不想要的当前风险。
- H3默认可按明确的Shot结构切镜。需要一镜到底时，使用一个连续段落并明确“不要切镜”；两张首/尾帧图时只描述两帧间的连续动作、光影和声音，明确“不要切镜”。多Shot台词的长度必须匹配Shot时长；跨Shot台词明确写出J-cut或L-cut、说话角色及画内/画外状态。
- 只引用最小充分的真实视觉、视频和音频资产。全能参考上限为9图、3视频、3音频、12个混合文件；音频不能独立输入。超过能力上限先保留角色身份、关键帧/空间锚点和关键道具，再缩减环境辅助素材；不宣称上传或界面能力。
- 用户明确要求当前视频的对白、口型、语言、音频复用或声音身份时，在现有 `台词：`、`音效：`和条件`音色特征：`写精确原文和最小执行语义。否则保持 Voice opt-in 的默认省略。已有视频编辑只在用户提供实际视频并明确`CHANGE`与`PRESERVE`时编译，不写时码。
- `反向提示词：`保留固定无 BGM 禁令，并在 H3 输出末尾加入官方推荐的`非叙事性音乐：N/A`；其余只保留当前 Clip 仍无法用正向状态锁定的少量生成风险。

## Handoff

把经验证的 H3 语义归并到 `state08_projection.md` 并由`templates/13_minimax_h3_video_prompt.md`输出。不得输出 Target Model、内部 Compiler、平台能力、模型参数、执行模式或未验证的首尾帧/视频编辑控制。
