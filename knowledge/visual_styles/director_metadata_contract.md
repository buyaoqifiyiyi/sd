# Director Knowledge Metadata Contract

## Purpose

保证导演知识可检索、可区分、可组合且能转译为执行语言。

每个 `knowledge/visual_styles/directors/*.md` 文件的Knowledge Role必须明确：

- 检索标签
- 适用阶段
- 使用边界
- 核心区分

正文必须继续包含统一导演Schema，并在STATE-04 / STATE-06 / STATE-08分别说明投影边界。

导演名首先是检索标签，也可以作为最终Prompt中的高层创作锚点保留。保留时不得单独承担执行控制：首次出现必须在同一风格段给出该项目中的具体含义，并落到少量可见的摄影、构图、灯光、色彩、表演、声音或剪辑行为。名称完全冗余时允许省略，但不得在完成具象化后默认强制删除。

组合时必须记录：Primary Style Logic、Secondary Borrowed Traits、Rejected Conflicts和最终Camera / Lighting / Editing主体系。
