# Reverse Shot

## 中文名称

反打镜头；正反打；Shot-Reverse-Shot。

## Definition

在已建立的对话或关系轴线同一侧，先拍 A，再从相反观察方向拍 B。它是两个或多个镜头的剪辑关系，不是同一镜头内摄影机绕到另一侧。

## Narrative Function

- 清楚呈现对话、对峙和情绪反应。
- 控制信息顺序：说话者、倾听者、反应者。
- 维持人物距离、权力和视线关系。

## Spatial Rules

- 建立 A 在左、B 在右或相反的空间关系。
- 两个机位必须位于 180 度轴线同一侧。
- A 看向画面右侧时，B 应看向画面左侧。
- 景别、眼睛高度和镜头距离应有可解释的匹配或差异。

## Execution Pattern

1. Establish：先用双人镜头或明确环境建立轴线。
2. Shot A：A 保持既定画面侧，完成对白或反应。
3. Reverse B：切到 B，眼线与 A 匹配，背景方向连续。
4. Return：需要时切回 A，动作和情绪承接上一状态。

## Seedance Execution Rule

将正打和反打拆为独立生成镜头，每个镜头只包含一位主要表演者和稳定眼线。不要在一个生成片段中要求摄影机自动绕到另一人面前。

## Recommended Prompt Language

> 反打 B：摄影机仍位于既定关系轴线同一侧，以 B 的中近景拍摄。B 位于画面右侧，身体朝向画面左侧的 A，视线落在 A 的眼线位置；背景门位于 B 身后右侧，与正打镜头方向一致。

## Avoid And Common Failure

- A、B 同时看向同一画面方向：修正为相反匹配眼线。
- 背景左右翻转：锁定门、窗和桌子的位置。
- 一个镜头内完成正反打：拆成独立镜头。
- 反打时人物身份或服装互换：引用各自资产并锁定画面侧。

## Shot Design Selection Rule

对白、对峙和反应链优先 Reverse Shot；需要连续双人身体关系时使用双人镜头或 Side Tracking；需要角色所见信息时使用 Subjective POV。

## Final Principle

反打的核心是轴线、相反眼线和独立镜头之间的连续性，不是摄影机炫技绕行。
