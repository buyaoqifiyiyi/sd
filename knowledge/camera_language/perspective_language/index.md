# Perspective Language Index

## Library

- [Subjective POV](subjective_pov.md)：角色主观、镜面主观和设备第一视角。
- [Reverse Shot](reverse_shot.md)：对话与对峙的正反打关系。
- [Over-the-Shoulder](over_shoulder.md)：以一方肩部为前景、主要观察另一方的关系构图。
- [肩膀视角与肩背移动](../camera_movement/shoulder_follow.md)

## Selection Principle

直接看角色所见选择 POV；固定关系构图选择 OTS；需要保留肩背并随人物移动选择 Shoulder Follow；需要切换双方反应选择 Reverse Shot。四者都必须继承人物方向、眼线和 180 度轴线。
