# Occlusion Frames

## 中文名称

遮挡构图；裂缝透视；夹缝观察；暗角窥视；隔窗远拍；裂窗镜头；半遮挡镜头。

## Definition

通过门缝、窗框、墙角、树叶、破碎玻璃或其他前景遮挡观察主体。遮挡物必须属于真实空间，并保留足够可读区域展示关键人物和动作。

## Source Shot Types

### 裂缝透视镜头

从墙体或物体狭窄裂缝观察人物，适合争吵、秘密和受限信息。裂缝边缘固定，不随人物脸部变形。

### 遮挡镜头 / 半遮挡镜头

用门框、树叶、车辆或建筑边缘遮住部分画面，增强空间层次和观察感。遮挡比例通常低于画面一半。

### 暗角窥视镜头

摄影机从墙角或暗处观察房间，前景保持低亮度，主体位于明确的亮区和空间位置。

### 夹缝镜头

从门缝或狭窄开口观察室内双人关系。必须锁定 A、B 左右位置、面对方向和 180 度轴线。

### 隔窗远拍镜头

摄影机位于窗外较远处，窗框作为完整空间边界，人物动作保持克制，避免被玻璃反光吞没。

### 裂窗镜头

通过破碎玻璃观察人物惊恐或冲突。玻璃裂纹固定，不能穿过人物脸部关键区域或随动作移动。

## Narrative Function

- 限制观众信息，表现秘密、监视、距离或危险。
- 用前景建立空间深度和摄影机的真实观察位置。
- 让人物关系发生在明确框架内，而不是直接正面展示。

## Execution Pattern

1. Start：锁定遮挡物、开口形状、摄影机侧和主体位置。
2. Process：人物完成一个简单动作，遮挡物保持固定或只产生轻微自然运动。
3. End：主体仍可识别，关键动作结果和人物空间关系清楚。

## Seedance Execution Rule

明确遮挡物占画面哪一侧、开口范围、人物可见部位和背景位置。单镜头只使用一个主要遮挡框架；不叠加多层裂缝、快速绕行、人物换位或穿过遮挡物。

## Recommended Prompt Language

> 摄影机固定在半开的门外，从画面右侧窄门缝观察室内 A 与 B；A 位于左侧、B 位于右侧，两人相互面对。门框和门缝宽度保持不变，人物不看向摄影机，不越过 180 度轴线。

## Avoid And Common Failure

- 遮挡物随主体移动：锁定门框、墙角或玻璃的固定空间位置。
- 主体被完全遮住：指定脸、手或关键动作始终可见。
- 破碎玻璃漂移：明确裂纹固定在前景平面。
- 多人方向混乱：补充左右位置、视线和关系轴线。

## Shot Design Selection Rule

秘密信息用裂缝或夹缝；中性空间层次用半遮挡；监视感用暗角窥视或隔窗远拍；危险和心理碎裂用裂窗，但需控制视觉复杂度。

## Final Principle

遮挡必须提供叙事视角和空间证据。观众可以被限制信息，但不能失去人物身份、动作和方向。
