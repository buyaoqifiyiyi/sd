# Action Composition Patterns

## Usage Rule

动作构图必须先服从动作编排、FX 生命周期、空间轴线和人物安全路径。图片名称只提供视觉意图，不授权新增枪火、爆炸、坠物、伤害或其他剧情事实。

| ID | 模式 | 规范组合与执行 | 风险与降级 |
|---|---|---|---|
| ACT-C01 | 弧线包抄 | 多角色沿已定义弧形路线收拢，主体位于清楚中心；摄影机固定或短弧线二选一 | 多人路线混乱时拆成建立镜头 + 主体近景 |
| ACT-C02 | 断层跃迁 | 明确起跳面、空中路线、落点与高度差；Wide/Full Shot 优先 | 跳跃物理失真时拆起跳/落地镜头或降低跨度 |
| ACT-C03 | 交叉火线 | 前后左右威胁线只作为已确认动作/FX方向，主体拥有唯一安全方向 | 禁止随机新增火力；线条过多时只保留主威胁与主反应 |
| ACT-C04 | 甩尾切入 | 高速主体从画面边缘沿单一路径切入，环境残影服务速度、主体轮廓保持可读 | 身份拖影时降低速度、扩大景别或改静态通过 |
| ACT-C05 | 坠物压境 | 上方已确认碎片/坠物朝前景形成压力，人物只做闪避或迎击之一 | 必须调用 FX；交互失稳时拆为坠物镜头与人物反应镜头 |
| ACT-C06 | 双轴冲撞 | 两组人物沿两条明确轴线接近唯一交汇点，锁定先后与碰撞结果 | 群体融合时拆分双方推进与交汇结果 |
| ACT-C07 | 掩体探身 | 人物从固定墙/车/柱后露出一侧轮廓，保留敌方方向空间 | 不让掩体随人物变形；复杂射击另拆动作镜头 |
| ACT-C08 | 旋身反制 | Full/Medium Shot 保留脚步、躯干旋转、格挡/反击的因果顺序 | 一镜只完成一次旋身与一个结果；肢体失真时分段 Coverage |
| ACT-C09 | 爆点后撤 | 已确认冲击源位于中后景，人物朝镜头或斜向后撤，光/碎屑方向一致 | 必须绑定 FX；失败则固定爆点轮廓 + 独立人物后撤镜头 |
| ACT-C10 | 窄巷夹击 | 走廊两端威胁与中央主体形成清晰三点关系，墙体压缩行动线 | 多人交叉时用建立镜头锁位，再拆正反方向 |
| ACT-C11 | 临空摆荡 | 明确绳索/吊臂支点、摆弧、身体重心与背景高度 | 高风险；优先拆起悬、摆动、落点，不在同镜叠加复杂摄影机 |
| ACT-C12 | 回身格挡 | 主体转身触发攻击者从固定侧切入，身体扭转与手臂受力可见 | 只保留一名攻击者和一次格挡；轴线不清则改侧面 Full Shot |
| ACT-C13 | 烟幕突穿 | 人物从已确认烟雾层中沿单一路线出现，轮廓先于面部可读 | 烟雾不得换人或吞没终点；绑定 FX 并降低背景动作 |
| ACT-C14 | 碎面追影 | 单一破裂玻璃/金属/水面反射主体，真实人物与反射层分离 | 多重复制时只留一个主反射面；追踪过程简化为短距离 |
| ACT-C15 | 错位扑袭 | 前景与中景人物在真实透视上短暂重叠，随后揭示接近关系 | 不用透视伪造不可能距离；失稳则改 OTS + 独立扑袭反应 |
| ACT-C16 | 尾迹撤离 | 主体快速离画，尾迹只来自已确认脚步水花、烟雾、布料或弹痕 | 尾迹不得替代人物动作；失败则固定镜头让主体完整离场 |

## Final Principle

动作构图先证明路线、支点、威胁来源和结果，再增加速度、FX 与层次。
