# Emotional Director Patterns

## Usage Rule

以下名称是便于导演沟通的模式标签，不是新的技术分类。每次使用必须回到“规范组合”所列权威文件，并结合剧情、表演、速度、光线和声音判断。不得仅凭“悲伤、震惊、权力”等标签自动套镜头。

## Pattern Matrix

| ID | 导演模式 | 规范组合 | 适用触发 | 执行与降级 |
|---|---|---|---|---|
| EMO-01 | 推近压迫 | `camera_movement/01_push_in.md` + 近景倾向 | 信息或情绪逐步逼近，人物仍相对静止 | 单次慢速直线 Push In，锁定面部与终点；脸部失稳则缩短距离或静态切近景 |
| EMO-02 | 后撤疏离 | `camera_movement/02_pull_out.md` + 环境负空间 | 离别、关系疏远、个体被环境吞没 | 人物留在原位，单次慢 Pull Out；环境重构则改静态远景或剪辑到空镜 |
| EMO-03 | 环绕眩晕 | `advanced_camera_movement/orbit_variants.md` | 认知、关系或空间发生失衡 | 先用 45–90 度小弧线，锁定中心、半径和方向；失败则静态角度切换，完整 360 非默认 |
| EMO-04 | 手持崩溃 | `camera_movement/handheld.md` | 秩序略有失控、现场感强化 | 先锁人物与空间，仅加低幅呼吸；脸和构图漂移则降为稳定机位加急促表演/声音 |
| EMO-05 | 低角压强 | `camera_angle/low_angle.md` + 可选短 Push In | 权力、威胁或体量需要强化 | Low Angle 为主；若加入 Push 只允许短直线一次。双重运动失稳则保留静态低角度 |
| EMO-06 | 俯拍孤立 | `camera_angle/high_angle.md` 或 `top_down.md` | 人物弱势、被围困或负空间关系重要 | 依据是否需要人物体积选择 High Angle/Top Down；身份过小则降低高度或改远景 |
| EMO-07 | 侧移窥视 | `camera_movement/side_tracking.md` + `composition_language/occlusion_frames.md` | 监视、秘密观察、危险靠近 | 侧向单一路径，前景只短暂掠过；遮挡吞没主体则减弱遮挡或改固定窥视构图 |
| EMO-08 | 定格凝视 | 固定机位 + `lens_language/framing_and_scale.md` | 沉默、忍耐、悲伤或信息消化 | 固定中近景/近景，保留可观察微表演和结束停顿；不把“定格”误写成冻结人物时间 |
| EMO-09 | 极速推进 | `advanced_camera_movement/rapid_and_motivated_push.md` | 突发发现、惊讯、危机冲击 | 事件触发后短距离单次 Fast Push；失稳则普通 Push In 或剪辑切特写 |
| EMO-10 | 拉焦转移 | `lens_language/focus_and_optics.md` 的 Rack Focus | 已同框的前后景信息需要交接注意力 | 固定机位、一次单向焦点转移；不是摄影机移动。失焦不可控则拆成两个独立镜头 |
| EMO-11 | 跟随沉浸 | `camera_movement/03_tracking.md`、`shoulder_follow.md` 或 `dolly_tracking.md` 三选一 | 奔赴、寻找、进入或执行任务 | 先决定侧位与稳定方式，只选一个跟随类型；路径复杂则缩短路线或拆镜 |
| EMO-12 | 变焦窒息 | `lens_language/focus_and_optics.md` 的 Dolly Zoom | 空间感需要反常变化以表达心理失衡 | 主体尺度近似稳定，直线位移与反向变焦视作一个联合机制；失败则长焦压缩或普通推拉 |
| EMO-13 | 剪影决绝 | 逆光剪影构图 + 固定机位/简单 Pull Out | 离开、牺牲、最终选择 | 锁定轮廓、光源和动作方向；脸部信息不是目标。轮廓糊合则减少背景光源与人物数量 |
| EMO-14 | 反打对峙 | `perspective_language/reverse_shot.md` + 可选 `over_shoulder.md` | 谈判、审问、关系冲突 | 拆成独立正打/反打，保持相反匹配眼线与同侧轴线；禁止一个片段内自动绕行 |
| EMO-15 | 微距失控 | `lens_language/framing_and_scale.md` 的大特写/局部 | 手指、眼睛、嘴角等微小动作承载关键反应 | 一镜只拍一个局部和一个动作；身份不清或肢体畸形则扩大到普通特写 |
| EMO-16 | 长焦抽离 | `lens_language/focus_and_optics.md` 的超长焦压缩 | 远距离观察、不可接近或被空间隔开 | 摄影机保持远距，背景压缩但位置稳定；不得把压缩写成推进或数字缩放 |
| EMO-17 | 穿越障碍 | `advanced_camera_movement/traverse_shots.md` 或 `composition_language/occlusion_frames.md` | 追寻、营救、突破边界 | 优先真实门道或完整遮挡切点，一镜只过一个边界；穿模则拆为遮挡前后两段 |
| EMO-18 | 慢摇预兆 | `camera_movement/pan.md` 或 `tilt.md` 二选一 | 逐步揭示异常、危险前兆或环境信息 | 固定机位、单向慢摇、明确落点；不以“摇”表示横移或随机摆动 |
| EMO-19 | 升降命运 | `camera_movement/crane.md` | 局部与整体、个体与环境关系在转折点重组 | 单一上升或下降，锁定高度和终点构图；建筑失稳则缩短高度或剪辑到高/低机位 |
| EMO-20 | 空镜余韵 | 固定环境镜头 + `editing_language/cutting_patterns.md` | 人物离场后需要结果、声音或环境继续承载情绪 | 人物完成离场后保持可读环境与持续声音；空镜不新增剧情事实，必要时独立生成 |

## Compound Rule

表中“角度 + 运镜”“构图 + 运镜”只允许一个主要空间路径；角度或构图必须从头到尾保持稳定。若无法用稳定的一条路径表达，就拆成多个镜头。

## Final Principle

情绪不是镜头的固定属性。导演模式必须由可观察的剧情变化触发，并且能够解释为什么此时选择这一个镜头。
