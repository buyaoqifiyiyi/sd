# Emotional Atmosphere Composition Patterns

## Usage Rule

氛围构图只能强化已存在的剧情与情绪，不能用视觉模式替代人物表演、声音或因果。反射、玻璃、阴影、色块与 FX 必须有真实来源并保持连续。

| ID | 模式 | 规范组合与执行 | 风险与降级 |
|---|---|---|---|
| ATM-C01 | 压迫边角 | 主体靠近角落/墙边，建筑墙面或阴影占据主要视野并保留可读面部 | 环境吞没主体时减少墙面比例或提高轮廓光 |
| ATM-C02 | 镜面分裂 | 一个真实人物 + 一个同步镜像，镜面边界和左右关系清楚 | 禁止生成两个独立人物；失稳则只拍镜中脸或真实后脑 + 镜像 |
| ATM-C03 | 窄缝窥视 | 门缝、柜缝或窄窗作为唯一观察开口，主体关键部位可见 | 开口宽度固定；主体被遮完时扩大开口或改半遮挡 |
| ATM-C04 | 遮半失衡 | 半张脸/半个身体处于有来源的光线或遮挡边界，另一半仍保留轮廓信息 | 不让黑暗吞没身份；光线分界不得随表情漂移 |
| ATM-C05 | 倒影主叙 | 水面、镜面桌面或橱窗倒影为主要叙事层，真实主体只作次级证据 | 倒影上下与动作同步；水面过动时降低波纹 |
| ATM-C06 | 色块对撞 | 两个有真实灯光/布景依据的互补色区分人物、阵营或状态 | 不在单镜无因换色；无法锁定时降级为单主色 + 局部对比色 |
| ATM-C07 | 影子先行 | 真实光源让人物影子先进入画面，随后人物沿一致方向出现 | 影子方向、长度和人物路径一致；失败则固定影子 + 后续独立人物镜头 |
| ATM-C08 | 玻璃阻隔 | 隔雾玻璃、雨窗或车窗观察主体，纹理不遮住关键表演 | 锁定玻璃平面、内外空间和反射层；过密水滴则降低纹理 |
| ATM-C09 | 环形包围 | 人群、灯带、拱门或桌席形成环形空间包围主体 | 先锁定中心、人数和朝向；群体失稳则用固定 Wide + 少量人 |
| ATM-C10 | 贴地掠行 | Ground Level + 单向短 Tracking，地面纹理形成速度层次 | 与 ACT/DYN 同类共享基础规则；穿模时固定贴地让主体经过 |
| ATM-C11 | 失焦情绪 | 关键主体保留可识别轮廓/局部焦点，其余轻度柔焦和光斑 | 不把主体完全虚化；若身份丢失则恢复眼睛或轮廓清晰 |
| ATM-C12 | 局部肢体 | 手、后颈、衣角、脚步等一个局部承担动作证据，身份来源清楚 | 一镜只拍一个局部和一个动作；肢体失真时扩大景别 |
| ATM-C13 | 群像割裂 | 柱、门框、光区或景别层把同框多人分成可读小组 | 每组人数、身份和方向明确；融合时拆成分组 Coverage |
| ATM-C14 | 曲面扭转 | 鱼眼、弧形建筑或弯曲镜面制造受控几何扭曲 | 高风险；优先真实弧形环境或轻度广角，禁止无来源的全画面融化 |
| ATM-C15 | 逆光剪影群体 | 多人逆光形成可分辨轮廓与层次，只保留必要姿态和间距 | 不依赖面部；人物融合时减少数量并扩大间距 |
| ATM-C16 | 顶部压顶 | 巨大天花、桥体、山体或机械结构占据上方，主体位于下方可读区域 | 固定结构比例与透视；主体过小时提高占比或改 Low Angle Establishing |

## Final Principle

氛围构图必须保留主体身份、动作证据和空间来源；氛围不能建立在不可验证的视觉混乱上。
