# Character Narrative Composition Patterns

## Usage Rule

人物构图通过站位、方向、距离、遮挡、光线与环境关系表达叙事。构图不能替代表演动因，不能自动赋予“告别、背叛、孤独”等剧情事实。

| ID | 模式 | 规范组合与执行 | 风险与降级 |
|---|---|---|---|
| CHR-C01 | 门轴偏置 | 人物贴近门轴/墙边一侧，另一侧保留明确行动空间；锁定身体朝向与门的开合方向 | 人物被边缘裁切时增加安全边距；门体动作复杂时保持固定 |
| CHR-C02 | 回望断点 | 人物越过画面重心后仅做一次头部/上身回望，视线与原行进方向形成可读反差 | 禁止凭构图新增旧人重逢；方向混乱时改侧面静态回望 |
| CHR-C03 | 夹层观察 | 人物位于楼梯、栏杆或上下层之间，环境分层但身份可辨 | 建筑重构时只保留一层栏杆与一个目标层 |
| CHR-C04 | 余光联结 | 两人不直接对视，以侧脸、余光、镜面边缘或姿态朝向建立弱关系 | 视线不可验证时改双人平衡或 OTS，不靠抽象“默契” |
| CHR-C05 | 临界跨步 | 人物一脚跨过门槛、水坑、光区或警戒线，清楚保留跨越前后位置 | 一镜只跨一个边界；脚步/地面失真时用 Match on Action 拆镜 |
| CHR-C06 | 光缝塑形 | 狭窄定向光只勾勒面部/身体关键轮廓，其余空间低照度 | 光缝必须有门缝/百叶/窗等来源；脸不可读时提高辅光 |
| CHR-C07 | 末端守望 | 人物位于走廊、站台、长桌或队列末端，环境线条证明被排除/等待位置 | 情绪需由表演和剧情支持；主体过小时提升景别 |
| CHR-C08 | 斜面静置 | 人物稳定站/坐于坡道、斜墙或倾斜地形，环境斜线与身体重心形成对照 | 不把真实斜面误写成 Dutch Angle；地形不稳则固定水平机位 |
| CHR-C09 | 反向通道人物 | 稳定主角与周围人流/车辆的单一反向运动形成关系 | 群体需锁定主流方向；混乱时减少背景数量与速度 |
| CHR-C10 | 双层窗景 | 前后两层窗框、车窗或室内反射中只保留一个真实主体与一个明确反射/背景层 | 复制人物时简化为单层玻璃构图 |
| CHR-C11 | 侧坐失衡 | 人物坐在床/椅/桌边并偏向一侧，重心、双脚与支撑点真实 | 不能只写“不安”；用肩部、手和视线表现状态 |
| CHR-C12 | 近远对峙 | 前景局部人物 + 远处完整主体形成空间对峙，双方视线和轴线一致 | 避免把它误当 OTS；关系不清时改标准 OTS/Reverse Shot |
| CHR-C13 | 群体裂口 | 人群中保留一条真实通道或空隙，主角位于裂口尽头/中心并可识别 | 人群融合时减少人数或拆成 Wide Establishing + 主角近景 |
| CHR-C14 | 轮廓贴边 | 人物面部或身体轮廓贴近画面边缘，只暴露关键表情/姿态，另一侧留给目标或环境 | 保留脸部和身体安全边距；过度裁切则退回 Close-Up 三分法 |
| CHR-C15 | 远近同框异步 | 同一角色通过真实反射/屏幕/照片在前后层出现不同时间信息 | 高风险且需剧情授权；优先独立生成后合成，禁止模型自由复制身份 |
| CHR-C16 | 暗场聚点 | 大面积暗区中只保留一个人物亮部焦点，亮点可偏离几何中心 | 锁定光源与曝光；人物消失时增加轮廓/面部可读光 |

## Final Principle

人物构图必须把关系写成可见的位置、朝向、距离、视线、遮挡和受光，而不是抽象心理标签。
