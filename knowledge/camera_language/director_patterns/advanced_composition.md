# Advanced Composition Patterns

## Usage Rule

这些模式组合构图、镜头、光线或焦点原子，不建立新的原子定义。每镜只保留一个主构图逻辑和一个主要摄影机运动；“适配情节”必须由剧情事实支持。

| ID | 模式 | 规范组合与执行 | 风险与降级 |
|---|---|---|---|
| ADV-C01 | 消失点压缩 | Leading Lines + 远距长焦压缩；主体位于单一消失点附近，前景轨道/道路导向主体 | 透视融化时固定摄影机、缩短景深层级或改普通引导线远景 |
| ADV-C02 | 侧翼失重 | Rule of Thirds + 大面积单侧 Negative Space；主体偏向一侧边缘但身份可读 | 主体出画时增加安全边距并减少负空间比例 |
| ADV-C03 | 逆向视差 | Layered Depth + 单向 Side Tracking；前景与背景产生方向相反、速度不同的真实视差 | 空间跳变时减少层数或改固定层次构图；不得写成时间错位特效 |
| ADV-C04 | 双窗对应 | 两个真实窗口/框架并置，各自容纳一名主体或一项信息 | 人物复制或框体漂移时拆成两个独立镜头或单窗 OTS |
| ADV-C05 | 中轴破缺 | 先建立可识别中轴，再以主体偏移、遮挡缺口或构图断裂破坏秩序 | 未建立中轴时模式无效；降级为明确不对称构图 |
| ADV-C06 | 顶光孤岛 | 固定主体 + 单一可解释顶光区域，其余空间保持低照度 | 黑场吞人时保留面部/轮廓可读光；不得凭空移动光斑 |
| ADV-C07 | 曲廊回勾 | 弧形走廊/拱廊作为 Curved Leading Line 把视线回引至人物 | 建筑变形时缩短曲线范围或改直线走廊引导 |
| ADV-C08 | 前后景失焦反转 | Layered Depth + 一次 Rack Focus，从前景转背景或反向 | 只允许一次焦点交接；失稳则拆成前后两个镜头 |
| ADV-C09 | 低饱和静爆 | 低饱和全局风格 + 静态构图 + 单一高信息焦点 | 不把色彩形容词当作情绪证据；靠表演/声音完成蓄势 |
| ADV-C10 | 遮挡递进 | 单向 Tracking/Push + 一至两个按距离顺序经过的真实遮挡层 | 多层遮挡吞没主体时只保留一层；不得让遮挡物随脸变形 |
| ADV-C11 | 斜雨切片 | Diagonal Composition + 方向一致的雨线/光线，人物运动与雨向可辨 | FX 过密时降低雨量并固定主光；不得遮住脸和动作结果 |
| ADV-C12 | 冷暖断层 | 两个有真实光源依据的冷暖区域分隔人物或空间 | 色温随人物漂移时锁定光区边界；降级为单一主色 + 局部辅色 |
| ADV-C13 | 远端微主体 | Extreme Long Shot + Negative Space，主体以路线、服装色或轮廓识别 | 主体消失时提高占比、缩小环境范围或改 Long Shot |
| ADV-C14 | 纵深回望 | 深走廊/通道 + 回头动作 + 明确前后层级 | 人物转向与轴线冲突时固定身体，仅做一次头部回望 |
| ADV-C15 | 多点视线牵引 | 三人以上按明确顺序看向不同目标，形成可追踪视线链 | 多人视线错乱时拆 Coverage；每镜优先一名主表演者、一次视线交接 |
| ADV-C16 | 边缘悬停 | 主体靠近画面边缘或临界位置，保留安全边距与明确视线空间 | 不让主体被裁切或跌出画面；失稳则回到三分法偏置构图 |

## Final Principle

高级构图必须能退回一个更简单的基础构图而不损失镜头目的。
