# Focal Length Patterns

## Usage

这些模式只用于内部选择。先确认Shot Purpose、景别、摄影机位置和动作容量，再选一个主模式；最终Prompt必须拆成执行语义，不输出FLN编号。

| ID | 规范模式 | 选择条件 | 可执行设计 | 稳定降级 |
|---|---|---|---|---|
| FLN-01 | 14–20mm 超广角空间参与 | 环境结构、纵深或近身动作必须与人物共同可见 | 宽视场；关键脸远离边缘；近机位时控制面部距离；中等/深景深优先；运镜短而清楚 | 退到21–28mm或固定广角全景 |
| FLN-02 | 21–28mm 广角人物环境 | 人物和环境信息同等重要 | 摄影机保持可读距离，前景路线与背景锚点同时清楚；限制边缘人物 | 退到29–40mm并减少背景事件 |
| FLN-03 | 29–40mm 温和广角临场 | 需要自然参与感、跟随或双人空间 | 近至中距离，人物不贴边，保留适量环境与运动视差 | 固定35mm倾向中景 |
| FLN-04 | 41–60mm 标准关系 | 对白、观察、反应需要中性空间关系 | 中距离机位，景别与眼线清楚；按叙事选择景深，不默认虚化 | 固定50mm倾向中景/中近景 |
| FLN-05 | 61–100mm 中长焦隔离 | 需要突出人物、压低背景干扰或观察细微表演 | 机位后移，锁定眼睛/关键动作，背景与人物距离拉开；运动缓慢 | 固定85mm倾向，减少人物和摄影机同步移动 |
| FLN-06 | 101–180mm 长焦叠层 | 远距观察、多层背景叠合或克制内心戏 | 远距离固定/短跟拍，清楚说明背景锚点和焦点对象，预留稳定结束 | 退到85–100mm并简化背景层数 |
| FLN-07 | 181mm+ 超长焦观察 | 必须远距离取景且窄视场具有叙事功能 | 固定或非常缓慢跟踪，单一主体、稳定支撑、保守跟焦；接受空气介质影响 | 退到135mm，或切换为远景建立加近景插镜 |

## Selection Rule

1. 先定景别，再定希望观众感知的摄影距离与空间关系。
2. 只有画幅已知时才把毫米数视为严格器材参数；否则写“约XXmm全画幅等效倾向”。
3. 一个镜头只选一个主焦段模式；光学变焦是焦距变化动作，不能同时假装焦段固定。
4. 焦段不能自动分配情绪。图片中的“适配情节”只能作为候选，必须由剧情、表演和构图证明。
5. 复杂人物动作 + 超广角运动，或复杂跟焦 + 超长焦运动，优先使用稳定降级。

## Prompt Quality Gate

合格焦段句必须同时回答：焦段倾向、摄影机距离、景别、可见空间效果、对焦/景深和运动约束。缺少机位距离时不得宣称透视或压缩结果。
