# Cutting Patterns

## 中文名称

长镜头；快切镜头；景别切换；反打结构。

## Source Shot Types

### 长镜头

在一个连续镜头中完成完整动作或关系变化，不依赖隐藏切点。必须先设计人物路线、摄影机路径、动作节点和结束状态；一个长镜头仍只保留一个主要运镜。

### 快切镜头

用多个独立短镜头增强节奏。每个短镜头只表达一个信息，保持人物资产、道具状态、屏幕方向和光线连续；快切不是让单个视频片段内部随机跳帧。

### 景别切换

按远景→中景→近景→特写或相反顺序逐步改变信息距离。每个景别为独立镜头，继承同一轴线、人物画面侧和动作状态。

### 反打结构

具体空间和眼线规则参见 `../perspective_language/reverse_shot.md`。反打属于独立镜头之间的关系。

## Narrative Function

- 长镜头：保留表演连续性和真实时间。
- 快切：压缩动作、增强信息密度和紧迫感。
- 景别切换：从空间建立逐步抵达情绪或细节。

## Execution Rule

先决定是否切镜。需要切镜时将每段明确编号并记录入点、动作结果和出点；不切镜时必须确保所有动作在一个可执行路径内完成。

## Seedance Execution Rule

Seedance 单次生成优先对应一个镜头。快切、景别切换和反打应先生成独立片段，再在编辑阶段组合。长镜头限制人物数量、动作节点和摄影机变化。

## Avoid And Common Failure

- 把“快切”写进单段导致画面随机跳变：拆分生成。
- 景别切换时人物方向翻转：继承轴线和画面侧。
- 长镜头同时穿越多场景：改用连续转场高级规则或拆镜。
- 动作结果不连续：记录每镜结束状态和下一镜开始状态。

## Final Principle

剪辑节奏来自独立镜头之间的明确关系，不来自单个提示词中堆叠多个景别和机位。
