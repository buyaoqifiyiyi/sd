# Movement Combination Patterns

## Usage Rule

以下模式只用于内部候选选择。每个模式必须经过`decision_engine.md`，拆分后的每个SHOT仍遵守一个主要路径。最终Prompt不得输出CMG编号或模式名称。

## Pattern Matrix

| ID | 规范模式 | 默认类别 | 镜头/路径结构 | 适用功能与稳定降级 |
|---|---|---|---|---|
| CMG-01 | 对话Coverage | C | 双人建立 → OTS/反打 → 关键反应 → 双人收束 | 普通交谈、误会、对峙；删减重复反应，保持眼线与轴线 |
| CMG-02 | 权力对峙Coverage | C | 双人关系镜头 → 强势方低角近景 → 弱势方高角近景 → 空间隔框 | 审问、谈判；角度只表达已确认关系，不把高低机位当运镜 |
| CMG-03 | 亲密细节Coverage | C | 双人中景 → 已确认手部/道具细节 → 眼神反应 → 双人近景收束 | 告白、惜别；细节必须有剧情依据，避免每个信息都切特写 |
| CMG-04 | 震惊反应递进 | C或A | 中景刺激 → 眼部/面部反应特写 → 可选短Push → 环境关系确认 | 真相揭露；精细反应优先固定特写，删掉无依据的瞳孔生理变化 |
| CMG-05 | 压抑崩溃递进 | C | 背/肩中景 → 支持性手部动作 → 侧脸反应 → 可选短弧线收束 | 悲伤失控；泪液需有形成过程，Orbit失败则固定侧脸近景 |
| CMG-06 | 黑化/决意揭示 | C | 轮廓建立 → 有依据的分区受光面部 → 短Push至眼神/行动选择 | 立场转折；灯光和表演必须来自上游，不用镜头制造未写剧情 |
| CMG-07 | 常规动作Coverage | C | 大景建立空间 → 单向冲刺/跟拍 → 交手动作镜头 → 碰撞细节 → 结果镜头 | 多人打斗；每镜只完成一个动作阶段，慢动作仅用于已确认关键结果 |
| CMG-08 | 突袭短节奏 | C | 有依据的武器/道具起手 → 低机位动作镜头 → 一次命中特写 → 拉回关系结果 | 偷袭、短打；命中与结果分开，避免一镜中跳跃、碰撞、拉远并发 |
| CMG-09 | FX动作Coverage | C/D | 空间与FX源建立 → 简单跟随/短弧线 → 施放动作 → 冲击与残留结果 | 法术/能力对决；先锁定FX生命周期，去掉多层相机运动 |
| CMG-10 | 主观记忆入口 | C/D | 面部/触发物 → 安全离镜把手 → 已确认记忆入口 | 回忆、梦境；交给Transition选择切点，不要求人物在同镜头内变成新场景 |
| CMG-11 | 地点交代跳转 | C/D | 当前地点收束 → 独立环境/方向镜头 → 新地点建立 | 室内外或跨地点；Pan只揭示当前空间，地点跳转使用已确认边界 |
| CMG-12 | 时间流逝蒙太奇 | D | 当前人物/环境 → 时间锚点系列 → 变化后的同一空间或人物 | 岁月流逝；不是单个Tilt，需已确认时间断点与可比较锚点 |
| CMG-13 | 窥视/监视视点 | A或C | 前景遮挡POV/客观窥视 → 单向轻Push聚焦目标 | 监听、监视；先确定POV归属，遮挡不得吞没关键信息 |
| CMG-14 | 宿命慢推 | A | 双人或单人中全景 → 极缓直线Push → 稳定停留 | 告别、决定、压迫；不切镜、不换侧，人物动作保持低密度 |
| CMG-15 | 第一人称恢复 | A | 已确认POV → 低幅生理性呼吸/轻微晃动 → 注视目标稳定 | 苏醒、眩晕；微动是稳定质感，不模拟失控抖动或换成他人视点 |
| CMG-16 | 追逃跟随揭示 | B或C | 中景跟跑 → 同向轻微侧移露出追兵；必要时拆为追兵反应镜头 | 逃亡、追逐；保持屏幕方向、肩侧和距离，长焦或高速时优先拆镜 |

## Selection Rule

先按Coverage Function选择候选，再决定Class。模式相似时优先信息最少、路径最单一、终点最稳定者。模式不能授权新增台词、情绪、武器、法术、泪水、光源、地点或时间变化。
