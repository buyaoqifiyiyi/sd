# Side Tracking

## 中文名称

侧向平行跟拍；侧跟镜头；平行跟拍。

## Definition

摄影机位于人物侧面，与人物行进路线大致平行，并以相同方向同步移动。核心不是单纯横移，而是在人物持续前进时保持相对距离、景别和侧面空间关系稳定。

资料术语对应：人物沿街跑动，镜头从侧面平行跟拍。

## Narrative Function

- 在不中断动作的情况下同时呈现人物、关系与环境变化。
- 维持双人并行关系，让距离、先后位置和交流自然发生。
- 交代角色从一个空间持续前往另一个空间。
- 保留步行、奔跑等动作的完整方向与节奏。

## Emotional Function

适合克制、陪伴、疏离、沉默、犹豫、关系缓慢靠近，以及具有明确方向的紧张行动。情绪主要通过步速、身体距离、短暂对视和前景变化表达，不依赖炫技运镜。

## Spatial Function

- 先锁定人物向画面左或画面右移动。
- 再锁定摄影机处于人物左侧或右侧，整个镜头保持同一侧。
- 双人镜头必须锁定 A、B 的左右或内外侧位置，不得无动作交换。
- 摄影机轨迹与人物路线平行，背景产生连续横向视差。
- 不跨越人物行进轴线或对话轴线；如需换侧，必须另起镜头设计。

## Best Use Cases

- 单人沿街道、走廊、站台或海岸行走
- 双人并肩行走或边走边说
- 人物在环境中寻找目标
- 关系从疏离到靠近的连续表演
- 中低速奔跑或稳定追踪
- 角色离开某个地点的过渡镜头

## Execution Pattern

### Start State

明确人物起始位置、行进方向、摄影机所在侧、人物与摄影机距离、初始景别和速度。例如：A 在靠建筑侧，B 在靠街道侧，两人向画面右侧行走；摄影机位于两人右侧约 3 米，保持双人中景和平视高度。

### Movement Process

人物开始移动后，摄影机沿平行路线同向侧移。保持距离、机位高度和人物画面占比基本稳定；人物减速或停步时，摄影机同步平滑减速。背景建筑、路面和前景物体应形成真实连续的横向视差。

### End State

明确摄影机与人物同步停止，或摄影机先减速停下并让人物继续前行。结束画面必须保留下一镜头需要的人物位置、面对方向、步态和空间关系。

## Character Coordination

- 人物身体主要朝行进方向，视线看前方、地面或短暂看向同伴。
- 双人保持身份、左右位置、步速和身体距离连续。
- 允许自然手势、短暂对视、轻微靠近或逐渐放慢脚步。
- 奔跑时强调真实脚步落地和身体重心，不得像跑步机或滑行。
- 不同时安排突然转身、多人交叉换位、复杂打斗和大幅机位变化。

## Speed Control

- Slow：情绪戏、重逢、沉默同行；人物与摄影机均低速稳定。
- Normal：普通步行、自然对白、进入空间；优先作为默认速度。
- Fast：奔跑或追逐；只在剧情明确需要时使用，并简化人物动作与背景复杂度。

## Lens Recommendation

- 35mm：人物与环境并重，适合街道和全身或中远景侧跟。
- 50mm：人物关系优先，适合双人中景与边走边说。
- 85mm：空间压缩和情绪更强，但容易裁切移动人物，不作为默认选择。

焦段仅表达视觉倾向；若项目未锁定技术参数，可用“自然透视的中等焦段”替代具体数值。

## Seedance Execution Rule

提示词必须同时说明：人物运动方向、摄影机所在侧、摄影机运动方向、相对距离、速度、景别、机位高度和结束方式。

单镜头只保留一个主要运镜：Side Tracking。允许极轻微的构图修正或焦点转移，但不叠加环绕、快速推拉、大幅升降或甩镜。

稳定表达公式：

`人物方向 + 摄影机侧位 + 平行同向移动 + 固定距离/景别 + 轴线限制 + 结束状态`

## Recommended Prompt Language

基础版本：

> 人物向画面右侧稳定行走，摄影机始终位于人物右侧约 3 米，与行进路线平行，同向缓慢侧跟，保持中景、平视高度和相对距离不变；不绕到人物正面，不越过 180 度轴线，镜头末尾与人物同步减速停止。

双人版本：

> A 位于靠建筑侧，B 位于靠街道侧，两人并肩向画面左侧行走。摄影机从两人街道侧以双人中景平行跟随，保持两人的左右位置和身体距离连续，让短暂对视与步速变化自然发生。

## Avoid

- 只写“摄影机跟随人物”，不说明侧位和方向
- 摄影机中途从人物一侧绕到另一侧
- 人物向右走而背景视差或摄影机轨迹无原因反向
- 双人突然交换左右位置或同时长时间正面对镜头
- 侧跟同时叠加快速推拉、环绕和大幅升降
- 为“电影感”增加无意义晃动

## Common Failure

- 人物像在跑步机上：补充真实脚步落地、摄影机沿实际路径移动、背景产生连续横向视差。
- 人物滑行或速度失配：明确人物步速与摄影机同步加减速。
- 摄影机变成正面拦截：重申“始终位于人物同一侧，不进入正面路线”。
- 双人身份或位置互换：用环境参照锁定 A、B 的内外侧位置。
- 构图漂移和肢体裁切：降低速度、扩大摄影距离或改用 35mm/50mm 倾向。

## Combination

- Side Tracking + 轻微 Rack Focus：在前后人物之间转移注意力。
- Side Tracking + Foreground Occlusion：门框、树木或路牌短暂掠过，增强空间层次。
- Side Tracking + 极轻微 Push In：仅当情绪需要靠近时使用，侧跟仍为唯一主要运镜。
- Side Tracking + 克制手持呼吸：用于纪实质感，晃动幅度必须低。

## Shot Design Selection Rule

当 STATE-06 同时出现“人物持续前进”和“关系或环境需要在运动中被观察”时，优先选择 Side Tracking。若镜头目的只是从一个静态对象转向另一个对象，选择 Pan；若需要稳定直线推进或跟随且不强调侧面关系，选择 Dolly Tracking；若要紧贴人物肩背进入空间，选择 Shoulder Follow。

## Final Principle

Side Tracking 的价值是让人物关系在真实前进过程中自然发生。方向、侧位、距离、速度和 180 度轴线必须清楚；稳定、连续、可执行优先于复杂变化。
