# Handheld

## 中文名称

手持镜头；克制手持；手持摄影。

## Definition

摄影机呈现由人体操作产生的轻微、不完全规则的呼吸式位移，用于建立纪实、在场和心理不稳定感。资料术语为“人为晃动模拟纪实感”。在 Seedance 中，默认采用克制手持，而不是剧烈抖动。

Handheld 首先是一种摄影稳定性和运动质感，不等同于任意路线。若镜头还需要跟随人物，必须另行明确单一、简单的主要路径。

## Narrative Function

- 让观众感到摄影机与事件处于同一现场。
- 在对话、追逐或突发事件中增加即时观察感。
- 表现人物无法完全控制的处境或主观压力。
- 保留动作的不完美与现实质地。
- 区分稳定秩序与失衡阶段，但不替代剧情变化。

## Emotional Function

适合紧张、焦虑、警觉、疲惫、混乱、真实和临场感。轻微手持可用于克制情绪；明显手持仅用于剧情明确的危险或追逐。晃动强度不能成为情绪表达的唯一手段。

## Spatial Function

- 先锁定摄影机站位、朝向、主体距离和人物屏幕方向。
- 手持呼吸只能在锁定构图附近小幅变化，不得无目的漂移到轴线另一侧。
- 多人场景保持 A、B 左右位置、面对方向和视线关系。
- 跟随时明确摄影机在人物前、后或侧，不使用“自由移动”一类模糊描述。
- 即使画面略有呼吸，环境结构和地平线仍应可读。

## Best Use Cases

- 紧张但克制的近距离人物观察
- 新闻、纪录或现场感场景
- 短距离追随人物进入混乱空间
- 角色听到突发信息后的不稳定反应
- 狭窄空间中的临场对话
- 动作段落中的短时补充镜头

## Execution Pattern

### Start State

明确摄影机位置、人物位置、面对方向、景别和手持强度。例如：摄影机位于 A 左前方约 1.5 米，以中近景观察 A；B 位于画面右侧，双方隔桌相对。

### Movement Process

保持主体构图和轴线，在小范围内加入轻微的上下、左右和前后呼吸式位移。若人物移动，摄影机只沿一条简单路径短距离跟随，速度与人物一致；不主动制造连续大幅晃动。

### End State

在人物动作或情绪反应完成后减弱手持幅度，落回稳定可读的结束构图。记录人物位置、朝向和动作结果供下一镜头衔接。

## Character Coordination

- 近景表演以呼吸、眼神、停顿、手部动作和轻微转身为主。
- 追随人物时，明确脚步节奏与摄影机距离，避免主体忽大忽小。
- 多人对话不因晃动改变左右位置或越过 180 度轴线。
- 不让人物默认直视摄影机，除非主观或采访语境明确要求。
- 复杂打斗应拆分为更清楚的动作段，不依赖抖动掩盖连续性。

## Speed Control

- Subtle：默认；轻微呼吸感，主体稳定，适合情绪和对话。
- Moderate：紧张现场或短距离追随；仍需保持主体可读。
- Strong：极少使用；只服务明确失控时刻，并限制镜头时长和动作数量。

## Lens Recommendation

- 28mm-35mm 倾向：现场感强，可容纳环境和身体动作；注意边缘变形。
- 35mm-50mm 倾向：人物与环境平衡，是克制手持的默认选择。
- 85mm 及以上倾向：微小晃动会被放大，除非刻意表现压迫，否则不推荐。

## Seedance Execution Rule

使用“轻微、克制、呼吸式手持”并同时说明主体保持稳定。禁止只写“镜头剧烈晃动”。单镜头主要行为应是克制手持观察，或克制手持加一条简单跟随路径；不叠加环绕、快速推拉、升降和甩镜。

稳定表达公式：

`固定空间侧位 + 主体稳定 + 轻微手持呼吸 + 简单人物动作 + 轴线不变 + 稳定结束`

## Recommended Prompt Language

静态观察版本：

> 摄影机位于 A 左前方约 1.5 米，以中近景克制手持观察。画面只有轻微呼吸式上下与左右位移，A 的脸和肩部始终保持稳定清晰；B 保持在画面右侧，双方空间关系和 180 度轴线不变，镜头末尾逐渐稳定。

短距离跟随版本：

> 摄影机在人物身后偏左约 2 米，以轻微手持质感短距离跟随人物向画面右侧前进，保持人物背部中景和环境可读；不环绕、不快速推拉、不剧烈抖动。

## Avoid

- 把手持等同于持续剧烈震动或随机漂移
- 不说明摄影机侧位、人物方向和主体距离
- 通过晃动掩盖动作、空间或人物身份不清
- 多人场景中无意越过 180 度轴线
- 同时加入环绕、快速变焦、大幅升降和甩镜
- 长焦近景配合强烈手持，导致脸部和构图失稳

## Common Failure

- 画面像地震：改为“轻微呼吸式手持，主体稳定”，降低强度。
- 主体持续出画：扩大景别、缩短路径并锁定人物画面区域。
- 变成随机运镜：明确机位侧、主要路径和结束构图。
- 空间关系混乱：加入 A、B 左右位置、面对方向和不越轴限制。
- 人物脸部模糊或变形：减少晃动、降低动作速度并避免过近长焦。

## Combination

- Handheld + Static Observation：在固定站位附近轻微呼吸，最稳定。
- Handheld + Short Follow：仅一条短距离前进路线，保持主体距离。
- Handheld + Foreground Occlusion：轻微遮挡增强在场感，不能遮住关键动作。
- Handheld + Sound Bridge：声音先行强化临场感，摄影机运动仍保持克制。

## Shot Design Selection Rule

当叙事需要“摄影机在现场、秩序略有不稳”而不是几何平滑移动时选择 Handheld。若需要稳定连续跟随，选择 Dolly Tracking 或 Side Tracking；若需要贴近人物肩背的沉浸路径，选择 Shoulder Follow，并仅把手持作为轻微质感。

## Final Principle

Handheld 的价值是可控的不完美。先保证人物、空间、方向和轴线清楚，再加入低幅度呼吸感；纪实感来自在场观察，不来自不可读的抖动。
