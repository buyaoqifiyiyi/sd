# Shoulder Follow

## 中文名称

肩背跟随；肩膀视角跟随；贴肩跟拍。

## Definition

摄影机位于人物身后并贴近一侧肩膀，以肩部、后脑或上半身作为稳定前景锚点，跟随人物向前移动。它保留第三人称摄影机位置，同时制造接近第一视角的沉浸感。

资料术语对应：“肩膀视角镜头：镜头从人物肩膀后紧随其步伐”“肩背镜头：摄影机贴近人物肩膀移动，制造第一视角沉浸感”。

## Narrative Function

- 让观众随人物进入新空间、寻找目标或接近事件。
- 同时保留人物存在感与其前方所见环境。
- 将探索过程、视线目标和空间进入动作连接在同一镜头中。
- 以人物为路径锚点，减少复杂环境中的方向迷失。
- 在不完全使用主观镜头的情况下增强参与感。

## Emotional Function

适合警觉、探索、孤独、期待、犹豫、被追踪感和进入未知空间。摄影机越贴近肩背，心理压力越强；距离略远则更偏观察与陪伴。

## Spatial Function

- 锁定摄影机在左肩后或右肩后，镜头中途不换肩。
- 锁定人物向前、向画面左前或右前的行进方向。
- 肩背作为前景锚点，前方通道、门口或目标保持在明确区域。
- 进入多人空间前先确认空间关系和关系轴线；跟随过程中不得从人物一侧穿到另一侧。
- 转弯必须有真实动作过程，摄影机沿同一路径跟随，不瞬间改变方位。

## Best Use Cases

- 人物走进房间、走廊、街巷或人群
- 人物寻找某人或接近一个目标
- 紧张探索、潜行或不确定前进
- 从人物背后观察前方事件逐渐显现
- 单人穿过复杂但连续的空间
- 用肩背锚点衔接下一镜头的视线对象

## Execution Pattern

### Start State

明确跟随哪位人物、左肩或右肩、摄影距离、人物面对方向、前方目标和初始景别。例如：摄影机位于 A 右肩后约 1 米，A 面向走廊深处，右肩和后脑占据画面右侧前景。

### Movement Process

人物向前移动，摄影机沿其后方同一路径同步跟随，保持肩部前景占比、机位高度和距离基本稳定。人物转弯时，摄影机跟随真实弧线转向，但不绕到正面或换到另一肩。

### End State

在人物停下、看到目标或到达门口时同步减速，并保持肩背与前方目标同时可读。结束构图明确人物站位、朝向、视线和目标位置，供后续反打或主观镜头衔接。

## Character Coordination

- 人物步速稳定，头部和肩部自然随步伐轻微起伏。
- 视线主要朝前方目标，不长时间回头直视摄影机。
- 开门、拨开帘子、停步或轻微侧头等动作应保持单一顺序。
- 进入多人区域时，明确 A 进入后的左右站位与面对对象。
- 不同时安排突然奔跑、快速回头、多人穿插和复杂打斗。

## Speed Control

- Slow：探索、犹豫、悬念；贴肩距离稳定，步态清楚。
- Normal：进入空间、寻找目标；作为默认速度。
- Fast：逃跑或紧迫跟随；适当拉远摄影距离并简化转弯和背景人群。

## Lens Recommendation

- 24mm-28mm 倾向：环境范围大、沉浸感强，但需控制肩背畸变。
- 35mm 倾向：肩背与前方空间平衡，优先选择。
- 50mm 倾向：更贴近人物心理，但前方视野较窄，适合简单路径。
- 长焦不适合作为默认，容易放大步伐晃动并压缩前方空间。

## Seedance Execution Rule

必须写明：人物身份、左肩或右肩、摄影机距离、人物前进方向、前方目标、跟随速度和结束状态。单镜头主要运镜只有 Shoulder Follow；可有极轻微步伐呼吸，但不叠加环绕、快速推拉、大幅升降或换肩。

稳定表达公式：

`人物身份 + 固定肩侧 + 肩背前景锚点 + 同路径向前跟随 + 目标位置 + 不换肩/不越轴 + 同步停止`

## Recommended Prompt Language

基础版本：

> 摄影机位于 A 右肩后约 1 米，右肩和后脑稳定占据画面右侧前景，以自然步速沿同一路径跟随 A 向走廊深处前进。门口目标始终位于画面左前方；不换到左肩，不绕到人物正面，不越过 180 度轴线，A 停步时摄影机同步停住。

人群版本：

> 摄影机贴近人物左肩后方，以中近距离跟随人物穿过人群，人物始终向画面右前方移动，左肩作为稳定前景锚点；背景行人只从两侧自然经过，不遮住目标，不改变人物方向和摄影机肩侧。

## Avoid

- 不说明跟随哪一侧肩膀
- 镜头中途从左肩切换到右肩或绕到正面
- 把肩背跟随写成完全第一人称，导致人物锚点消失
- 摄影机忽近忽远，肩部占比不断变化
- 人物转弯或进门时瞬移、穿模或方向反转
- 同时叠加环绕、快速推拉、升降和剧烈手持

## Common Failure

- 肩膀消失，变成主观镜头：明确肩部和后脑持续作为前景锚点。
- 摄影机换肩或越轴：重复锁定“始终位于右肩后/左肩后”。
- 人物身体比例失真：适当拉远距离，避免超广角贴得过近。
- 步伐导致剧烈抖动：使用平稳跟随，仅保留轻微自然起伏。
- 前方目标漂移：明确目标所在画面区域和镜头结束位置。

## Combination

- Shoulder Follow + Foreground Reveal：人物经过门框后逐步揭示前方空间。
- Shoulder Follow + Eyeline Target：人物停步后，目标保持在其视线前方。
- Shoulder Follow + Subtle Handheld：只增加轻微呼吸感，肩背跟随仍是主要路径。
- Shoulder Follow + Cut to POV：在结束状态明确后切入主观镜头，不在同一镜头内强行转换。

## Shot Design Selection Rule

当剧情要求观众“随人物进入或寻找”，同时又需要保留人物肩背作为身份和方向锚点时，优先选择 Shoulder Follow。若强调人物侧面关系，选择 Side Tracking；若强调几何稳定的直线推进，选择 Dolly Tracking；若完全模拟人物视线，应另选主观镜头。

## Final Principle

Shoulder Follow 的稳定性来自固定肩侧、固定距离和明确前方目标。它要让观众跟着人物进入空间，而不是让摄影机自由漂移或无理由换侧。
