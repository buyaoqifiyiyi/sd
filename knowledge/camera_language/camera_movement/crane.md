# Crane

## 中文名称

升降镜头；摇臂升降；缓慢升降镜头。

## Definition

摄影机在垂直方向上升或下降，以改变观察高度和空间覆盖范围。基础执行只选择一个主要方向：上升或下降。它不同于 Tilt；Tilt 是机位不变、只上下转动视轴，Crane 会改变摄影机实际高度。

资料术语对应：“升降镜头：镜头上下移动，展现楼层结构”“缓慢升降镜头：镜头从低处缓缓升起呈现全景”“全景拉升镜头：镜头从局部上升展示全景”。

## Narrative Function

- 从人物或局部信息逐步展开更大的环境关系。
- 从环境下降到人物，建立人物在空间中的位置。
- 展示楼层、庭院、舞台或建筑的垂直结构。
- 作为段落结尾，让人物逐渐融入环境并形成余韵。
- 用高度变化表达局部与整体、个人与群体的关系。

## Emotional Function

缓慢上升常用于释然、离开、孤独、渺小感和章节收束；缓慢下降适合进入、关注、压迫或从宏观落到具体人物。情绪来自空间尺度变化，而不是速度和炫技。

## Spatial Function

- 明确起始高度、结束高度、上升或下降方向。
- 锁定摄影机相对人物的前后侧位，不在升降途中绕轴。
- 人物的屏幕方向、左右位置和面对方向保持连续。
- 垂直运动必须揭示真实存在的空间层级，不凭空重构建筑。
- 若从人物扩展到全景，终点需交代人物在环境中的明确位置。

## Best Use Cases

- 从低位人物中景缓慢升至环境全景
- 从建筑高处下降到入口人物
- 展示楼层、庭院、舞台或人群规模
- 离别、失败或任务结束后的收束镜头
- 从局部动作揭示更大的空间后果
- 单一垂直路径的空间建立镜头

## Execution Pattern

### Start State

明确摄影机初始高度、距离、朝向、主体构图和垂直路径。例如：摄影机位于人物前侧、离地约 1.2 米，以中景观察人物站在庭院中心。

### Movement Process

摄影机沿稳定的垂直路径缓慢上升或下降，保持朝向和人物所在画面区域可控。运动过程中逐步揭示楼层、屋顶、广场或地面结构；不得同时环绕、横移或突然变焦。

### End State

到达明确高度后平滑减速并停住，形成可读的终点构图。结束画面需说明人物大小、空间范围和下一镜头所需的方向关系。

## Character Coordination

- 人物动作以站立、缓慢行走、抬头、转身或完成一个简单动作为主。
- 人物移动时必须保持原有屏幕方向，不因摄影机升降而无故反向。
- 多人场景锁定左右位置和中心关系，防止升高后人物互换或消失。
- 人物抬头看向上升摄影机仅在剧情需要时使用，避免默认直视镜头。
- 升降过程中不安排复杂打斗、快速穿插或多次队形变化。

## Speed Control

- Slow：默认选择，适合空间展开、结尾和情绪转折。
- Normal：用于清晰展示垂直结构或从环境落到人物。
- Fast：只用于明确的突发揭示；限制距离和动作复杂度，不作为默认。

## Lens Recommendation

- 24mm-35mm 倾向：空间展示和从局部扩展到全景，优先选择。
- 35mm-50mm 倾向：人物与环境平衡，适合较短升降。
- 长焦倾向：高度变化不易读且构图敏感，除非需要空间压缩，否则不推荐。

焦段为视觉倾向，不替代已确认的项目摄影参数。

## Seedance Execution Rule

必须描述：上升或下降、起始高度、结束高度、主体相对位置、速度、揭示内容和终点构图。一个镜头只执行一次主要垂直运动；不要写“上下移动”让模型往返升降。

稳定表达公式：

`起始高度/构图 + 单一垂直方向 + 稳定速度 + 逐步揭示的空间 + 结束高度/构图`

## Recommended Prompt Language

上升版本：

> 摄影机从人物前侧约 1.2 米高度的中景开始，沿垂直路径缓慢稳定上升，朝向保持不变，逐步把庭院、围墙和远处海面纳入画面，最后在高位全景平滑停住；人物始终位于庭院中心，不环绕、不横移、不越轴。

下降版本：

> 摄影机从二层高度俯看入口，沿同一垂直轴缓慢下降到平视高度，逐步把注意力从建筑结构收束到门口的 A；A 始终向画面左侧行走，镜头结束时保持人物中景和既定空间方向。

## Avoid

- 同一镜头反复上升和下降
- 不说明起始高度、结束高度和揭示对象
- 把 Crane 与 Tilt、无人机飞升或高空拉远混为一谈
- 升降同时叠加环绕、快速横移、推拉和变焦
- 无视建筑结构，让楼层或地面关系发生跳变
- 升降途中越过人物关系轴线或改变屏幕方向

## Common Failure

- 只发生视轴仰俯，没有高度变化：强调“摄影机实际垂直升高/降低”。
- 变成无人机远飞：锁定水平位置和朝向，只允许垂直路径。
- 人物在画面中消失：指定人物终点位置和终点景别。
- 建筑结构变形：减少升降距离，明确被揭示的固定空间元素。
- 速度突然变化：使用缓慢匀速，并在终点前平滑减速。

## Combination

- Crane Up + Wide Reveal：从人物扩展到环境，Crane 为唯一主要运镜。
- Crane Down + Character Emphasis：从空间下降到人物，结束后静态停留。
- Crane + Foreground Layer：升降时由栏杆、屋檐等稳定前景建立层次。
- Crane + Character Look Up：仅在叙事要求人物意识到上方信息时使用。

## Shot Design Selection Rule

当镜头目的依赖垂直空间变化、局部到整体或整体到人物的尺度转换时选择 Crane。若机位固定、只改变上下观察方向，选择 Tilt；若需要远距离飞行或鸟瞰路线，属于后续 Advanced Camera Movement，不在本文件处理。

## Final Principle

Crane 的核心是可读的单一垂直路径。高度变化必须服务空间揭示或人物尺度，且保持人物方向、空间结构和 180 度轴线连续。
