# Dolly Tracking

## 中文名称

轨道镜头；轨道移动；稳定轨道跟拍。

## Definition

摄影机沿预先确定的平滑路径进行实际空间位移，通常是直线推进、后退或同向跟随。运动具有稳定、几何清楚和速度均匀的特征。

资料术语对应：“轨道镜头：镜头沿轨道平稳推进，跟随人物”。本文件默认以单一、可读的直线轨迹为主，不处理复杂曲线、环绕或多段一镜到底。

## Narrative Function

- 稳定地陪同人物进入、穿过或离开空间。
- 以持续距离变化逐步强化人物或揭示环境。
- 保持动作完整，让观众清楚理解移动路线。
- 建立秩序、控制感、仪式感或冷静观察。
- 为连续表演提供平滑、可预测的摄影路径。

## Emotional Function

慢速轨道推进适合关注、压迫、吸引和情绪靠近；稳定平行或后退跟随适合陪伴、秩序和连续对白；较快轨道运动适合明确行动，但不应以速度替代剧情张力。

## Spatial Function

- 在镜头前锁定轨道起点、终点和唯一主要方向。
- 明确摄影机在人物前方后退跟随、人物后方向前跟随，或侧面平行移动。
- 保持摄影机与人物的相对距离或明确距离变化目标。
- 轨道不得无原因穿过人物关系轴线；多人左右位置和面对方向保持连续。
- 背景与前景应产生符合真实位移的视差，环境结构不能跳变。

## Best Use Cases

- 沿走廊、街道、站台或室内通道稳定推进
- 摄影机在人物前方后退，保持正面或三分之二侧跟随
- 摄影机在人物后方稳定跟随进入空间
- 双人连续对白中的平稳移动
- 从环境前景逐步靠近人物
- 需要精确起点、终点和构图控制的连续镜头

## Execution Pattern

### Start State

明确轨道起点、摄影机朝向、人物起点、人物运动方向、相对位置、距离和初始景别。例如：摄影机在 A 前方约 3 米，A 面向摄影机并向画面深处前进，摄影机位于同一条走廊中线。

### Movement Process

摄影机沿预定直线以均匀速度平稳移动。若跟随人物，摄影机与人物同步加速、保持和减速；若用于推进，明确距离逐渐缩短但不改变左右侧位。机位高度和朝向保持稳定，仅进行必要的轻微构图修正。

### End State

在预定位置平滑减速，形成明确结束景别和人物空间状态。结束时说明摄影机与人物距离、人物朝向、动作结果及是否共同停下。

## Character Coordination

- 人物沿单一路径步行、后退、进入或离开，动作节奏与轨道速度匹配。
- 正面后退跟随时，人物保持前进方向，不无原因转身或直冲镜头。
- 双人镜头锁定 A、B 左右位置、步速和相互视线。
- 人物停步时摄影机同步减速，避免镜头继续撞近或超越人物。
- 不同时安排多人交叉、复杂打斗、快速折返和路线改变。

## Speed Control

- Slow：情绪推进、仪式感、压迫或进入关键空间。
- Normal：步行跟随、对白和环境进入；默认速度。
- Fast：明确行动或追赶；缩短路径、扩大景别并减少人物动作数量。

## Lens Recommendation

- 24mm-35mm 倾向：强化空间视差和推进感，适合走廊与环境进入。
- 35mm-50mm 倾向：人物比例自然，适合中景跟随和对白。
- 85mm 及以上倾向：空间压缩强、距离控制敏感，不作为默认选择。

## Seedance Execution Rule

必须明确：轨道起点、终点、单一方向、摄影机在人物前/后/侧、速度、相对距离、景别变化和停止方式。单镜头只设置一个主要运镜：一条轨道路径；不叠加环绕、升降、甩镜、快速变焦或多次方向反转。

稳定表达公式：

`轨道起点 + 前/后/侧位置 + 单一直线路径 + 与人物速度关系 + 距离/景别目标 + 轴线限制 + 终点`

## Recommended Prompt Language

前方后退跟随版本：

> 摄影机位于 A 前方约 3 米，沿走廊中线以稳定正常速度向后直线移动，A 同步向前行走；始终保持人物中景、平视高度和约 3 米距离，A 的行进方向不变，摄影机不横移、不环绕、不越过关系轴线，A 停下时镜头同步平滑停住。

稳定推进版本：

> 摄影机从门外的中远景开始，沿一条直线轨道缓慢推进到室内人物的中景，机位高度和朝向保持不变，前景门框产生自然视差；人物保持原位并面向画面左侧，镜头不升降、不变焦、不绕拍。

## Avoid

- 只写“轨道镜头”而不说明前、后、侧和运动方向
- 同一镜头内先推进、再横移、再环绕
- 摄影机速度与人物步速失配或超越人物
- 用 Zoom 替代摄影机真实位移
- 无原因越过 180 度轴线或改变人物屏幕方向
- 把复杂曲线、一镜多场景穿越纳入基础轨道镜头

## Common Failure

- 画面只有缩放没有视差：强调摄影机沿真实空间直线移动，前后景产生连续视差。
- 摄影机忽近忽远：锁定相对距离或明确唯一的距离变化目标。
- 人物像滑行：补充真实步态、脚步落地和同步速度。
- 轨道变成环绕：指定直线路径、固定侧位和不绕拍。
- 终点失控：明确停止标记、终点景别和人物动作结果。

## Combination

- Dolly Tracking + Foreground Parallax：门框、柱子或路牌建立真实位移感。
- Dolly In + Static Character：人物不动，摄影机沿直线缓慢靠近；不使用变焦。
- Dolly Back + Walking Character：摄影机前方后退跟随，保持固定距离。
- Dolly Tracking + Rack Focus：在单一路径中进行一次必要焦点转移，轨道运动仍为主。

## Shot Design Selection Rule

当镜头需要“几何稳定、路径清楚、可精确控制的实际位移”时选择 Dolly Tracking。若重点是人物侧面并行关系，选择 Side Tracking；若需要更贴近肩背的沉浸感，选择 Shoulder Follow；若机位固定只转动视线，选择 Pan；若需要垂直高度变化，选择 Crane。

## Final Principle

Dolly Tracking 的核心是预先确定的一条稳定路径。起点、终点、方向、相对距离和人物速度必须可验证；轨道感来自真实视差和连续空间，不来自缩放或复杂混合运镜。
