# Tilt

## 中文名称

仰俯摇镜；垂直摇镜；Tilt Up / Tilt Down。

## Definition

摄影机物理位置保持固定，只绕水平轴向上或向下转动视轴。Tilt 改变观察方向，不改变摄影机高度；摄影机实际升高或降低应使用 Crane。

## Narrative Function

- 从脚步、道具或人物局部向上揭示完整人物。
- 从人物视线向上方建筑、天空或目标转移注意力。
- 从高处信息向下落到人物或地面结果。
- 在固定观察点内交代垂直空间关系。

## Execution Pattern

先锁定固定机位、起始朝向、向上或向下的单一方向、速度和终点主体。人物左右位置、面对方向和关系轴线保持不变；到达终点前平滑减速并稳定停住。

稳定表达公式：

`固定机位 + 起始主体/朝向 + 单向 Tilt Up 或 Tilt Down + 终点主体/朝向 + 平滑停住`

## Seedance Execution Rule

单镜头只执行一次单向仰摇或俯摇。不与升降、横移、推拉、环绕或变焦叠加；若需要摄影机真实改变高度，改用 Crane。

## Recommended Prompt Language

> 摄影机固定在人物正前偏左位置，从 A 手中的信封开始，以缓慢匀速向上仰摇，沿 A 的手臂抵达面部中近景并平滑停住；摄影机位置和高度不变，不推进、不升降、不越轴。

## Avoid

- 把 Tilt 写成摄影机上下移动
- 同一镜头先仰摇再俯摇
- 不说明起点、方向或终点
- 仰俯摇动造成空间方向、人物身份或轴线翻转

## Final Principle

Tilt 是固定机位上的垂直视线转移。方向、落点与停止状态必须可读。
