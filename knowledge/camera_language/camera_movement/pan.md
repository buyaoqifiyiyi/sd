# Pan

## 中文名称

水平摇镜；横摇；摇镜头。

## Definition

摄影机机位基本固定，只绕垂直轴水平转动视线，从画面左侧摇向右侧，或从右侧摇向左侧。它改变观察方向，不改变摄影机的实际空间位置。

资料中的“摇镜头：镜头从左向右平移，展示城市天际线”在执行层统一解释为水平转动视轴；如果摄影机本体发生侧向位移，应改用 Side Tracking 或 Dolly Tracking。

## Narrative Function

- 从一个主体发现另一个主体或重要信息。
- 沿人物视线揭示其正在观看的对象。
- 在同一机位内交代连续空间或环境范围。
- 跟随一个短距离横向动作，同时保留空间方位。
- 用起点与终点建立因果、对照或注意力转移。

## Emotional Function

慢速 Pan 适合观察、等待、发现与空间揭示；正常速度适合人物入画和视线转移；快速摇镜会增强惊讶和急迫，但执行不稳定，只在剧情必需时采用。

## Spatial Function

- 机位固定，先锁定起始朝向与结束朝向。
- 明确从左向右或从右向左，禁止中途无原因反向。
- 起点主体与终点主体必须处于可理解的同一空间。
- 多人场景保持人物左右位置、面对方向和 180 度轴线一致。
- Pan 不应被描述成横向平移；画面变化来自视轴旋转和边缘视差。

## Best Use Cases

- 从空环境摇到进入画面的人物
- 从人物表情摇到其视线目标
- 展示城市天际线、房间布局或队列关系
- 跟随人物短距离横穿画面
- 在同一空间连接 A 与 B
- 用结尾落点揭示关键信息

## Execution Pattern

### Start State

明确固定机位、初始朝向、起点主体位置、摇镜方向、终点主体和构图。例如：摄影机固定在街角，先对准画面左侧的空街道，人物将从左侧进入。

### Movement Process

摄影机平滑地绕垂直轴水平转动，机位高度、焦段和物理位置保持不变。若跟随人物，人物横向速度与摇镜角速度匹配；若用于揭示，转动途中不增加无关停顿和第二次反向。

### End State

在预定主体或环境信息上平滑减速并稳定停住，形成清晰的结束构图。结束方向应为下一镜头提供明确视线或空间依据。

## Character Coordination

- 人物横穿画面时，先明确从左到右或从右到左。
- 用视线引导摇镜时，人物先看向目标，摄影机再顺势转向目标。
- 双人关系中保持 A、B 原有左右位置，不用摇镜偷偷越轴。
- 人物可入画、停下或离开，但不同时安排复杂折返和多人交叉。

## Speed Control

- Slow：空间揭示、观察、情绪等待；缓慢均匀，在落点前减速。
- Normal：人物入画、对白注意力转移；自然且明确。
- Fast：突发信息或快速寻找；只允许短角度单向摇动，避免甩镜式模糊。

## Lens Recommendation

- 24mm-35mm 倾向：展示较宽空间，摇动幅度应更克制，避免边缘畸变过强。
- 35mm-50mm 倾向：人物与空间平衡，适合作为默认范围。
- 85mm 及以上倾向：视野窄、摇动更敏感，仅适合短角度精确跟随。

焦段未被项目确认时，描述视觉效果，不强制虚构设备参数。

## Seedance Execution Rule

必须明确“摄影机位置保持固定”，并写出起点、方向、速度、终点和停住对象。单镜头只设置一个主要运镜：一次水平 Pan；不叠加横移、推拉、升降、环绕或变焦。

稳定表达公式：

`固定机位 + 起始主体/朝向 + 单向水平转动 + 结束主体/朝向 + 平滑停住`

## Recommended Prompt Language

环境揭示版本：

> 摄影机固定在屋顶边缘，保持同一高度和位置，从左向右缓慢水平摇镜，依次展示连续的城市天际线，最后在远处亮起灯光的塔楼上平滑减速并停住；不横移、不推进、不升降。

视线揭示版本：

> 人物先看向画面右侧，摄影机从人物中近景开始，机位保持固定，沿其视线向右缓慢摇动，最后落在门口刚出现的 B 身上并稳定停住；保持人物空间关系和 180 度轴线不变。

## Avoid

- 把 Pan 写成摄影机沿水平方向移动
- 不说明起点、终点或摇镜方向
- 左右来回摆动、途中多次反向
- 同时加入推近、横移、升降或环绕
- 通过摇镜跨到人物关系轴线另一侧
- 大角度快速甩镜导致主体丢失和背景模糊

## Common Failure

- 生成横移而非摇镜：强调“机位固定，只水平转动视轴”。
- 终点没有落在目标上：明确终点主体、画面位置和停住时长。
- 摇镜忽快忽慢：指定匀速转动并在终点前平滑减速。
- 人物出画或构图漂移：缩短摇镜角度，使用更宽的视觉范围。
- 空间方向反转：重申人物屏幕方向和关系轴线保持不变。

## Combination

- Pan + Eyeline Match：先人物视线，再摇向被观察对象。
- Pan + Reveal：通过前景边缘逐步揭示空间或角色。
- Pan + Rack Focus：仅在终点主体进入画面后进行一次轻微焦点转移。
- Pan + Static Hold：摇镜结束后保持稳定观察，便于剪辑衔接。

## Shot Design Selection Rule

当镜头目的为“固定观察点内的注意力转移或空间揭示”时选择 Pan。若摄影机需要与人物一起移动，改用 Tracking、Side Tracking 或 Dolly Tracking；若需要改变垂直高度，选择 Crane。

## Final Principle

Pan 的核心是固定机位上的单向视线转移。起点、方向、落点和停止必须明确；不把水平转动与摄影机横移混为一谈。
