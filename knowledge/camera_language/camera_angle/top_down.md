# Top Down

## 中文名称

垂直俯拍；顶视镜头；天花板俯拍。

## Definition

摄影机位于主体正上方或接近正上方，视轴近似垂直向下，使人物、道具和地面关系呈现平面化构图。资料对应“从屋顶拍摄下方，营造孤独感”。Top Down 强调近 90 度俯视和局部空间几何，不等同于斜向 High Angle，也不等同于城市尺度的 Bird's Eye View。

## Narrative Function

- 清楚展示人物、道具、路线和地面几何关系。
- 表现人物被困、孤立、失去方向或成为空间中的一点。
- 展示桌面、床面、房间或小型行动区域。
- 用平面图式构图组织多人位置。

## Emotional Function

适合孤独、宿命、被观察、秩序、失控和抽离。规则排列可产生冷静秩序；人物独处在大面积负空间中可强化孤立。

## Spatial Function

- 明确摄影机正上方对应的地面中心和画面朝向。
- 锁定画面上方对应空间中的哪一方向，避免人物左右与前后混乱。
- 人物路线必须在地面平面上清楚可追踪。
- 多人保持位置、距离和交叉顺序，不通过俯拍隐藏 180 度轴线问题。

## Best Use Cases

- 房间、床铺、桌面或狭小区域的顶视构图
- 人物独处在大面积地面负空间中
- 多人队形、包围或行动路线
- 道具摆放和手部动作关系
- 人物倒下、停留或缓慢穿过画面

## Execution Pattern

### Start State

明确地面坐标、人物位置、面对方向、画面顶部所对应的空间方向和摄影机高度。

### Movement Process

默认摄影机固定垂直向下，让人物沿一条清楚路线完成单一动作。若需移动，只允许缓慢升高、降低或平移中的一项，并保持视轴垂直和空间朝向不变。

### End State

人物到达明确地面位置或动作完成后保持顶视构图，记录人物朝向、道具位置和下一镜头需要的空间方向。

## Character Coordination

- 人物沿可读路线步行、躺下、坐起或移动道具。
- 不安排多次交叉换位、复杂打斗或无路线的随机移动。
- 多人用服装、位置或道具锁定身份，避免从顶部看时身份互换。
- 肢体与地面接触自然，不出现穿透或异常缩短。

## Angle Intensity Control

- Near Top Down：接近垂直，仍保留少量人物侧面体积。
- True Top Down：视轴近 90 度向下，强调平面几何。
- High Aerial Top Down：覆盖城市或广场的大尺度建立，应改用 Bird's Eye View。

## Lens Recommendation

- 24mm-35mm 倾向：覆盖完整局部空间，注意边缘人物畸变。
- 35mm-50mm 倾向：适合桌面、床面和较小区域。
- 长焦倾向：适合较高位置压缩平面，但不利于展示完整路线。

## Seedance Execution Rule

必须说明摄影机垂直向下、地面朝向、人物起点、路线、终点和画面边界。单镜头只设置一个主要机位逻辑，不同时旋转、环绕、飞升和切换角度。

## Recommended Prompt Language

> 摄影机固定在房间中央正上方，视轴垂直向下。画面上方对应房门方向，A 从画面下方缓慢走到床边并停下；床、桌子和门的位置保持不变，A 的路线连续，不旋转画面、不改变高度、不越过既定空间方向。

## Avoid

- 未定义画面顶部对应的真实空间方向
- 顶视过程中画面自动旋转或变成斜俯
- 人物路线跳跃、穿过家具或突然换向
- 多人从顶部看时身份互换或肢体融合
- 同时加入旋转俯拍、无人机飞行和复杂升降

## Common Failure

- 变成普通高角度：强调视轴近 90 度垂直向下。
- 画面方向旋转：锁定门、道路或桌边作为方向参照。
- 人物像贴纸：降低高度或保留自然阴影和身体体积。
- 空间重构：列出固定家具、地面和人物终点位置。

## Combination

- Top Down + Static Blocking：通过人物路线和负空间表达关系。
- Top Down + Slow Pedestal：只进行轻微垂直高度变化，视轴保持向下。
- Top Down + Match on Action：在手部或脚步动作完成处切换角度。

## Shot Design Selection Rule

当镜头需要以平面几何展示人物、道具和路线时选择 Top Down。若仍需看见人物面部或侧面体积，选择 High Angle；若覆盖城市、广场或大规模人群，选择 Bird's Eye View。

## Final Principle

Top Down 的核心是固定空间坐标和垂直视轴。画面方向、人物路线和道具位置必须先被锁定，旋转俯拍留给后续高级镜头层。
