# High Angle

## 中文名称

高角度镜头；俯拍镜头。

## Definition

摄影机位于人物视线高度以上，以斜向下的视轴拍摄主体。资料对应“俯视人物内心挣扎的状态”。High Angle 保持人类尺度和斜向观察，不等同于接近 90 度的 Top Down，也不等同于城市尺度的 Bird's Eye View。

## Narrative Function

- 显示人物在环境中的弱势、受困或孤立。
- 清楚交代人物、道具和周围空间的相对位置。
- 观察人物选择、停顿或失败后的状态。
- 在多人场景中展示包围、距离或队形关系。

## Emotional Function

适合脆弱、孤独、犹豫、受压、被观察和无力感。轻度高角度也可用于中性空间说明，不应把所有俯拍都解释为弱势。

## Spatial Function

- 明确摄影机高于主体的程度和所在前、后、左、右侧。
- 保持人物面对方向、左右位置和视线关系连续。
- 地面、家具、道路或环境参照必须稳定，帮助读懂距离。
- 不在俯拍过程中越过对话或行动轴线。

## Best Use Cases

- 人物独处、挣扎、失败或被围困
- 展示人物与房间、道路或道具的位置关系
- 对峙中的弱势一方
- 角色停留在大空间中的孤立构图
- 从环境观察人物完成简单动作

## Execution Pattern

### Start State

明确人物站位、朝向、摄影机高度和轴线侧。例如：A 位于房间左侧，面向画面右侧的门；摄影机位于 A 右前上方。

### Movement Process

保持斜向下视轴和稳定侧位，让人物完成步行、坐下、停顿或拾取道具等单一动作。默认静态观察；如有运镜，只设置一个缓慢且明确的主要运动。

### End State

在人物动作结果和空间关系清楚后停住，保留人物位置、面对方向、道具状态和下一镜头的轴线依据。

## Character Coordination

- 人物视线指向真实目标，不无理由抬头直视摄影机。
- 肢体动作保持自然，避免因俯角造成头大身小或身体缩短。
- 多人镜头锁定 A、B 的左右和前后关系。
- 情绪通过停顿、肩膀下沉、步速和视线表达，不自动增加夸张表演。

## Angle Intensity Control

- Mild：略高于眼平，适合中性观察和轻微心理弱势。
- Moderate：明显高位斜俯，适合空间关系与孤立感。
- Extreme：接近垂直俯拍时应改用 Top Down，避免概念混用。

## Lens Recommendation

- 28mm-35mm 倾向：空间关系清楚，注意人物头部和边缘畸变。
- 35mm-50mm 倾向：人物比例与环境平衡，作为默认选择。
- 70mm 以上倾向：压缩地面关系，适合较远观察但不利于空间展开。

## Seedance Execution Rule

必须说明摄影机在人物哪一侧上方、俯角强度、人物位置、面对方向和地面参照。单镜头只保留一个主要机位逻辑，不叠加大幅升降、环绕、快速推拉或轴线切换；复杂旋转俯拍留给高级镜头层。

## Recommended Prompt Language

> 摄影机位于 A 右前上方约 3 米，以中等高角度斜向下观察房间。A 位于画面左侧，身体面向画面右侧的门，缓慢坐到椅子上；桌面与门的位置保持固定，A 不抬头看镜头，摄影机静止并保持 180 度轴线不变。

## Avoid

- 把高角度写成完全垂直俯拍
- 不说明摄影机处于人物哪一侧
- 人物头部异常放大、身体比例被压短
- 地面结构、家具位置或道路方向跳变
- 多人镜头因俯拍而互换左右位置

## Common Failure

- 变成 Top Down：降低俯角，保留人物正面或侧面可读性。
- 人物像缩小模型：减少高度并保留自然透视。
- 角色抬头直视镜头：明确视线目标在环境内。
- 空间方向混乱：加入地面参照和轴线侧说明。

## Combination

- High Angle + Static Observation：适合孤立或挣扎状态。
- High Angle + Slow Pull Out：仅在环境逐渐压过人物时使用。
- High Angle + Foreground Frame：栏杆或楼梯边缘强化被观察感。

## Shot Design Selection Rule

当镜头需要在人物尺度内表现弱势、孤立或更清楚的空间关系时选择 High Angle。若要用平面化构图展示人物与地面几何关系，选择 Top Down；若要建立城市或广场整体规模，选择 Bird's Eye View。

## Final Principle

High Angle 是有侧位的斜向俯视。它必须让人物状态与空间关系更清楚，而不是仅靠高机位强行赋予弱势含义。
