# Vertical Upward

## 中文名称

垂直仰拍；仰顶镜头；天井向上镜头。

## Definition

摄影机位于空间底部或主体下方，视轴近似垂直向上，拍摄天空、天井、井口、屋顶结构、树冠或高处目标。资料对应“从建筑中央垂直向上拍摄天空”。它不同于 Low Angle：Low Angle 通常以斜向上视轴观察人物或建筑，Vertical Upward 以近 90 度向上视轴强调垂直空间中心。

## Narrative Function

- 建立天井、井口、楼梯井或树冠等垂直空间结构。
- 表现出口、希望、压迫顶部或遥不可及的目标。
- 让人物视线或动作连接到上方空间。
- 用几何中心完成场景建立或转场依据。

## Emotional Function

适合希望、敬畏、困住、眩晕、封闭与向上渴望。明亮天空中心可产生出口感；封闭屋顶或高墙可产生压迫感。

## Spatial Function

- 明确摄影机位于何处底部、镜头中心对应什么上方目标。
- 锁定建筑边缘、墙体、树冠或井口的方位与对称关系。
- 若人物进入画面边缘，说明其左右位置、朝向和上望目标；由人物镜头切入时保持视线匹配和既定 180 度轴线。
- 画面不自动旋转，空间顶部结构保持稳定。

## Best Use Cases

- 天井中央向上看天空
- 井底、楼梯井或峡谷底部向上观察
- 建筑穹顶、树冠或高处目标建立
- 人物抬头后的视线镜头
- 表现出口、压迫或垂直尺度

## Execution Pattern

### Start State

明确摄影机在空间底部的中心或偏侧位置、视轴方向、上方目标和固定建筑参照。

### Movement Process

默认摄影机固定垂直向上，让云、光线、树叶或高处人物进行简单运动。若需镜头运动，只允许缓慢旋转以外的单一轻微变化；旋转仰拍另属高级镜头。

### End State

在上方目标、光线变化或人物视线信息清楚后保持稳定画面，记录结构方向和光源位置。

## Character Coordination

- 地面人物若出现，只占画面边缘并明确向上看，不无理由俯视摄影机。
- 高处人物站位、栏杆和身体方向必须符合真实建筑结构。
- 云、树叶或光影运动保持缓慢，不与建筑方向矛盾。
- 不同时安排多人从不同边缘无序探入画面。

## Angle Intensity Control

- Steep Upward：大角度仰拍但保留部分人物或墙面纵深。
- True Vertical Upward：视轴近 90 度向上，以天空或顶部结构为中心。
- Rotating Upward：旋转仰拍稳定性较低，留给 Advanced Camera Movement。

## Lens Recommendation

- 16mm-24mm 倾向：强化天井、穹顶和垂直空间，注意边缘拉伸。
- 24mm-35mm 倾向：结构更自然，作为默认选择。
- 50mm 以上倾向：只截取顶部局部，不利于建立完整空间。

## Seedance Execution Rule

必须说明摄影机位于空间底部、视轴垂直向上、中心目标、周围结构和光源方向。单镜头只设置一个主要机位逻辑，禁止自动旋转、飞升、穿顶、环绕或改变建筑结构。

## Recommended Prompt Language

> 摄影机固定在方形天井底部中央，视轴垂直向上，蓝色天空位于画面中心，四面墙体和窗框形成稳定对称边界。云层缓慢经过，右上方阳光照入；摄影机不旋转、不升高、不穿过屋顶，建筑结构和光线方向保持一致。

## Avoid

- 把垂直仰拍写成普通人物低角度
- 画面无原因旋转或建筑边缘不断变形
- 摄影机飞升穿过天井或屋顶
- 高处人物位置不符合栏杆和楼层结构
- 同时加入旋转、升降、穿越和变焦

## Common Failure

- 变成斜向 Low Angle：强调视轴近 90 度向上、天空居中。
- 建筑像隧道融化：锁定墙面、窗框和中心几何。
- 画面自动旋转：明确摄影机固定、方向不变。
- 光源跳变：指定阳光进入的固定方位。

## Combination

- Vertical Upward + Static Geometry：最稳定，依靠结构和光线表达空间。
- Vertical Upward + Eyeline Match：先人物抬头，再切到垂直仰拍。
- Vertical Upward + Natural Motion：只让云、树叶或光影缓慢变化。

## Shot Design Selection Rule

当镜头目的依赖天井、井口、穹顶或天空中心的垂直结构时选择 Vertical Upward。若主要拍摄完整人物或建筑立面，选择 Low Angle；若要让摄影机向上飞升或旋转，进入 Advanced Camera Movement 层。

## Final Principle

Vertical Upward 的核心是稳定的垂直视轴和可验证的顶部结构。天空、光源、建筑边缘和人物位置必须保持方向一致，运动复杂度从简。
