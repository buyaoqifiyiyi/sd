# Bird's Eye View

## 中文名称

鸟瞰镜头；高空俯视建立镜头。

## Definition

摄影机位于显著高于场景的位置，以广阔视野俯视城市、街区、广场、自然地貌或大规模人群。资料对应“从高空俯拍城市街区，车流穿梭，建筑鳞次栉比”。基础层只定义固定或极缓慢的高空建立视角，不包含无人机飞行、旋转俯拍或高空拉远路径。

## Narrative Function

- 建立地点、规模、路线和群体分布。
- 把个体放入更大的城市、自然或事件系统。
- 交代车流、人流、道路和建筑组织。
- 在段落开始或结束提供宏观空间信息。

## Emotional Function

适合宏大、秩序、疏离、孤独、客观观察和命运感。人物越小，情绪越偏抽离；需要人物表演时不应使用过高视角。

## Spatial Function

- 明确城市道路、广场、海岸或建筑的主方向。
- 锁定摄影机高度、朝向和画面中心区域。
- 人流、车流和人物运动方向必须遵循真实路径。
- 若有主角，说明其在画面中的明确位置、颜色或路线，避免消失；切入地面镜头时保持已建立的屏幕方向和 180 度轴线。

## Best Use Cases

- 城市、街区、港口、广场或自然地貌建立
- 展示人群、车流或队伍组织
- 个体进入大空间后的渺小感
- 场景段落的开场或收束
- 清楚说明多条道路和目的地关系

## Execution Pattern

### Start State

明确高空位置、俯视方向、主要地标、道路方向和主角位置。基础版本默认摄影机已经处于稳定高位。

### Movement Process

摄影机保持固定或只进行极缓慢、单一方向的构图调整。人物、车流或人群沿真实路线移动；不执行飞越、盘旋、俯冲或升空。

### End State

在地标、主角路线或人群组织清楚后保持稳定建立画面，记录关键方向供下一镜头进入地面空间。

## Character Coordination

- 主角动作简化为沿明确路线行走、停下或进入建筑。
- 用服装颜色、位置或独立路线区分主角，不依赖面部识别。
- 人群和车辆保持合理间距，不瞬移、不相互穿透。
- 下一镜头的人物屏幕方向应与鸟瞰建立的路线一致。

## Angle Intensity Control

- Elevated Establishing：明显高位但仍能看见建筑立面，空间较易读。
- Bird's Eye：高空广域俯视，人物成为环境中的小尺度主体。
- Extreme Aerial：超高空、飞行或大范围拉远属于 Advanced Camera Movement。

## Lens Recommendation

- 24mm-35mm 倾向：覆盖大范围环境，需保持建筑线条稳定。
- 35mm-50mm 倾向：压缩范围，突出街区或广场内部组织。
- 超长焦俯瞰属于另一种压缩美学，不作为基础默认。

## Seedance Execution Rule

必须说明摄影机为稳定高空视角、场景主方向、关键地标、主角位置和群体路线。单镜头只设置一个主要行为：固定鸟瞰或极缓慢构图调整；不加入无人机飞行、旋转、俯冲、穿楼和高空拉远。

## Recommended Prompt Language

> 稳定的高空鸟瞰视角俯视城市广场，画面上方为北侧主入口，主道路从左下延伸到右上。人群沿既定通道缓慢流动，A 穿深色外套，从广场左侧入口向中央喷泉行走；摄影机高度和朝向保持固定，不飞行、不旋转、不拉远。

## Avoid

- 把 Bird's Eye 自动写成无人机飞行
- 不说明道路、地标和画面方向
- 主角过小且没有位置或视觉识别点
- 车流、人流无路线地随机移动或穿模
- 同时加入盘旋、俯冲、升空和旋转

## Common Failure

- 变成移动航拍：强调稳定高位、摄影机固定。
- 城市结构融化：减少覆盖范围，锁定道路和地标。
- 主角消失：指定入口、路线、服装颜色和终点。
- 下一镜头方向反转：用同一道路方向建立屏幕运动连续性。

## Combination

- Bird's Eye + Static Establishing：最稳定，交代地点和规模。
- Bird's Eye + Crowd Choreography：人群沿清晰路线运动，摄影机不动。
- Bird's Eye + Direct Cut：切入与已建立方向一致的地面镜头。

## Shot Design Selection Rule

当镜头目的为建立城市、广场、自然环境或群体规模时选择 Bird's Eye View。若只展示房间或局部地面几何，选择 Top Down；若需要飞行路线或高空拉远，进入 Advanced Camera Movement 层。

## Final Principle

Bird's Eye View 是宏观空间建立，不等于无人机炫技。基础执行先锁定高度、朝向、道路、地标和主角路线，再保持摄影机稳定。
