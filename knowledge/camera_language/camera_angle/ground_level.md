# Ground Level

## 中文名称

地面机位；贴地视角；地面低机位。

## Definition

摄影机接近地面，以极低高度观察脚步、车轮、草丛、地面纹理或从下方经过的主体。资料对应“从草丛中仰拍人物奔跑的脚步”和“镜头从地面看人物鞋底经过”。Ground Level 强调贴地空间和运动接触，不等同于普通 Low Angle。

## Narrative Function

- 强调脚步、追逐、到达或离开的动作结果。
- 让地面材质、障碍和速度成为叙事信息。
- 隐藏人物全貌，制造等待、危险或神秘感。
- 用局部动作衔接人物进入下一空间。

## Emotional Function

适合紧张、逼近、潜伏、重量感、速度和未知。静态贴地观察可制造等待；快速脚步经过可增强突发感，但动作仍需可读。

## Spatial Function

- 明确摄影机在道路、门口、草丛或人物行进路线的哪一侧。
- 锁定人物从画面左到右、右到左、朝向或远离摄影机。
- 说明摄影机与脚步路线的安全距离，避免人物穿过摄影机位置。
- 地面纹理、门槛和环境方向必须连续；涉及连续人物镜头时保持既定 180 度轴线。

## Best Use Cases

- 人物脚步进入或离开画面
- 奔跑、追逐、巡逻或接近门口
- 鞋底、车轮、雨水和地面道具特写
- 草丛或低矮遮挡后的观察
- 动作衔接和地点建立

## Execution Pattern

### Start State

明确摄影机贴地位置、人物起点、行进方向、脚步与镜头的最近距离。例如：摄影机位于道路右侧贴地，A 将从画面左侧跑向右侧。

### Movement Process

默认摄影机静止，让脚步或物体按单一方向经过；若需跟随，只允许低速短距离侧跟。保持真实落地、重心和地面接触，不让鞋底穿透镜头或地面。

### End State

人物脚步离开、停下或落在明确位置后保持地面构图，记录人物最终方向、脚的位置和关键道具状态。

## Character Coordination

- 步态、落脚、溅水或跨过门槛必须有开始、过程和结果。
- 人物不突然改变行进方向或无动作停步。
- 多人脚步需锁定先后、左右和身份特征，避免腿部混合。
- 局部镜头不承担复杂表演，情绪由节奏、力度和声音体现。

## Angle Intensity Control

- Near Ground：离地约膝部以下，保留小腿与环境，稳定性较高。
- Ground Level：接近地面，突出鞋、地面和经过动作。
- Extreme Underfoot：鞋底正上方经过，穿模风险高，仅在明确需要时使用。

## Lens Recommendation

- 24mm-35mm 倾向：强化近距离动作和地面纵深，注意鞋脚畸变。
- 35mm-50mm 倾向：动作比例较自然，适合门槛或脚步细节。
- 长焦不利于贴地空间读解，通常不作为默认。

## Seedance Execution Rule

必须说明摄影机贴地位置、人物经过方向、最近距离、动作速度和结束落点。单镜头只设置一个主要机位行为：静态经过或短距离贴地跟随；不叠加环绕、升降、快速推拉和方向反转，复杂贴地穿越留给高级镜头层。

## Recommended Prompt Language

> 摄影机固定在湿润街道路面右侧、接近地面高度，A 的双脚从画面左侧向右侧正常跑过，脚步真实落地并溅起少量水花，鞋底与镜头保持安全距离；背景道路方向不变，不穿模、不反向，A 离开画面右侧后镜头保持半秒。

## Avoid

- 不说明人物从哪个方向经过
- 鞋底正面撞向摄影机或穿过镜头
- 人物脚步滑行、悬浮或步态循环错误
- 多人腿部融合、身份和先后关系混乱
- 贴地机位叠加复杂高速运镜

## Common Failure

- 脚步像滑动：强调脚跟/前掌真实落地与重心转移。
- 镜头变成普通低角度全身：降低机位并限定局部构图。
- 鞋脚畸变：拉远安全距离，减少超广角倾向。
- 行进方向跳变：重复锁定从左到右或从右到左。

## Combination

- Ground Level + Static Pass：最稳定，用人物经过完成动作。
- Ground Level + Foreground Grass：草叶轻微遮挡，不能遮住关键脚步。
- Ground Level + Match on Action：脚步落地处切入下一镜头。

## Shot Design Selection Rule

当叙事重点是地面接触、脚步、速度或被隐藏的进入动作时选择 Ground Level。若仍需完整人物和权力表达，选择 Low Angle；若摄影机垂直向上看天空或井口，选择 Vertical Upward。

## Final Principle

Ground Level 必须让地面接触和运动方向可读。贴地不是为了奇观，而是为脚步、速度、环境材质或进入动作提供明确叙事信息。
