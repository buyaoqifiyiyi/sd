# Low Angle

## 中文名称

低角度镜头；仰拍镜头。

## Definition

摄影机位于主体视线高度以下，以斜向上的视轴拍摄人物、建筑或物体。资料对应“仰拍高大建筑，增强压迫感”和“人物仰望高楼，背景建筑压迫感强”。Low Angle 是相对人物或主体的低机位，不等同于贴地机位，也不等同于垂直朝天拍摄。

## Narrative Function

- 强化人物权力、威胁、决心或体量。
- 让建筑、机器或障碍成为主导视觉力量。
- 从弱势观察者的位置观看更强势主体。
- 在角色完成决定后强化其状态变化。

## Emotional Function

适合压迫、敬畏、危险、崇高、决心和不安。角度越低、越靠近主体，视觉力量越强；日常对白只宜使用轻度低角度。

## Spatial Function

- 明确摄影机低于谁、位于主体前方或哪一侧。
- 锁定人物左右位置、面对方向、视线和关系轴线。
- 背景建筑或天花板只能来自真实空间，不得凭空改变结构。
- 多人镜头不因低角度而让双方同时无理由面向摄影机。

## Best Use Cases

- 强势人物出场或作出决定
- 人物面对高楼、巨型结构或威胁
- 对峙中的权力倾斜
- 英雄性但克制的动作完成
- 环境压迫人物的主观感受

## Execution Pattern

### Start State

明确主体位置、人物面对方向、摄影机高度、距离和所在轴线侧。例如：摄影机位于 A 左前方、低于胸口高度，A 面向画面右侧的高楼。

### Movement Process

保持低机位和斜向上视轴，人物完成一个简单、连续动作。默认摄影机静止；若需移动，只允许一项轻微主要运镜，并保持原有侧位与角度。

### End State

在人物动作或视线落点完成后保持稳定构图，记录人物方向、姿态和空间位置供下一镜头继承。

## Character Coordination

- 人物视线看向对手、目标或高处对象，不默认直视摄影机。
- 动作以抬头、站定、迈步、转向目标或握紧道具为主。
- 多人对峙保持 A、B 左右位置和相互视线。
- 避免人物过度后仰或下巴、鼻孔被极端夸大。

## Angle Intensity Control

- Mild：略低于眼平，适合对白中的轻微权力变化。
- Moderate：腰部至胸口以下，适合威胁、决心和建筑压迫。
- Extreme：接近地面且仰角很大，仅在剧情明确需要时使用；优先改用 Ground Level 或 Vertical Upward 的专门规则。

## Lens Recommendation

- 28mm-35mm 倾向：强化近大远小和空间力量，注意脸部边缘变形。
- 35mm-50mm 倾向：人物比例更自然，作为默认选择。
- 长焦倾向：压缩背景但削弱低角度空间感，只在明确视觉设计下使用。

## Seedance Execution Rule

必须说明摄影机相对主体的高度、前后/左右侧位、仰角强度、人物面对方向和背景参照。单镜头只保留一个主要机位逻辑，不同时叠加环绕、快速推拉、大幅升降和越轴；复杂低机位旋转留给高级镜头层。

## Recommended Prompt Language

> 摄影机位于 A 左前方约 2 米、低于胸口高度，以中等低角度斜向上拍摄。A 身体面向画面右侧的高楼并缓慢抬头，高楼从其身后向上延伸；保持 A 的侧脸和身体比例自然，不直视镜头，不越过 180 度轴线，摄影机全程固定。

## Avoid

- 只写“仰拍”，不说明相对谁、从哪一侧拍
- 极端广角贴近脸部造成五官变形
- 人物无原因直视镜头或身体后仰
- 背景建筑跳变、弯曲或方向错误
- 低角度同时叠加复杂运镜

## Common Failure

- 变成普通平视：补充摄影机低于胸口、视轴明显斜向上。
- 变成地面鞋底特写：提高机位或改用 Ground Level。
- 人脸变形：拉远摄影距离，采用 35mm-50mm 倾向。
- 权力关系混乱：重新锁定 A、B 左右位置、面对方向和轴线侧。

## Combination

- Low Angle + Static Hold：最稳定，用姿态与背景体现力量。
- Low Angle + Slow Push In：只在情绪升级时轻微推进。
- Low Angle + Foreground Structure：栏杆、门框或建筑线条强化压迫。

## Shot Design Selection Rule

当镜头需要突出主体力量、威胁或高大结构，且观察点仍处于人物尺度时选择 Low Angle。若摄影机几乎贴地观察脚步，选择 Ground Level；若镜头垂直朝上看天空或井口，选择 Vertical Upward。

## Final Principle

Low Angle 通过相对高度表达权力和体量。角度必须服务剧情，并保持人物比例、空间参照、方向和 180 度轴线清楚。
