# Memory And Distortion

## 中文名称

快切闪回；重影镜头；倒置镜头；记忆视觉失真。

## Source Shot Types

### 快切闪回镜头

用少量短记忆片段快速出现。每个片段只承载一个可识别信息，颜色、人物资产和时代状态需一致；闪回顺序由剧情触发，不随机堆叠。

### 重影镜头

同一人物或动作形成受控叠影，表达幻觉、记忆或心理延迟。必须说明主像、重影数量、偏移方向和持续时间。

Prompt：`A 的主像保持清晰，右侧出现一层低透明度动作延迟重影，重影只持续一次转头过程，随后与主像重合。`

### 倒置镜头

整个画面以固定 180 度倒置呈现，用于精神失衡或世界观异常。倒置期间地面、人物和重力关系保持一致，不在同一镜头中反复翻转。

Prompt：`画面从镜头开始即保持固定倒置，A 沿走廊向画面左侧缓慢行走；摄影机不旋转，走廊结构和人物方向连续。`

## Narrative Function

- 闪回：快速唤起过去信息。
- 重影：表现记忆残留、幻觉和主观延迟。
- 倒置：表现强烈失衡、颠覆或异常空间感。

## Seedance Execution Rule

效果必须作用于明确对象和明确区间。单镜头只保留一种主要失真机制；闪回属于多个独立短镜头的编辑组合，不要求模型在一个连续镜头中生成多时空。

## Avoid And Common Failure

- 闪回人物换脸：为每段引用同一角色资产和对应时期状态。
- 重影变成双胞胎：明确低透明度、同一人物、动作延迟。
- 倒置过程中自动旋转：写明从开始到结束固定倒置。
- 失真掩盖剧情信息：每段只保留一个关键视觉事实。

## Selection Principle

回忆信息串联用快切闪回；主观幻觉与延迟用重影；世界或心理彻底失衡用倒置。

## Final Principle

记忆和失真镜头必须建立清楚的现实锚点，否则效果只会制造身份与空间混乱。
