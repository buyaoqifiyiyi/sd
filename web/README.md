# SD Film Web MVP

这是一个无依赖的本地网页应用，使用 Node.js 内置服务，不需要安装 npm 包。

它实现了：项目创建、STATE-00 至 STATE-09 的流程视图、确认推进、工件摘要、确认清单，以及每个项目独立的本地状态文件。

## 本地预览

双击根目录的 `启动网页.bat`；或在此目录执行：

```powershell
node server.mjs
```

访问 `http://127.0.0.1:4173`。

每个项目的数据保存在 `data/projects/<Project ID>/project.json`，并同步写出符合 SD Film 状态合同的 `project_status.md`。关闭浏览器后仍可恢复。

## 上传项目文件

通过工作台顶部的“上传文件”或右侧“项目文件”卡片，可上传剧本、资产和参考素材。支持 `.txt`、`.md`、`.pdf`、Word 文档、图片、视频和音频；单个文件最大 50 MB。文件保存在项目目录的 `uploads/` 内，不会上传到第三方服务。

## 连接 OpenAI

点击页面右上角“模型中心”，只需为每个 API 提供方连接一次。API Key 只保存在正在运行的本地服务内存中，关闭或重启服务后会自动清除；它不会写进项目、浏览器本地存储或日志。

模型不需要逐步手动选择。系统会依据当前 STATE、项目正文、已保存工件和上传文件自动路由：剧本、导演、镜头和审核等高推理阶段优先 GPT-5.6 Terra；结构化整理阶段优先 GPT-5.6 Luna；STATE-03 根据“内置图像 / Midjourney / 外部出图”意图选择资产提示词包；STATE-07/08 检测到首尾帧、短片或已有视频编辑时使用 MiniMax H3，其余视频需求使用 Seedance 2.5。OpenAI 未连接而兼容文本 API 已连接时，文字阶段会自动降级为兼容文本提示词输出。

多模态 GPT 适配器会在用户点击“模型生成草稿”时发送当前项目摘要、当前阶段、已保存工件和最多四张已上传参考图片。OpenAI 兼容文本接口不会发送图片，只输出文本提示词；Built-in Image、Midjourney、Seedance 和 MiniMax 提示词适配器不调用第三方 API，只在本地交付可复制的提示词包。生成或提示词输出都不会自动确认或推进制作阶段。

## 返回与修改

任意已经确认的历史阶段都可以在左侧流程中打开。点击“返回此步骤继续”后，系统会回到该阶段允许编辑；后续成果不会删除，但会被标为“待复核”，需要在重新推进时逐项确认。这样既能改剧本、资产或镜头，也不会丢失已经完成的内容。

## 接入真实 `sd-film` 的边界

浏览器不直接读取 `SKILL.md`，也不保存模型密钥。当前服务端已处理项目状态和确认推进；接入真实 Agent / 模型时仍需要：

1. 按 Project ID 读取、校验和写回 `project_status.md` / portable state；
2. 调用具备 `sd-film` Skill 的 Agent，返回结构化的工件、确认关卡和下一工作流；
3. 将图像、视频生成提交为异步任务，并将结果和审核记录写回项目状态；
4. 只向浏览器返回用户有权访问的项目和媒体 URL。

已提供 `POST /api/projects` 和 `POST /api/projects/:id/actions/confirm`。真实 Agent 接口应由服务端校验 Completion Gate 后再推进状态。
