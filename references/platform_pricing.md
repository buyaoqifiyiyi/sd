# Platform Pricing And Runtime Parameter Truth Table

本文件是`references/skill_experience_contract.md`的`## Knowledge Classification`中`O｜Operational Parameter`所要求的**已取证参数真源**：模型与平台的价格、限时折扣、跨分辨率比较基准集中登记在这里。它不创建STATE、不拥有最终Prompt字段、不替代各`adapters/`的能力声明，也不定义任何用户可见Template字段。

消费方：`modules/model-selection.md`的`## Cost Alternative Note`（成本提示）、各`adapters/`（能力边界）、`references/asset_package.md`（素材计费影响）。

---

## Rules

费率属于`O`类，必须带`valid_as_of`与来源：

1. **只有本文件已登记的档位可以出数字。** 未登记档位一律写`待用户提供`；不得推算、不得用"更便宜 / 差不多 / 大约"这类定性说法冒充价格。
2. **必须写清币种、分辨率、画幅与是否含视频输入**——官方价格表按分辨率分档，且"含视频输入"另有计价与最低 token 消耗下限。
3. **限时折扣必须写适用期。** 折扣到期后一律按原价计算，不得沿用折扣价。
4. **跨分辨率或跨画幅比较前必须先对齐交付画幅。** 项目`交付画幅`为`Pending`时，成本提示只能按档位并列，不得替用户选定画幅后再说"更便宜"。
5. **到期或平台改价后必须重新取证并更新`valid_as_of`**；未复测前不得继续引用。
6. **费率不是门**：任何价格都不得成为拒绝、延迟或静默更换用户已选模型的理由（见`modules/model-selection.md`）。

## Seedance 2.5

平台模型ID：`dreamina-seedance-2-5-260628`。来源：BytePlus ModelArk Pricing，`docs.byteplus.com/en/docs/ModelArk/1544106`；`valid_as_of: 2026-09-19`。共同基准：**16:9、24 fps、5 秒输出、无视频输入**。

| 分辨率 | 单价 | 5秒视频 | 含视频输入（输入 2–30 秒） |
|---|---:|---:|---|
| 480p | 0.103 USD/秒 | 0.514 USD | 0.553–2.152 USD/条 |
| 720p | 0.231 USD/秒 | 1.156 USD | 1.244–4.838 USD/条 |
| 1080p | 0.569 USD/秒 | 2.843 USD | 3.062–11.907 USD/条 |

按 token 计价的另一面（同一来源）：480p/720p 无视频输入 10.70 USD/M tokens、含视频输入 6.40；1080p 无视频输入原价 11.7、含视频输入 7.0。价格 = token 单价 × token 消耗量，`估计消耗 = (输入时长 + 输出时长) × 宽 × 高 × 帧率 / 1024`；含视频输入时受最低 token 消耗下限约束。

**限时折扣（已过期）**：1080p 输出 28% off，原文"prices starting at approximately USD 0.41 per second"；适用期 2026-08-14 14:00 至 2026-09-17 14:00（UTC+8）。**该折扣已于 2026-09-17 结束，不得继续按 0.41 USD/秒 计算。**

## MiniMax

来源：MiniMax 开放平台按量计费页`platform.minimax.cn/docs/guides/pricing-paygo`「视频」节与`platform.minimax.io/docs/guides/pricing-paygo`；`valid_as_of: 2026-09-19`。**H3 无独立定价页**——官方视频资源包页只写"H3 暂不支持视频资源包，需按量购买 API 或联系销售"，其"按量购买 API"链接指向的就是该按量计费页。

**H3 按秒计费**（官方计费规则列原文一律"按秒计费"）：

| 模型 | 分辨率 | 刊例价（CNY） | 刊例价（USD） |
|---|---|---:|---:|
| MiniMax-H3 | 768P | 0.50 元/秒 | $0.08/秒 |
| MiniMax-H3 | 2K | 0.80 元/秒 | $0.13/秒 |
| MiniMax-H3-Max | 480P | 0.33 元/秒 | $0.05/秒 |
| MiniMax-H3-Max | 768P | 0.50 元/秒 | $0.08/秒 |

输入素材另计：H3 音频输入**免费**；图片 5 张以内免费、超出 0.20 元/张；视频输入按输入时长与输出分辨率计费（2K 0.80、768P 0.50 元/秒）。H3-Max：图片 2 张以内免费、超出 0.50 元/张；视频输入 480P 0.37、768P 0.97 元/秒。视频再生成（768P→2K）0.30 元/秒。H3-Context-IR 属文本任务，按 token 计价（输入 5.80 / 输出 23.00 元每百万 tokens），不用于视频生成比价。

**H3 的时长粒度也是整数秒**：H3 为 4～15 秒、H3-Max 为 5～15 秒，官方原文"仅支持整数值"，可选值 4—15 逐秒。这与 Seedance 2.5 的整数秒约束同一口径。

Hailuo 系列（非 H3）的点数制与套餐：视频基础包 ¥7,000 / 3,680 点、高级包 ¥15,000 / 8,330 点、进阶包 ¥30,000 / 17,650 点、企业包 ¥40,000 / 25,000 点（原价列 ¥7,368 / ¥16,667 / ¥35,294 / ¥50,000）。按官方原价列做除法可推得约 **1 视频点数 = ¥2**，但**页面并未写出这句话**，属算术推导而非官方明文，不得作为官方汇率引用；折扣价为 1.60–1.90 元/点。Token Plan 积分为另一体系（1,000 积分 = ¥7 / $1），且官方明文**不含 H3**。

## Reviewer Note｜本轮取证的射程（诚实记录）

- 已实测取回：Seedance 2.5 与 Seedance 2.0 系列的官方单价表（含分辨率档位、含视频输入价、单价基准 `16:9 / 24 fps / 5秒`、限时折扣适用期），来源为 BytePlus ModelArk Pricing 页，由本机 CDP 浏览器实际读取页面表格获得。
- 已实测取回：MiniMax H3 / H3-Max 的官方按秒刊例价（人民币与美元两版）、输入素材价、再生成价，来源为 MiniMax 按量计费页；并确认 H3 的时长窗口为整数秒 4—15。
- 未取回：**MiniMax 视频点数→货币的官方明文汇率**。官方只公布套餐价与点数总量；由原价列除法可推得约 ¥2/点，但页面未写明，属推算（见上文）。
- 未取回：H3 能否用视频点数购买或用 Token Plan 积分支付；官方只说不支持视频资源包、积分不覆盖 H3。
- 因此：**H3 与 Seedance 之间可以比价**（两边都有官方按秒价），但**不得把推算的 ¥2/点 当官方汇率引用**，也不得用积分体系折算 H3。
- 交付画幅在本项目仍为`Pending`；跨分辨率比较必须先由用户确定画幅，否则只能并列档位。
