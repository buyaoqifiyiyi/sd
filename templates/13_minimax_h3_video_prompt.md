# MiniMax H3 三段式视频提示词

## Purpose And Ownership

这是仅在 `Target Video Model = MiniMax H3` 时使用的 STATE-08 最终输出模板，独占H3最终字段、顺序和排版。它将官方三段式“参考素材说明 → 核心创意 → 画面过程说明”转为可直接提交的H3 Prompt；不借用Seedance 2.0的十字段骨架，也不借用Seedance 2.5的50项多模态时间线模板。

该模板不改变Production-Locked Script、Canonical Asset、Director Intent、Spatial Blocking、A/B/C尾帧合同、Voice opt-in或视频Prompt永久无BGM规则。

---

## 唯一允许的最终模板

```text
# CLIP-X｜标题 MiniMax H3视频提示词
时长：
画幅：

参考素材说明：
- @图片1 / @视频1 / @音频1：<真实素材或资产ID>；用途：<人物 / 物体 / 场景 / 关键帧 / 风格 / 构图 / 动作 / 运镜 / 音色 / 音频复用 / 编辑>；保持：<其授权维度>。

核心创意：
<主体 + 地点 + 事件 + 题材/风格 + 必要运镜；写清当前Clip的叙事目标和最重要的视觉结果>

画面过程说明：
<按故事线或Shot顺序写每段的开始状态 → 画面/景别/机位 → 动作与情绪 → 空间和道具 → 台词/音效 → 结束状态。>

反向提示词：
禁止生成背景音乐、配乐、BGM、主题音乐、氛围音乐，只保留台词、环境声、动作音效和必要的自然声音。
<只列当前Clip少量真实风险>

非叙事性音乐：N/A
```

每个Clip必须完整使用这六个字段并保持顺序；`非叙事性音乐：N/A`必须是最后一行。不得新增时间线字段、时码、逐秒区间、API参数、内部执行模式或未验证的平台能力。

---

## Field Contract

### 时长 / 画幅

时长仅写Confirmed Clip Plan中的4—15秒。画幅使用已确认的比例、媒介和必要规格；首/尾帧模式服从输入图比例。不得写帧率、帧数、逐秒精度或超过15秒的长视频能力。

### 参考素材说明

全能参考模式最多9图、3视频、3音频、总计12个文件；每段视频或音频2—15秒，视频和音频总时长≤15秒，且音频不能单独作为输入。首/尾帧模式最多2张图。每个实际上传素材必须按上传顺序写`@图片N / @视频N / @音频N`、唯一用途和授权维度；未使用、未确认或无法访问的素材不得列入。

Canonical角色、环境和道具优先于临时动作/构图/风格参考。STATE-07按实际光色漂移风险选择的`Project Color Reference（非资产）`可作为@图片输入，但只能锁定综合色相 / 明度 / 饱和度 / 强调色占比，不得控制角色、环境、道具、构图、光源、镜头或最终画风。视频编辑必须已有实际视频，并明确`CHANGE`与`PRESERVE`；H3不写Seedance式时间码。两张首尾帧只能描述两帧间的连续动作、光影和声音，并明确“不要切镜”。

### 核心创意

使用一段简洁、正向、可执行的描述，固定主体、地点、事件、题材/风格、当前Clip的叙事目标和必要运镜。复杂风格名必须补充少量可见载体，不得压过主体、动作、空间和镜头。

### 画面过程说明

H3可按明确Shot结构切镜：以故事线或`镜头1 / 镜头2`顺序写清每段的起点、画面、摄影机、动作、表演、空间、道具、台词、音效和稳定结尾。需要一镜到底时，只写一段连续动作并明确“不要切镜”；多Shot对白须与镜头时长匹配，跨Shot声音只在用户明确要求时写J-cut / L-cut与画内/画外状态。

每个重要事件仍必须有开始状态、过程和结果；不得新增剧情、改变上游已确认事实、让道具换手/瞬移、翻转空间轴线或让未出场角色提前出现。

### 反向提示词 / 非叙事性音乐

反向提示词第一句固定为无BGM禁令，其余只写当前Clip难以正向锁定的少量风险。`非叙事性音乐：N/A`是H3专属的固定最后行，不得省略、移动或改写成配乐请求。

## Output QA

- 只用于MiniMax H3；标题、时长、画幅、参考素材说明、核心创意、画面过程说明、反向提示词和`非叙事性音乐：N/A`完整且顺序正确。
- 时长4—15秒；没有Seedance 2.5时间线、30秒长时长、Video Extension、Clay Render或时码式Targeted Edit语义。
- 参考输入符合当前H3模式上限，且每项`@`素材真实、已提交/待补状态诚实、用途唯一。
- 对白、口型、音色、音频复用、J-cut/L-cut或视频编辑均只在用户明确要求且输入存在时出现。
- 末尾无BGM禁令和`非叙事性音乐：N/A`均存在；没有额外正文。
