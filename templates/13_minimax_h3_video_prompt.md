# MiniMax H3 三段式视频提示词

## Purpose And Ownership

这是仅在 `Target Video Model = MiniMax H3` 时使用的 STATE-08 最终输出模板，独占H3最终字段、顺序和排版。它将官方三段式“参考素材说明 → 核心创意 → 画面过程说明”转为可直接提交的H3 Prompt；不借用Seedance 2.0的十字段骨架，也不借用Seedance 2.5的50项多模态时间线模板。

该模板不改变Production-Locked Script、Canonical Asset、Director Intent、Spatial Blocking、A/B/C尾帧合同、Voice opt-in或视频Prompt永久无BGM规则。

---

## 唯一允许的最终模板

```text
参考素材说明：
- @图片1 / @视频1 / @音频1：<真实素材或资产ID>；用途：<人物 / 物体 / 场景 / 关键帧 / 风格 / 构图 / 动作 / 运镜 / 音色 / 音频复用 / 编辑>；保持：<其授权维度>。

核心创意：
主风格：<项目风格标签或Visual Grammar Baseline + 项目内含义 + 建立轮的四项Aesthetic Decision Lock各一次（选择与它排除的可见结果）+ 当前Clip的可见 / 可听高价值风格载体；载体可少，四锁不得缺项>
<主体 + 地点 + 事件 + 必要运镜；写清当前Clip的叙事目标和最重要的视觉结果>

画面过程说明：
<按故事线或Shot顺序写每段的开始状态 → 画面/景别/机位 → 动作与情绪 → 空间和道具 → 台词/音效 → 结束状态。>

反向提示词：
禁止生成背景音乐、配乐、BGM、主题音乐、氛围音乐，只保留台词、环境声、动作音效和必要的自然声音。
<只列当前Clip少量真实风险>

非叙事性音乐：N/A
```

每个Clip必须完整使用以下字段并保持顺序；字段名与顺序不得改变。`非叙事性音乐：N/A`必须是最后一行。不得新增时间线字段、时码、逐秒区间、API参数、内部执行模式或未验证的平台能力。

Prompt正文不声明标题、时长与画幅。`Clip ID`、`标题`、`目标时长`、`分辨率`、`宽高比`都是生成时的平台选择或生产计划信息，由 STATE-07 的 Confirmed Clip Production Plan 拥有并记录，不进入Prompt正文。Prompt以文件名（`G0N_CLIP-XXX.md`）与交付顺序定位；Seedance 2.5 的目标时长仍可从时间线的末阶段边界读出，其余模型的目标时长只在 Clip Plan 中声明。

## Field Contract

### 时长（正文不写）

本模板没有`时长：`字段。目标时长只在Clip Plan中声明：H3为4—15秒。正文不得写时长、帧率、帧数、逐秒精度或超过15秒的长视频能力。输出分辨率与宽高比是用户在生成时自行选择的平台参数，不进入本Prompt，也不得另设字段声明；首/尾帧模式服从输入图比例。

### 参考素材说明

全能参考模式最多9图、3视频、3音频、总计12个文件；每段视频或音频2—15秒，视频和音频总时长≤15秒，且音频不能单独作为输入。首/尾帧模式最多2张图。每个实际上传素材必须按上传顺序写`@图片N / @视频N / @音频N`、唯一用途和授权维度；未使用、未确认或无法访问的素材不得列入。Final=`REQUIRED`的`REF-SKETCH-XX`仅能在All-Reference模式以真实`@图片N`提交，并计入9图/12文件预算；Start / End、Start-End和Video Edit模式不得把它伪装为帧或声称已提交。该模式冲突时Prompt Pending，先返回STATE-07改为All-Reference、改选模型或调整Blocking。

Canonical角色、环境和道具优先于临时动作/构图/风格参考。All-Reference模式中，Final=`REQUIRED`且草图可访问、Signature匹配、预算有位时，写`- @图片N：REF-SKETCH-XX｜<真实文件或受控ID>；用途：实际提交的Clip Blocking / Visual Blocking；保持：仅Position / Facing / Distance / Topology / Axis / Camera / Pose / Gaze / Action Path。`不可提交时不得写成已使用。STATE-07按实际光色漂移风险选择的`Project Color Reference（非资产）`可作为@图片输入，但只能锁定综合色相 / 明度 / 饱和度 / 强调色占比，不得控制角色、环境、道具、构图、光源、镜头或最终画风。视频编辑必须已有实际视频，并明确`CHANGE`与`PRESERVE`；H3不写Seedance式时间码。两张首尾帧只能描述两帧间的连续动作、光影和声音，并明确“不要切镜”。

### 核心创意

保持H3官方三段式，不新增顶级`主风格：`段落；但`核心创意：`下的第一行必须是`主风格：`。最低内容按`knowledge/prompt_compilation/state08_projection.md`的`### 主风格 Minimum Content Rule`执行：建立轮必须写足标签或基线 + 项目内含义、Visual Grammar Baseline的稳定倾向、Aesthetic Decision Lock四项各一次（每项含选择与它排除的可见结果）以及当前Clip的载体，**不得压成一句风格句**；后续连续Clip只保留已锁定锚点与当前Delta，但四锁锚点不得整体消失。它写经确认的项目风格标签或Visual Grammar Baseline、当前项目具体含义，以及当前Clip最有控制价值的可见 / 可听载体——载体可少，四锁不得缺项。第二行才使用简洁、正向、可执行的描述固定主体、地点、事件、当前Clip叙事目标和必要运镜。风格必须来自已确认Visual Direction / Project Bible、Canonical资产、Director Intent与当前剧情功能的交集；不得压过主体、动作、空间和镜头，也不得带入无依据默认场景包。

### 画面过程说明

H3可按明确Shot结构切镜：以故事线或`镜头1 / 镜头2`顺序写清每段的起点、画面、摄影机、动作、表演、空间、道具、台词、音效和稳定结尾。需要一镜到底时，只写一段连续动作并明确“不要切镜”；多Shot对白须与镜头时长匹配，跨Shot声音只在用户明确要求时写J-cut / L-cut与画内/画外状态。

本段同时承担背景与环境活动，不得只写主要表演者。画面存在可见非主要角色时，必须逐人给出镜内任务、注意对象、开始或反应时点与强度差异，写明谁先察觉、谁晚半拍、谁完全不看；不得所有人同一时点转向同一目标、同时做同一动作或同时冻结。环境按地点与时间维持自己的节奏，不等待主人公启动；无人时写清环境动态或有意留白与仅有环境声。背景活动强度必须低于当前视觉重点，不得穿过主体轮廓、遮挡关键表演或制造错误焦点。

段数与镜头数以Confirmed Clip Production Plan锁定的分镜单元为准，必须与实际写出的段数一致，并在本段首行写明总数声明，例如“本Clip严格只有N段，禁止增加额外段、额外镜头或额外场景”；不得为此新增顶级字段。模型可能自行补出计划外镜头时，`反向提示词：`保留同义兜底句。

每个重要事件仍必须有开始状态、过程和结果；不得新增剧情、改变上游已确认事实、让道具换手/瞬移、翻转空间轴线或让未出场角色提前出现。

### 反向提示词 / 非叙事性音乐

反向提示词第一句固定为无BGM禁令，其余只写当前Clip难以正向锁定的少量风险；模型可能自行补出计划外镜头时，本字段保留与`画面过程说明`总数声明一致的兜底句“本Clip严格只有N段，禁止增加额外段、额外镜头或额外场景”，该数量必须与实际写出的段数完全一致。`非叙事性音乐：N/A`是H3专属的固定最后行，不得省略、移动或改写成配乐请求。

## Output QA

保存为文件时必须运行 `scripts/validate_prompt_package.py <prompt-file> --model minimax-h3`；该校验器只做确定性断言（字段存在与顺序、`核心创意：`首行、反向提示词位置、`非叙事性音乐：N/A`为最后一行、无BGM固定句，以及两条内容形态：Canonical参考条目的`<资产ID>｜<资产名>`形态与`主风格：`行不得保留通用负向清单），未通过不得交付，通过也不替代下列语义检查。

- 只用于MiniMax H3；参考素材说明、核心创意（第一行为`主风格：`）、画面过程说明、反向提示词和`非叙事性音乐：N/A`完整且顺序正确；正文没有标题行、`时长：`或`画幅：`（标题、目标时长、分辨率与宽高比由STATE-07的Confirmed Clip Production Plan拥有，不入Prompt正文）。
- 参考素材的每条`@`条目均为`@图片N：<资产ID>｜<资产名>`形态；同一Asset ID对应多张Canonical图时补View Code或Purpose，**包内文件名的扩展名不进入引用名**；`REF-SKETCH` / `REF-TAIL` / 色卡 / 用户提供的首尾帧沿用各自登记名。
- `主风格：`行按`knowledge/prompt_compilation/state08_projection.md`的`### 主风格 Minimum Content Rule`写足（建立轮四块），且不保留通用负向清单（`禁止 / 不要 / 避免 / 不做 / 拒绝 / 不得`）；这类约束收束到末尾唯一`反向提示词`。四锁里"排除了什么可见结果"属于必需内容，不在该断言的射程内。四锁在字段内保留维度名（`反差与光比结构` / `色彩对抗关系` / `构图主张` / `视觉母题与变化轨迹`）；完全没有维度名时校验器给出`WARNING`（不阻断交付），部分缺失仍须人工判定。
- Clip Plan中的确认时长为4—15秒；正文没有`时长：`，也没有Seedance 2.5时间线、30秒长时长、Video Extension、Clay Render或时码式Targeted Edit语义。
- 参考输入符合当前H3模式上限，且每项`@`素材真实、已提交/待补状态诚实、用途唯一；Final=`REQUIRED`时仅All-Reference存在可访问、签名匹配的`REF-SKETCH-XX @图片N`。
- 对白、口型、音色、音频复用、J-cut/L-cut或视频编辑均只在用户明确要求且输入存在时出现。
- `画面过程说明`已声明段数并承担背景与环境活动；声明与实际段数一致，且末尾`反向提示词：`保留与声明一致的数量兜底句，非主要角色逐人有任务与时点差异，无人时有环境动态或有意留白。多段之间必须有可指认的机位 / 景别差异或明确的静置段；每段都写"极缓 / 轻微"同语汇缓动等于固定机位，只能作为其中一段且必须由剧情节点触发。每段运镜是否写明**情绪触发者**与可核对的起止景别；整片是否至少一次由关键情绪节点驱动，而不是全部只由空间或功能触发。
- 参考覆盖是否按`rules/02_asset_rules.md`的路由覆盖不变量核对：有反向背景 / 轴线 / 门窗朝向风险时至少覆盖`ENV-01`与`ENV-02`或`ENV-03`；服装与道具**状态**（敞/合、亮/灭、干/湿）有独立参考或文字锁，不用一张身份图代替。
- 末尾无BGM禁令和`非叙事性音乐：N/A`均存在；没有额外正文。
