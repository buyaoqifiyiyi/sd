## Visual Production Checkpoint

固定顺序为`Prompt Draft → Prompt Confirmed → Image Generated → Asset Confirmed`。FX Image Prompt必须完整包含Effect身份、Trigger/Source、Lifecycle、材质行为、交互、光影、构图/视角、一致性、必要负面限制与生成参数。未经Prompt确认不得生成图片；生成图在用户确认前仅为Candidate References；未经图片确认不得登记Canonical References、Active Version或confirmed asset。
