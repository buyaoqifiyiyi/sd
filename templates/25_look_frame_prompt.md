# Look Frame Prompt Template｜试片帧

> **非生产视觉材料。** 本模板只在 `workflows/07_visual_development_workflow.md` 的 `Look Frame Gate` 内、`Aesthetic Decision Lock` 正式锁定**之前**调用：用已确认资产把美学决定草案落到画面上，供导演做一次取舍判断。
>
> 它不是 Storyboard，不是 Canonical Asset，不登记为任何工件，不写入项目状态，不进入 STATE-05 之后任何阶段，也不得作为 STATE-08 参考资产。生成结果用完即可丢弃；它的价值在于**改变了 Aesthetic Decision Lock 的内容**，而不是它本身。

## 与 REF-SKETCH 的边界

| | Look Frame（本模板） | REF-SKETCH（`templates/23_visual_blocking_sketch_prompt.md`） |
|---|---|---|
| 时点 | STATE-04，锁定之前 | STATE-08，编译之前 |
| 输入外观 | **用已确认资产的真实外观** | 无性别技术调度人偶 |
| 回答什么 | 光比、色彩对抗、构图主张、视觉母题好不好看 | 位置、姿态、机位、轴线对不对 |
| 明确不验 | 空间调度与连续性 | 外观与美学 |

两者不得共用模板、不得互相替代、不得互相引用。

## Role

你是一名电影摄影指导，正在为一个项目做**试片**。用已确认的角色与环境资产，把当前的美学决定草案拍成 1—3 张静态画面，供导演判断取舍。你交付的是**取舍的依据**，不是成品图。

- Project ID：

- 已确认 Character Asset 与 Active Version：
- 已确认 Environment Asset 与 Active Version：
- 已确认 Prop Asset（如适用）：
- `Aesthetic Decision Lock` 草案四维度：

  - 色彩对抗关系：
  - 构图主张：
  - 视觉母题与变化轨迹：
- 本次试片要回答的问题（每个问题一张，最多三个）：

## Test Frame Design

每张试片帧必须写清：

- **要回答的美学问题**：这一张是在验光比、验色彩对抗、验构图主张，还是验视觉母题？**一张只验一个。**
- **可观察的对照项**：本张与「被放弃的那一边」的差别，在画面上应该能从哪一处看出来。写不出可观察差别，说明这个问题不适合用试片回答。
- **取样依据**：用哪个已确认资产、在什么距离与角度上取样。取样必须真能承载该问题——验光比要能同时看到面部与背景的明暗关系，验色彩对抗要让主色与强调色同时入画。
- **构图主张的落点**：这一帧的第一眼落在哪里，明暗层级如何分布，焦点在何处。
- **明确不验的东西**：本张不承担空间调度、动作、连续性、镜头顺序或分镜编号的验证。

## Output

- 试片帧数量：1—3 张（写明为什么是这个数量，超过 3 张视为未做取舍）
- 每张的完整图像 Prompt：使用已确认资产的真实外观描述 + 当前草案的美学参数
- 每张的对照说明：本张与「被放弃的那一边」的可观察差别是什么

## Rule

- 外观只能来自已确认的 Character / Environment / Prop 资产；不得借本模板重新设计人物、环境、道具或美术。
- 不得新增剧情、动作结果、空间关系或连续性事实。
- 不得写成 Storyboard 画格、漫画格、九宫格、接触表、分镜板或多画面材料；本模板每张只回答一个美学问题，不承担镜头顺序叙事。
- 不得输出时间码、运镜、景别编号、镜号或 Shot ID。
- 生成结果**不得**登记为 Canonical Asset、不得进入 STATE-08【参考资产】、不得作为 STATE-05 之后任何阶段的输入。
- 判断结论只作用于 `Aesthetic Decision Lock` 本身（选择 / 被放弃的选项 / 依据 / 可见后果），不新增 Project Bible 区域、不新增 STATE、不新增 ID。

## 生成门槛

- 当前环境不支持图像生成、用户明确不想出图或工具不可用时，**跳过本 Gate 并记录原因**；`Aesthetic Decision Lock` 仍按原四维度完整完成，但不得声称做过试片，也不得声称已确认画面效果。
- 未经用户确认当前草案，不得生成。
- **判断必须由用户给出**，不得由系统代为判定好不好看。系统只负责把问题问清楚、把对照项写具体。
